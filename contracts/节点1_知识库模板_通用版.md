# 节点 1 · 知识库模板（通用厂内版）

> **用法**：复制下方「可直接粘贴」到 Comfy 节点 1「② 知识库」，或接上游 STRING 节点。  
> **定位**：资料与口径，**不写** JSON 契约（契约在 `节点1_系统Prompt_通用版.md`）。  
> **可按项目**：复制本文件后增删「项目专节」，系统 Prompt 保持通用即可。

---

## 可直接粘贴（知识库正文）

```text
=== ecursor 眼眉 · 通用知识库 v1 ===

【厂内定位】
- 本知识库供模型查阅，不替代客户本轮原话。

【硬禁忌 — 违反则不要 apply，改 consult 说明】
- 不编摄影机、灯光、服装、场景、Wan/扩散、整脸、口型、身体大动。
- macro 各键必须 0～100 整数；不要输出帧号、不要输出 schema 外字段。
- 一段 5 秒一包：不要在同一包里硬拧两种相反情绪（如又施压又可怜）。

【consult 常见问答口径】
- 「六根滑杆」：push 方向、power 力度、speed 快慢、steady 稳盯、grip 定住、outro 收场；细节见厂内滑杆规范。
- 「盯住段」：hold_seg.shape 管盯住段是平顶、下泄、慢拱、脉冲还是发颤；与 grip（定得住）不是一回事。
- 「预设 vs 滑杆」：先选十六预设之一当底子，再用 macro 微调；不是 16 根滑杆。

【十六预设 · 人话速查】
压·慑：施压·凝视(标准施压钉视) | 冷压·决心(更狠更钉) | 威慑·一瞬(极急快收) | 怒视·压人(高推平顶) | 鄙夷·冷瞥(外放轻力快收)
悲·怯：可怜·委屈(内收轻颤) | 要哭未哭(更轻慢颤) | 崩溃·泄劲(decay快断) | 哀求·仰望(内收慢收) | 惊惧·一怔(急颤快收) | 空竭·死心(轻慢散)
媚·勾：魅惑·勾人(pulse粘慢收) | 纯甜·含情(轻甜脉冲) | 媚杀·一眼(深脉冲猛) | 若即若离(swell飘) | 打量·玩味(swell中等粘)

【客户说法 → 编译提示（apply 时参考）】
更冷 / 更钉 / 更狠 → power↑ steady↑ grip↑；style 偏冷时可配合冷压·决心
更轻 / 更可怜 / 要哭 → power↓ push↓；可怜·委屈 / 要哭未哭
更急 / 一瞬间 / 瞪一下 → speed↑；威慑·一瞬
慢勾 / 媚 / 放电 → 魅惑·勾人；hold pulse_rate 40～60 量级
别颤 / 稳一点 → steady↑；shape 避免 tremble，倾向 flat
快收 / 利落收场 → outro↓（数值低=快落）
眉压 / 往里收 → push 偏低（内收）或 power↑ 视语境
外放瞪人 → push↑ power↑

【修改轮话术识别】
含：刚才、上一版、在基础上、再…一点、更…一点、别那么…、沿用 → 倾向 apply·修改，优先 macro_delta，勿乱换 preset。

【energy_map_note 写法示例】
- 「起段急推，盯住平顶高稳，收场快收。」
- 「内收轻力，盯住段微颤，收场留尾。」
（不写扩散、不写镜头）

【项目占位 — 可按片填写】
- 主角/片名：
- 默认审美：（例：少眨、眉压、冷感）
- 禁忌：（例：禁止卡通颤眉）
- 参考戏一句：（例：施压瞬间凝视，不笑眼）

=== 知识库结束 ===
```
