## 2. 真值层级（谁可以改什么）

```text
① SliderPacket（滑杆 · 唯一编辑入口）
    ↓ finalize_packet（L1 禁区）
② energy_envelope E(t)（能量曲线）
    ↓ channels_from_envelope
③ Dense 12×150（包络展开）
    ↓ apply_human_prior
④ Dense′（真人律后）
    ↓ fix_pulse_quality（平庸三检）
⑤ 烘焙 02_烘焙_真人律.json（_baked_dense）
    ↓
```

| 层级 | 客户/LLM 能否直接改 | 文件/段 |
|------|---------------------|---------|
| 滑杆 | ✅ **唯一能改** | `slider_packet` |
| 包络 | ❌ 只看 | 工作台 ② / `2_energy_envelope` |
| 全量 | ❌ 只看 | 工作台 ③④ |
| 烘焙 02 | ❌ 出厂物 | `02_烘焙_真人律.json` |

**硬禁止**：

1. LLM / 前端 **直接改** `channel_tracks` 里任意 `(t, v)`（除非走 `--legacy-sparse` 专家母版路径）。  
4. 绕过 `human_prior` 把包络展开当最终脸（除非 `ECURSOR_HUMAN_PRIOR=0` 做 A/B）。

## 3. 十二操作通道（指令集只写这 12 个名字）

> 程序枚举：`channel_contract.CANONICAL_KEYS`  

| id | 中文 | 数值习惯 | 观众读到什么 | S01 施压·凝视要点 |
|----|------|----------|--------------|-------------------|
| `pupil_x` | 视线左右 | 0 中；**正=向右** | 锁住对方的方向 | 14～25 急扫；**17 过冲、23 回弹** |
| `pupil_y` | 视线上下 | **负=向下** | 略沉、不仰头瞪 | 比 `pupil_x` **晚 2～5 帧** 到位 |
| `blink` | 眼睑开合 | 0 睁；**大=闭** | 凝视少眨 | **独立脉冲** ~86，不跟扫视同帧猛闭 |
| `eyebrow` | 眉压 | 0～0.4+ | 冷压、不挑眉凶相 | **慢于眼**；峰约 **32** |
| `pupil_scale` | 瞳孔缩放 | 0～0.14 | 盯住时略收 | 随能量尾随，弱于主视线 |
| `iris_scale` | 虹膜圈 | 0～0.08 | 眼神锐度 | 眉峰后略抬 |
| `cornea_bulge` | 角膜鼓起 | 0～0.18 | 「有神」 | 启动末～保持初抬起 |
| `squint` | 眯眼框压 | 0～0.24 | 眶压、颧骨张力 | 跟 `eyebrow`，略晚略弱 |
| `brow_raise` | 挑眉 | **常≈0** | 本戏压低 | 施压戏 **禁止** 高挑眉 |
| `lid_upper` | 上眼睑 | 0～0.10 | 上睑压 | 跟眉，弱于 `eyebrow` |
| `lid_lower` | 下眼睑 | 0～0.05 | 下睑微绷 | 保持段微抬 |
| `eye_gloss` | 湿润高光 | **可非 0 底** | 节拍/质感 | 随能量与眨联动；**供 05 扩散** |

**扩散提示**：`channel_contract.DIFFUSION_HINTS`（写 Prompt / 05 时用）。

## 4. 能量四段与滑杆分工

与 `滑杆规范.md` §3 一致：

| 阶段 | 参考帧 | 主要滑杆 | 全量上应看到 |
|------|--------|----------|--------------|
| 蓄力 | 0～14 | 模板/预设 | 各通道近 0，允许极弱预备 |
| 启动 | ~14～25 | `speed` `power` `push` | 视线撞击、过冲回弹 |
| 保持 | ~25～90 | `steady` `grip` `hold_seg` | 盯住 + 底噪/脉冲/颤（依 shape） |
| 缓和 | ~90～149 | `outro` | 有序收回，非截断 |

`hold_seg.shape` 在全量保持段的表现：

| shape | 全量语义 |
|-------|----------|
| `flat` | 平顶（施压默认） |
| `decay` | 保持段能量下泄 |
| `swell` | 慢拱起伏 |
| `pulse` | 低频起伏（魅惑） |
| `tremble` | 高频微颤（可怜/惊惧） |

## 5. 分通道节奏合同（继承原「分轨关键帧」）

原稀疏规范要求：**各通道自己的时刻与曲线，再合成**。现由 **`human_prior` + `pulse_quality`** 在全量上保证，不依赖手填点。

### 5.1 必须满足（程序可检）

| 编号 | 规则 | 检测位置 |
|------|------|----------|
| R01 | 扫视窗（约 12～28）`pupil_x` **先峰后谷**（过冲回弹） | `human_prior` / 验收 |
| R02 | `speed` 高 → 过冲比 `speed` 低 **更大** | A/B 滑杆 |
| R03 | 眉峰帧 − 眼动 onset **≥ 5** | `pulse_quality` Q03 |
| R04 | `blink` 不与扫视主峰 **同帧猛到最大** | 人工 + 曲线 |
| R05 | 盯住窗（约 25～110）`pupil_x/y` 方差 **> ε 且 < 上限** | `human_prior` |
| R06 | 扫视窗颤动 **<** 盯住窗（勿盖过冲） | `micro_jitter` by_phase |
| R07 | 12 轨长度 **150**，无 NaN | `validate_baked_delivery` |

### 5.2 通道耦合（一人脸）

| 主钟 | 跟随 |
|------|------|
| `pupil_x` / `pupil_y` 扫视 | `eyebrow`、`squint`、`pupil_scale` **晚 + 弱** |
| 能量标量 E(t) | `iris_scale`、`cornea_bulge`、`lid_*` 同向缩放 |
| `blink` | **独立** 事件轴 |

**禁止**：12 轨各画各的、互不跟随也不独立眨眼。

### 5.3 S01 施压·凝视 · 数值锚（验收对照）

| 通道 | 典型峰帧 | 典型峰值 v |
|------|----------|------------|
| pupil_x | 17（冲）→ 23（稳） | 0.34 → 0.30 |
| pupil_y | 20 → 25 | -0.13 → -0.11 |
| eyebrow | 32 | 0.36～0.40 |
| blink | 86 | 0.12 |
| eye_gloss | 55 | 0.40 |

## 6. 全量帧合格线（§0 合格线 · 继承）

### 6.1 结构

| 检查 | 合格 |
|------|------|
| 帧数 | 每通道 **150** 个采样 |
| 通道 | **12** 轨齐全 |
| schema | 烘焙含 `_baked_dense: true` 或 `schema_version` 含 `baked` |

| 报告 | 含 `human_prior_report`；可选 `pulse_quality_report`、`_pulse_quality_fix_log` |

### 6.2 表演（Dense′ / 烘焙）

| 检查 | 不合格观感 |
|------|------------|
| 扫视 | 匀速撞停、无过冲 |
| 盯住 | 死线、或乱抖 |
| 眉眼 | 同帧一起猛冲 |
| 眨 | 扫视时猛闭 / 凝视期乱眨 |
| 全脸 | 12 条漂亮曲线但不像一个人 |

细节阈值见 `眼眉真人默认律.md` §6.1～§6.4。

## 7. 负面清单（原 L2 关键帧 · 并入全量质检）

> 原 `pulse_keyframe_fix` / 手填过冲点 **已废弃**；下列改由 **出厂链自动保证** 或 **平庸修正** 处理。

| 编号 | 禁止 | 现处理方式 |
|------|------|------------|
| N01 | 高速扫视 **无过冲** | `human_prior` 二阶动力学 |
| N02 | 盯住 **死线**（方差≈0） | 盯住底噪 + Q02 |
| N03 | 盯住 **过乱**（尖刺过多） | Q02 轻平滑 |
| N04 | 峰太弱、戏像没发力 | Q01 能量抬升 |
| N05 | 眉眼 **同时峰值** | Q03 眉延后 |
| N06 | `brow_raise` 施压戏过高 | 包络 + 人格 clamp |
| N07 | 启动段 **颤动盖过冲** | jitter by_phase：启动 amplitude=0 |
| N08 | 跳过真人律直接播包络 | **流程错误** |

**滑杆 L1 禁区**（越界弹回）仍在 `滑杆规范.md` §10，不在此重复。
