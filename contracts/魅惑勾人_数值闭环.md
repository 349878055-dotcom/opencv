## 1. 第一层 · 滑杆宪法（唯一编辑入口）

### 1.1 出厂初始值（v1 定稿 · 与代码一致）

**preset / emotion** = `魅惑·勾人`

| 字段 | 键 | **定稿值** | 允许微调带（L1） |
|------|-----|-----------|------------------|
| macro | push | **72** | 52～92 |
| macro | power | **62** | 35～75 |
| macro | speed | **40** | 20～60 |
| macro | steady | **70** | 50～90 |
| macro | grip | **82** | 62～100 |
| macro | outro | **72** | 52～92 |
| hold | shape | **pulse** | 仅 pulse / swell |
| hold | pulse_rate | **46** | 30～70 |
| hold | pulse_depth | **58** | 25～65 |
| hold | swell | **32** | （pulse 形下辅助，少单独拧） |

**禁止组合（L1 会弹回或改形）**：

- shape = flat / decay / tremble（媚·勾戏种只允许 pulse、swell）  
- speed≥82 且 power≤28（急却无力）  
- steady≥80 且 grip≤25（钉却泄）  
- 非 pulse 形却 pulse_depth≥1  

### 1.2 数值背后的戏意（方便你记）

| 键 | 55 表示什么 | 本条为何是 72/82/40… |
|----|-------------|----------------------|
| push 72 | 偏外放 | 面向观众勾，不是内收可怜 |
| power 55 | 中等力 | 不媚杀、不施压顶满 |
| speed 40 | 起慢 | 慢勾，非一瞬瞪 |
| steady 70 | 中稳 | 有脉冲，不是死钉 95+ |
| grip 82 | 高粘 | 盯住不愿泄 |
| outro 72 | 慢收 | 留韵；&lt;50 会变成快断收场 |
| pulse_rate 50 | 放电密度中 | 盯住段可见波纹 |
| pulse_depth 45 | 波深中 | 勿超过 60 以免像媚杀 |

### 1.3 单轮微调协议（落实到数）

| 客户话 | 只改 1～2 项 | 建议 delta |
|--------|--------------|------------|
| 更勾 / 更放电 | pulse_rate 或 pulse_depth | +5～+10 |
| 更粘 | grip | +8 |
| 更慢收 | outro | +10 |
| 更柔 / 别太狠 | power | −8 |
| 脉冲太密 | pulse_rate | −8 |
| 收太快 | outro | −15（慎，低于 50 变快收） |

**不要一次改**：speed、power、grip、outro 四个同时动——无法归因。

## 2. 第二层 · 能量包络 E(t)（由 §1 公式推出）

> 以下数字由当前 `envelope_compile.py` 对 §1 初值 **直接计算**（150 帧、30fps）。  
> 你改 §1 后，用工作台 ② 包络或重跑节点 2 刷新，本节表应 **整体重算对照**。

### 2.1 时间锚点（帧号 · 定稿）

| 符号 | **帧** | 时间 (s) | 戏意 |
|------|--------|----------|------|
| t_peak | **18** | 0.60 | 起势爬到峰 |
| t_settle | **24** | 0.80 | 落到平顶区 |
| t_hold0 | **25** | 0.83 | 盯住段开始 |
| t_hold1 | **110** | 3.67 | 盯住段结束（outro≥50 → 长盯住） |
| t_outro_end | **149** | 4.97 | 收场结束 |

对比施压类（speed 高、outro 低）：魅惑 **起更晚（18 vs ~15）**、**盯住更长（到 110）**、**收场更慢**。

### 2.2 能量标量（E(t) 关键值）

| 指标 | **定稿值** | 验收 |
|------|-----------|------|
| peak_level（公式峰） | **0.2437** | 中等，勿 >0.35（会像施压） |
| plateau（盯住平顶基线） | **0.2385** | ≈ peak×(0.88～1.0×grip) |
| 盯住段 ripple（max−min） | **≈ 0.049** | 必须有；<0.02 像 flat；>0.08 像媚杀 |
| E(0) | 0 | |
| E(149) 尾值 | **≈ 0.036** | 慢收：约为 plateau 的 **15%** |

### 2.3 E(t) 抽样检查表（跑通必对）

| 帧 t | E(t) 约 | 阶段 |
|------|---------|------|
| 0 | 0.000 | 蓄力 |
| 18 | **0.244** | 峰 |
| 24～25 | **0.238** | 入盯住 |
| 50 | **0.225～0.263** 间振荡 | 脉冲中 |
| 92 | **0.227～0.263** 间振荡 | 脉冲中 |
| 110 | **0.238** | 盯住末 |
| 149 | **0.036** | 缓和尾 |

**全局阶段标签**（写入烘焙/节拍表）：`蓄力 → 启动 → 保持 → 缓和`。

## 3. 第三层 · 包络展开 12 通道（human_prior 前）

> 由同一 E(t) 耦合；下列为 **展开公式直接输出** 的名义值，供示意图/扩散读节奏。  
> 真人律会在扫视窗加过冲、在盯住加底噪，见 §5。

### 3.1 全局耦合参数（本条）

| 参数 | 值 | 来源 |
|------|-----|------|
| 视线方向 sign | **+1**（外放） | push≥50 |
| pupil_y 偏置 | **−0.12×E** | 略抬视线的耦合 |
| 眉滞后 lag | **≈ 9 帧** | speed 40 → lerp(12,6,0.4) |

### 3.2 关键帧名义值（验收用 · 允许 ±15% 浮动）

| 通道 | t=0 | t=25（盯住初） | t=50 | t=92 | t=149 |
|------|-----|----------------|------|------|-------|
| pupil_x | 0 | **0.24** | 0.23 | 0.23 | 0.04 |
| pupil_y | 0 | **0.17** | 0.16 | 0.16 | 0.03 |
| eyebrow | 0.04 | **0.25** | 0.28 | 0.28 | 0.12 |
| squint | 0.02 | **0.15** | 0.14 | 0.14 | 0.04 |
| blink | 0 | 0 | 0 | 0 | 0 |

### 3.3 独立眨眼事件（全片一次）

| 项 | **定稿** |
|----|----------|
| 中心帧 t_blink | **86**（≈2.87s） |
| 形状 | 0→0.11→0.14→0.08→0（5 帧窗） |
| 与魅惑关系 | **不绑** 起势峰；保持段内「真人轻眨」 |

扩散节拍表里 **blink** 在 t≈86 必须仍可读（Wan 唇颊节奏也会跟）。

## 4. 第四层 · 真人律 / 平庸（相对 §3 的方向，无数值表）

> 具体每帧由程序生成；本条只锁 **「改完应像什么」**，避免和施压搞反。

| 阶段 | human_prior 应呈现 | pulse_quality 应呈现 |
|------|-------------------|----------------------|
| 12～28 扫视窗 | 有过冲、回弹（speed 40 → 中等过冲） | 峰不过弱 |
| 25～110 盯住 | **底噪 + 脉冲保留**，非死线 | 尖刺不过多 |
| 眉 vs 眼 | 眉峰 **晚于** 眼动 onset ≥5 帧 | Q03 |
| 86 眨 | blink 脉冲保留 | 不与眉峰乱叠 |
| 媚/勾 | 盯住 **节奏型** 增强，不是开关颤 | — |

**禁止像**：盯住方差≈0（死线）、高速无过冲、眉眼同帧齐峰（施压/劣质 AI 感）。

## 7. 若要把「魅惑」再拧紧：建议动哪几个数

| 目标 | 优先改 | 预期连锁 |
|------|--------|----------|
| 脉冲更明显 | pulse_depth +8 | ripple ↑，勿超 0.08 |
| 更粘 | grip +8 | plateau ↑，尾收更慢感 |
| 更慢勾 | speed −8 | t_peak 后移，起更柔 |
| 更留韵 | outro +10 | E(149) 更高，尾更长 |
| 力太大像媚杀 | power −10 | peak_level ↓ |

改完 **只重跑 2→4→…** 或全链，用 §2.3 表对照是否仍像魅惑。
