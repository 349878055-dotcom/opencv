## 1. 核心对象

**一股 5 秒眼眉能量脉冲**（一条可量化信号）。

| 层 | 角色 |
|----|------|
| **滑杆** | 脉冲的 **唯一编辑接口**（0～100、`shape` 枚举） |
| **Python** | 滑杆 → 脉冲曲线 → 12 轨关键帧 |
| **5 秒容器** | 固定；脉冲在其中的形状可变 |

定义台 = **列出并验收：脉冲的每一维 ↔ 哪一根杆**。

---

## 2. 「覆盖所有眼眉表情」是什么意思

不是世界上每一个表情名各一根杆。

**可操作定义：**

> 在 **5 秒、12 轨、近景眼眉戏** 这个产品范围内，  
> 任意一种 **我们打算交付的脉冲形状**，都能用 `SliderPacket` **唯一量化**，  

| 算覆盖 | 不算覆盖 |
|--------|----------|
| 急起、猛、钉、泄、飘、一阵一阵、慢收、内收… | 明星脸复刻 |
| 平顶 / 脉冲 / 下泄 / 拱起 / 发颤 等花纹 | 嘴笑、全身、台词跟拍 |
| 两维组合（猛 + pulse） | 同一名词对应多根杆扯不清 |

**读全** = 上表 **脉冲维度** 都有键，且 **互不抢**（改 A 主要动 A，不全家乱抖）。

---

## 3. 正面覆盖表（操作台必须表达的脉冲维）

### 3.1 主脉冲（整条劲）

| 脉冲维 | 键 | 量化 |
|--------|-----|------|
| 上升沿陡缓 | `macro.speed` | 0～100 |
| 峰值力度 | `macro.power` | 0～100 |
| 方向（外放/内收） | `macro.push` | 0～100 |
| 下降沿快慢 | `macro.outro` | 0～100 |

### 3.2 平顶段（劲停住时）

| 脉冲维 | 键 | 量化 |
|--------|-----|------|
| 平顶 vs 往下淌 | `macro.grip` | 0～100 |
| 盯飘 vs 钉死 | `macro.steady` | 0～100 |
| 花纹类型 | `hold_seg.shape` | 5 枚举 |
| 脉冲疏密 | `hold_seg.pulse_rate` | 0～100（`pulse` 时） |
| 脉冲深度 | `hold_seg.pulse_depth` | 0～100（`pulse` 时） |
| 段内慢拱 | `hold_seg.swell` | 0～100（`swell` 等） |

```text
幅度
  ↑   起( speed,power,push ) — 动( shape,steady,grip,… ) — 收( outro )
  └──────────────────────────────────────────────────→ t
```

### 3.3 覆盖够了怎么办

- **够**：不再加杆；新「表情」= 上表 **数值组合**。  
- **禁止**：为每个表情名加杆；禁止 12 轨各一根。

### 3.4 可选后续（仍属量化）

若验收发现「动段占整条脉冲长短」也缺，可加 **1 根比例杆**（仍是一个 Packet）。**v1 先不默认有。**

## 4. 可量化编辑（定义台硬要求）

| 要求 | 说明 |
|------|------|
| 全是数或枚举 | 0～100；`shape` 五选一 |
| 右栏 JSON = 完整状态 | 无第二套隐藏状态 |
| 字段名固定 | `macro.*` `hold_seg.*` |
| 单键可验 | 只改一键，脉冲图 / 眼眉应 **主要变一处** |
| 可复现 | 同一 JSON → 同一 `02` |

**定义台 UI**：示意曲线 + 滑杆 + JSON；不为「好看」，为 **验收覆盖表 §3**。
