## 二、理论依据（Theory）

### E(t) 四段（本情绪共用公式，数值因滑杆而异）

```text
蓄力(0～t_peak) → 启动(t_peak～t_settle) → 保持(t_hold0～t_hold1) → 缓和(t_hold1～149)
```

- 实现：[`gaze_engine/_shared/envelope_compile.py`](../../../gaze_engine/_shared/envelope_compile.py) → `build_energy_envelope()`
- **本情绪**：peak=0.39562，t_peak=14，保持段 [25, 92]

### 滑杆 → E(t)

| 阶段 | 主要滑杆 |
|------|----------|
| 起 | push · power · speed |
| 盯住 | steady · grip · hold_seg |
| 收场 | outro |

人类 prior / 眉滞后见 `gaze_engine/human/human_prior.py`。

### PAD → 12 通道（与 E(t) 正交）

- PAD **不进** E(t) 公式；只参与 `compute_pad_scale()` → 各通道整段 scale。
- 实现：[`emotion_pad.py`](../../../gaze_engine/_shared/emotion_pad.py) · [`human/pad_weights.py`](../../../gaze_engine/human/pad_weights.py)
- **本情绪 PAD**：P=0.0，A=0.8，D=0.5 → 愉悦中性 · 高激活 · 偏支配/压人

## 三、为什么这样做（Why）

| 键 | 客户语义 | 备选方向 | 定稿 | 理由 |
|----|----------|----------|------|------|
| `push` | 往哪使劲 | 偏低 → 偏内收 / 偏高 → 偏外放 | **90** → 偏高 → 偏外放 | 🧠 与 JSON 同步 |
| `power` | 力度 | 偏低 → 偏轻 / 偏高 → 偏狠 | **92** → 偏高 → 偏狠 | 🧠 与 JSON 同步 |
| `speed` | 快慢 | 偏低 → 偏缓 / 偏高 → 偏急 | **98** → 偏高 → 偏急 | 🧠 与 JSON 同步 |
| `steady` | 盯得稳 | 偏低 → 偏飘 / 偏高 → 偏钉死 | **90** → 偏高 → 偏钉死 | 🧠 与 JSON 同步 |
| `grip` | 定得住 | 偏低 → 偏泄 / 偏高 → 偏憋住 | **86** → 偏高 → 偏憋住 | 🧠 与 JSON 同步 |
| `outro` | 收场 | 偏低 → 偏快落 / 偏高 → 偏慢收 | **10** → 偏低 → 偏快落 | 🧠 与 JSON 同步 |
| `hold.shape` | 盯住段纹理 | flat/pulse/tremble/… | **flat** | 平顶盯住 |
| `pad.P/A/D` | 通道性格 | 各轴 -1～1 | **(0.0, 0.8, 0.5)** | 🧠 与 JSON `pad` 同步；不改 E(t) |

⚠️ **历史教训**：同组情绪若 push/power/hold.shape 三者全同，门户与 02 烘焙无法区分 → 必须在本文件 §4.6 写清「别像谁」。

### 4.2 滑杆定稿

| 键 | 定稿值 | 范围 | L1 建议带 | 说明 |
|----|--------|------|-----------|------|
| `push` | **90** | 0～100 | 82～98 | 往哪使劲 |
| `power` | **92** | 0～100 | 84～100 | 力度 |
| `speed` | **98** | 0～100 | 90～100 | 快慢 |
| `steady` | **90** | 0～100 | 82～98 | 盯得稳 |
| `grip` | **86** | 0～100 | 78～94 | 定得住 |

> 人类预设无 `ear` 块。

### 4.3 PAD 定位（通道性格，与滑杆/E(t) 正交）

> **真源**：JSON `pad` 块 · 值域各 **[-1, 1]** · 客户调滑杆 **不改变** PAD。

| 轴 | 定稿值 | 空间定位 | 主要通道倾向 |
|----|--------|----------|--------------|
| **P** 愉悦度 | **0.0** | 居中 → 中性 | 吃 P 权重：`eye_gloss` · `squint` · `pupil_scale` |
| **A** 激活度 | **0.8** | 偏高 → 偏急/警觉 | 吃 A 权重：`pupil_x/y` · `lid_upper` · `cornea_bulge` |
| **D** 控制度 | **0.5** | 偏高 → 偏支配/压人 | 吃 D 权重：`eyebrow`（人类 D 负权）· `brow_raise` |

**一句话定位**：愉悦中性 · 高激活 · 偏支配/压人

**通道投影 hint**（🧠 近似）：`pupil_x↑ · pupil_y↑ · lid_upper↑ · eyebrow压↓`

**物种映射**：人类：`eyebrow` 的 D 权重为负 → 高 D 时眉压下（拒/压）；`eye_gloss` 吃 P。

公式（全物种共用，权重见 `human/pad_weights.py`）：

```text
scale[ch] = base[ch] + P×Wp + A×Wa + D×Wd
pulse[ch,t] = E[t] × scale[ch]   // 品种/style 叠在 pulse 之后
```

### 4.4 能量包络 E(t)

| 指标 | 值 | 说明 |
|------|-----|------|
| peak_level | **0.39562** | 全轨峰值 |
| t_peak | **14** | 蓄力结束 |
| t_settle | **18** | 启动结束 |
| t_hold0 / t_hold1 | **25** / **92** | 保持段 |
| E[0] / E[149] | **0.0** / **0.0** | 起/收 |
| 保持段 E | **0.3890 ~ 0.3890** | hold 纹理 |

### 4.5 观众读感（🧠 待审）

- 资产 note：**极急、快收**。
- 视线/情绪 **面向外放**，有压向镜头或对方的倾向。
- 整体 **能量偏高**，盯住段硬，不宜像发呆或困倦。
- 保持段 **平顶高 grip**，钉住不放。
- 起势 **偏急**，戏眼来得快。

### 4.6 避免混淆（🧠 待审）

| 别像 | 区分要点 |
|------|----------|
| 施压·凝视 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 冷压·决心 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 怒视·压人 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
