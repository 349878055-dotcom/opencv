## 二、理论依据（Theory）

### E(t) 四段（本情绪共用公式，数值因滑杆而异）

```text
蓄力(0～t_peak) → 启动(t_peak～t_settle) → 保持(t_hold0～t_hold1) → 缓和(t_hold1～149)
```

- 实现：[`gaze_engine/_shared/envelope_compile.py`](../../../gaze_engine/_shared/envelope_compile.py) → `build_energy_envelope()`
- **本情绪**：peak=0.24381，t_peak=14，保持段 [25, 92]

### 滑杆 → E(t)

| 阶段 | 主要滑杆 |
|------|----------|
| 起 | push · power · speed |
| 盯住 | steady · grip · hold_seg |
| 收场 | outro |

人类 prior / 眉滞后见 `gaze_engine/human/human_prior.py`。

### PAD → 12 通道（与 E(t) 正交）

- PAD **不进** E(t) 公式；只参与 `compute_pad_scale()` → 各通道整段 scale。
- 实现：[`emotion_pad.py`](../../../gaze_engine/_shared/emotion_pad.py) · [`human/pad_weights.py`](../../../gaze_engine/human/pad_weights.py)
- **本情绪 PAD**：P=-0.4，A=0.7，D=-0.3 → 偏不悦/压抑 · 高激活 · 控制中性

## 三、为什么这样做（Why）

| 键 | 客户语义 | 备选方向 | 定稿 | 理由 |
|----|----------|----------|------|------|
| `push` | 往哪使劲 | 偏低 → 偏内收 / 偏高 → 偏外放 | **38** → 偏低 → 偏内收 | 🧠 与 JSON 同步 |
| `power` | 力度 | 偏低 → 偏轻 / 偏高 → 偏狠 | **58** → 偏高 → 偏狠 | 🧠 与 JSON 同步 |
| `speed` | 快慢 | 偏低 → 偏缓 / 偏高 → 偏急 | **96** → 偏高 → 偏急 | 🧠 与 JSON 同步 |
| `steady` | 盯得稳 | 偏低 → 偏飘 / 偏高 → 偏钉死 | **58** → 偏高 → 偏钉死 | 🧠 与 JSON 同步 |
| `grip` | 定得住 | 偏低 → 偏泄 / 偏高 → 偏憋住 | **42** → 偏低 → 偏泄 | 🧠 与 JSON 同步 |
| `outro` | 收场 | 偏低 → 偏快落 / 偏高 → 偏慢收 | **14** → 偏低 → 偏快落 | 🧠 与 JSON 同步 |
| `hold.shape` | 盯住段纹理 | flat/pulse/tremble/… | **tremble** | 长保持微颤 |
| `pad.P/A/D` | 通道性格 | 各轴 -1～1 | **(-0.4, 0.7, -0.3)** | 🧠 与 JSON `pad` 同步；不改 E(t) |

⚠️ **历史教训**：同组情绪若 push/power/hold.shape 三者全同，门户与 02 烘焙无法区分 → 必须在本文件 §4.6 写清「别像谁」。

### 4.2 滑杆定稿

| 键 | 定稿值 | 范围 | L1 建议带 | 说明 |
|----|--------|------|-----------|------|

| `speed` | **96** | 0～100 | 88～100 | 快慢 |

> 人类预设无 `ear` 块。

### 4.3 PAD 定位（通道性格，与滑杆/E(t) 正交）

> **真源**：JSON `pad` 块 · 值域各 **[-1, 1]** · 客户调滑杆 **不改变** PAD。

| 轴 | 定稿值 | 空间定位 | 主要通道倾向 |
|----|--------|----------|--------------|
| **P** 愉悦度 | **-0.4** | 偏低 → 偏不悦/压抑 | 吃 P 权重：`eye_gloss` · `squint` · `pupil_scale` |
| **A** 激活度 | **0.7** | 偏高 → 偏急/警觉 | 吃 A 权重：`pupil_x/y` · `lid_upper` · `cornea_bulge` |
| **D** 控制度 | **-0.3** | 居中 → 中性 | 吃 D 权重：`eyebrow`（人类 D 负权）· `brow_raise` |

**一句话定位**：偏不悦/压抑 · 高激活 · 控制中性

**通道投影 hint**（🧠 近似）：`eye_gloss↓ · pupil_x↑ · pupil_y↑ · lid_upper↑`

**物种映射**：人类：`eyebrow` 的 D 权重为负 → 高 D 时眉压下（拒/压）；`eye_gloss` 吃 P。

公式（全物种共用，权重见 `human/pad_weights.py`）：

```text
scale[ch] = base[ch] + P×Wp + A×Wa + D×Wd
pulse[ch,t] = E[t] × scale[ch]   // 品种/style 叠在 pulse 之后
```

### 4.4 能量包络 E(t)

| 指标 | 值 | 说明 |
|------|-----|------|
| peak_level | **0.24381** | 全轨峰值 |
| t_peak | **14** | 蓄力结束 |
| t_settle | **18** | 启动结束 |
| t_hold0 / t_hold1 | **25** / **92** | 保持段 |
| E[0] / E[149] | **0.0** / **0.0** | 起/收 |
| 保持段 E | **0.2164 ~ 0.2373** | hold 纹理 |

### 4.5 观众读感（🧠 待审）

- 资产 note：**急、中力、颤、快收**。
- 保持段有 **细颤**，避免 5 秒铁板同一帧。
- 起势 **偏急**，戏眼来得快。

### 4.6 避免混淆（🧠 待审）

| 要哭未哭 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 崩溃·泄劲 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
