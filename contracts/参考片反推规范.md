## 1. 在流水线中的位置

```text
参考片.mp4（约 5s / 30fps）
    │
    ├─【反推】ffmpeg 拆 150 帧 → MediaPipe 眼眉估计 → 03 稠密
    │                    └→ RDP+峰谷收缩 → 02_候选
    │
    ├─【人审】对照原片改候选（过冲、眉慢于眼、轻眨…）
    │
    ├─【采纳】02_候选 → 02_眼眉稀疏指令.json（备份旧版）
    │
```

**不做的事**：反推结果 **不自动覆盖** `02`；反推 **不替代** §2 真人感条款的手动裁定（过冲幅度、眉峰延后等）。

## 4. 十二通道：反推怎么估（与 §0.5 一一对应）

所有通道键名以 `gaze_engine/channel_contract.py` 为准。

| 通道 | 中文 | 从片子的估计方式 | 可靠度 |
|------|------|------------------|--------|
| `pupil_x` | 视线左右 | 双眼虹膜中心相对眼眶水平偏移；可选 `ECURSOR_INFER_FLIP_X=1` 修正符号 | 高 |
| `pupil_y` | 视线上下 | 虹膜相对眼眶垂直偏移；标定为 **负值 = 下沉** | 高 |
| `blink` | 眼睑开合 | 双眼 EAR（纵横比）；闭合↑ | 高 |
| `eyebrow` | 眉压 | 眉点与上睑距离 | 中高 |
| `pupil_scale` | 瞳孔缩放 | 虹膜宽度 / 眼宽 | 中 |
| `iris_scale` | 虹膜圈 | 同虹膜宽度代理（略缩比例） | 中 |
| `squint` | 眯眼眶压 | 眼眶收窄（EAR 偏小但未全闭） | 中 |
| `brow_raise` | 挑眉 | 眉区相对额部高度；本戏常接近 0 | 中 |
| `lid_upper` | 上眼睑 | 上睑–虹膜上缘距离 | 中 |
| `lid_lower` | 下眼睑 | 虹膜下缘–下睑距离 | 中 |
| `cornea_bulge` | 角膜鼓起 | **代理**：虹膜显露 × 睁眼度 | 低（需人审） |
| `eye_gloss` | 湿润高光 | **代理**：眼眶 ROI 亮度分位 | 低（需人审） |

**不估计的内容**：嘴型、`smile`、下颌、全身、背景、头大幅转动（转动会污染视线代理，故推荐 **脸部特写** 参考片）。

**实现注**：检测器为 MediaPipe Face Mesh（`refine_landmarks=True`，含虹膜点）；只在眼眉相关 landmark 与眼部 ROI 上计算。

## 5. 反推算法（两阶段）

### 5.1 阶段 A：稠密（150 帧 × 12 通道）

1. `ffmpeg` 拆帧 → `参考/_frames_cache/f_%04d.png`（默认跑完删除）。  
2. 每帧人脸检测；失败帧 **前向填充** 上一有效帧。  
3. 逐通道原始标量 → **基线扣除**（默认前 12 帧中位数）→ **按 S01 峰值量级归一化**（见 `video_infer_ref._CALIB`）。  
4. 写出 `03_逐帧反推.json`：

```json
{
  "schema_version": "0.2-dense-inferred",
  "provenance": "video_infer_ref",
  "fps": 30,
  "frame_count": 150,
  "keys": [ "pupil_x", "…", "eye_gloss" ],
  "channels": {
    "pupil_x": [ 0.0, 0.01, "…共150个" ],
    "…": []
  }
}
```

### 5.2 阶段 B：稀疏收缩（→ `02_候选`）

对 **每一通道** 独立：

1. 5 点滑动平均平滑；  
2. **Ramer–Douglas–Peucker** 简化曲线；  
3. 强制保留 **局部峰/谷**（过冲、回弹、轻眨尖峰）；  
4. `blink` 通道：仅保留基线 + 超过阈值的眨峰（及前后各 3 帧）；  
5. 每点写入 `t`, `v`, `phase`, `easing`（与 contract §3.1 同形）；  
6. `phase` 由时间轴推断：默认 `0蓄力 / 12启动 / 25保持 / 120缓和`，启动起点可依 `pupil_x` 首次偏离微调。

**`easing` 指派（收缩器启发式）**：

| 条件 | easing |
|------|--------|
| 短段（≤6 帧）且变化大 | `ease_out_expo` |
| 短段变化小 | `linear` |
| 其余 | `smoothstep` |

收缩后 **不保证** 自动满足 §2.2 过冲/眉慢于眼；**人审必须对照原片** 补点或改 `v`。

### 5.3 元数据从哪来

`02_候选` 的 `gaze_emotion_id`、`mood`、`energy_phases`、`micro_jitter` 等：从 **当前正式 `02`** 复制，仅替换 `channel_tracks` 与 `inference_meta`。  
**禁止** 用旧 `02` 的通道数值填进候选。

## 6. 参考片从哪来、怎么截

### 6.1 你可以直接说 YouTube + 时间段（推荐）

在对话里发：

```text
链接: https://www.youtube.com/watch?v=……
从 1:23 到 1:28
```

或在项目根执行（已装 `yt-dlp` + `ffmpeg`）：

```bash
./scripts/s01_从YouTube截取参考片.sh "URL" "1:23" "1:28"
./scripts/s01_从YouTube截取参考片.sh "URL" "1:23" "1:28" --infer
```

产出：`参考/参考片.mp4`（规范为 5s / 30fps）+ `参考片_来源.txt` 记录 URL。

### 6.2 自己找片时的原则

| 要 | 不要 |
|----|------|
| **脸部特写**（眼眉占画面大） | 全身远景、脸小于画面 1/4 |
| 眼神戏清晰、光线均匀 | 强模糊、大侧脸、墨镜遮挡 |
| **约 5～8 秒** 含完整一眼戏（静→甩眼→盯住） | 只有 1 秒或整段 30 秒不剪 |
| 固定机位或缓推 | 快速摇镜、硬切 |

**去哪找**：正版片源 / 你已购买的媒体；YouTube 上常有预告、访谈特写、4K 修复片段（注意版权仅用于你的内部创作与验收）。搜索词示例：`林青霞 东方不败 眼神`、`Brigitte Lin Swordsman eye` + `close up`。

不清晰时：**换一段更近的镜头**，比强行反推糊片更有效。

## 8. 审定与验收（必须做）

### 8.1 候选合格线（采纳前）

对照 `全量帧指令集规范.md` §3 与本文 §2：

- [ ] `channel_tracks` **12 轨齐全**，每轨 ≥2 点，第 2 点起有 `easing`  
- [ ] `pupil_x/y` 启动段有 **过冲 + 回弹**（曲线或稀疏点）  
- [ ] `eyebrow` 峰 **不早于** 眼线到位（眉慢于眼，约晚 10～15 帧）  
- [ ] `blink` 盯住段 **至多轻眨 1 次**（除非片子确实多次）  
- [ ] `keys_active` 列满 12 项；`micro_jitter` 块完整  

### 8.2 采纳后验收

```bash
./scripts/s01_采纳候选指令.sh
./scripts/s01_主验收示意图.sh          # 四通道主图 + 12 通道参考图
./scripts/s01_参考十二通道.sh          # 可选：12 通道全轨 PNG
./scripts/s01_导出扩散节拍表.sh
```

## 10. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 人脸检测失败 | 脸太小、侧脸、遮挡 | 换特写；提高片源分辨率 |
| 视线方向反 | 镜像 / 摄影机朝向 | `ECURSOR_INFER_FLIP_X=1` 或手改 `pupil_x` 符号 |
| 眉峰与眼同帧 | 收缩器不懂「戏」 | 手改 `eyebrow` 时间点，延后 10～15 帧 |
| `eye_gloss` 乱飘 | 亮度代理 | 手改或按 `02` 旧节奏重打 |
