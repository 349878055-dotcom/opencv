# contracts 索引

> **合同规范**：所有 contracts 文件必须遵循 [`合同规范.md`](合同规范.md) 的统一五段格式 —
> **概述（What）→ 理论依据（Theory）→ 为什么这样做（Why）→ 怎么实现（How）→ 检查点（Checkpoints）**
>
> 每个合同都要求"有依据"：每个设计决策必须追溯到物理/数学/上游约束，不接受无依据的决策。
