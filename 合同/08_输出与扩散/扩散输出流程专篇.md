## 一、Wan 实际吃几路

```text
① start_image.jpg      → 身份（参考图）
② 03_工程底模.mp4      → 眼眉几何（像素控制）
③ ## 扩散节拍表       → 每通道关键帧语义（导演指令）
④ wan_positive         → 正向 + ③ + ## 叙事
⑤ wan_negative         → 负向禁区
```

| 缺什么 | 后果 |
|--------|------|
| 仅 MP4 | 形状对，情绪方向可能错 |
| 仅文本 | 有故事，眉眼节奏不可控 |
| ②③ revision 不一致 | 节拍与像素对不上 |

**02 JSON 不送 Wan** — 只作机器真源；节拍表 **只许** `rhythm_compiler` 从 02 生成。

命名：正式叫 **扩散节拍表** / **节奏说明书**；口语「导演指令」= 同物。

## 二、04 五段与 Wan 拆分

### 2.1 五段结构

| 段 | 来源 | 动态/固定 |
|----|------|-----------|
| 文件头 | assembler 元信息 | 动态 |
| `## 正向 Prompt` | 品种/情绪 + `EMOTION_VISUAL_PROMPTS` + 「跟随控制序列」 | 动态 |
| `## 扩散节拍表` | `build_metronome_text(02)` 全文 | 动态 |
| `## 叙事` | `customer_action` 原文 | 动态 |
| `## 负向 Prompt` | 模板 + `NEGATIVE_EXTRA` | 大半固定 |

正向推荐三层：`[L1]` 品种/质感 → `[L2]` 情绪视觉词 → `[L3]` 严格跟随控制序列。  
负向：**不含**节拍表、叙事。

### 2.2 `split_for_wan`

```python
clips = DiffusionPromptAssembler.split_for_wan(prompt_04)
# wan_positive = 正向 + 空行 + 扩散节拍表 + 空行 + 叙事
# wan_negative = 负向段全文
```

| 04 段 | wan 去向 |
|-------|----------|
| 正向 | `wan_positive` 段 1 |
| 扩散节拍表 | `wan_positive` 段 2 |
| 叙事 | `wan_positive` 段 3 |
| 负向 | `wan_negative` 全文 |
| （MP4 不在 04） | `control_video` |

## 三、门户流程（推荐顺序）

```text
① POST /api/portal/pomot/round1   → 02 + 04 + wan±（无 MP4）
② POST /api/portal/save            → 落盘 01/02/04
③ POST /api/portal/render-preview  → 可选，仅 03_工程底模.mp4
④ POST /api/portal/export          → 03 + 04 + wan± + 扩散引擎包/
```

| API | 产出 |
|-----|------|
| `pomot/round2` | 同 round1，delta 后重编 02/04 |
| `archive` | 可选打包，可不重渲 |

**原则**：MP4 渲染贵 → **export 时**再渲+打包；`assembler` **不渲染**。

`export` body 要点：`customer_id`, `project_id`, `baked`（02 全文）, `action`, `species`, `breed`, `emotion`。

## 四、扩散引擎包

路径：`客户资产库/客户_{cid}/项目_{pid}/输出/扩散引擎包/`

| 文件 | Wan |
|------|-----|
| `03_工程底模.mp4` | control_video |
| `04_Prompt.txt` | 归档全文 |
| `wan_positive.txt` | positive CLIP |
| `wan_negative.txt` | negative CLIP |
| `start_image.jpg` | start_image |
| `manifest.json` | `ready_for_diffusion` |

```json
{
  "schema": "diffusion_bundle_v1",
  "ready_for_diffusion": true,
  "usage": "start_image + 03 MP4 + wan± → Wan Fun Control"
}
```

### 4.1 端到端（export 内）

```text
02 + action + 元信息
  → assembler.assemble() → 04
  → split_for_wan() → wan±
  → _render_opencv_video() → 03
  → build_diffusion_bundle() → 扩散引擎包/
```

### 4.2 MP4 像素约定（摘要）

| 色 | 解剖 |
|----|------|
| R | 眼睑 blink/squint/lid |
| G | 眉/耳 eyebrow/brow_raise |
| B | 瞳孔 pupil/iris |

详见 [`工程底膜合同.md`](../07_工程底膜/工程底膜合同.md)。

### 4.3 revision

`02.revision` == `03.meta.baked_revision` == 04 文件头；改 02 后必须 **re-export**。
