# 双质量标准 — 不要假 · 不要平庸

> **本文件 = S6 先验 + S7 质检的跨物种总纲**  
> **产品一句话**：成片眼区要 **像真的在演**（不要假），又要 **有戏劲不发蔫**（不要平庸）。  
> **状态**：人类 S6+S7 ✅ 已落地 · 狗 S6 部分 + S7 底线 ✅ · 猫 🔧 规划中

**兄弟合同**：[`00_先验质检导读.md`](00_先验质检导读.md) · [`04_通道与先验/眼眉真人默认律.md`](../04_通道与先验/眼眉真人默认律.md) · [`08_架构与验收/5秒气质精品成片合同.md`](../08_架构与验收/5秒气质精品成片合同.md)

## 一、概述（What）

### 1.1 本合同管什么

| ✅ 管 | ❌ 不管 |
|------|--------|
| **不要假**：生理/物种先验（prior）的验收定义与理论链 | S0–S5 滑杆、PAD、E(t)、品种偏移 |
| **不要平庸**：pulse_quality / QC 的验收定义与理论链 | 工程底膜 MP4 几何标定（见 `06_工程底膜`） |
| 人 / 狗 / 猫 **统一双标准** 与代码映射 | 04 Prompt 文案、Wan 采样参数 |
| S6→S7 **顺序** 与 A/B 对照方法 | 端到端「靠扩散修眼」 |

### 1.2 管线位置

```text
S5 styled（12×150）
    ↓
★ S6 prior   — 真实性层：补生理与物种行为，消除「数学插值感」
    ↓
★ S7 QC      — 表演力层：抬能量、清主次、防乱抖，消除「发蔫/打架」
    ↓
final → 02 烘焙 → 03 底膜 → 04 扩散
```

**硬顺序**：必须先 S6 再 S7。先验把曲线「弄活」，质检把曲线「弄有戏」；颠倒则 QC 会在死曲线上做无效放大，或 prior 把已抬的能量再次打乱。

### 1.3 双标准对照（产品 ↔ 工程）

| 产品标准 | 典型失败观感 | 工程层 | 主要模块 |
|----------|--------------|--------|----------|
| **不要假** | 匀速滑移、死盯、眉眼同动、像面具/像模型 | **S6 prior** | `human_prior` / `apply_dog_prior` / `apply_cat_prior` |
| **不要平庸** | 戏太弱、盯住发蔫、保持段乱尖刺、主次不清 | **S7 QC** | `fix_pulse_quality` / `fix_dog_pulse_quality` |

两者 **正交**：可以「真但蔫」（prior 开、QC 关）或「假但有劲」（prior 关、QC 强抬）—— **合格成片必须两者同时过线**。

## 二、理论依据（Theory）

### 2.1 理论依据链（总）

```text
① 社交注意力：>80%「有没有气质」来自眼区 + 时序（5秒气质合同）
        ↓
② 恐怖谷 / 似人度：外观与运动学不匹配 → 不适；眼区是判「像不像真」的第一特征
        ↓
③ 眼动生理学：扫视有过冲与纠正；盯住非静止（微扫视/漂移）— 缺则「死鱼眼」
        ↓
④ 拉班 Effort：Weight·Time·Space·Flow 描述「怎么用力」— 塌缩=平庸，Flow 失控=乱
        ↓
⑤ Beat / ensemble：同一表演里主钟与从属通道有时差 — 眉眼同帧=假
        ↓
⑥ 动物 FACS：犬猫眼—耳—睑为可编码动作单元，耳位是猫狗社交信号主特征之一
        ↓
⑦ 工程约束：Wan 吃 03 像素轨迹 — 假/蔫必须在 02 数值层修，不能押 Prompt  alone
```

### 2.2 「不要假」— 真实性与表演生理

#### 2.2.1 眼动动力学（人类 & 哺乳动物共性）

| 现象 | 权威描述 | 本工程映射 |
|------|----------|------------|
| **扫视过冲** | 快速眼动常越过目标，随后纠正（Bahill & Stark, 1975；corrective saccades 50–300ms 内） | `human_prior` 欠阻尼二阶系统；`speed`↑ → ζ↓ → 过冲↑ |
| **盯住非静止** | Fixation 期间持续 microsaccades + drift，非数学平线（Martinez-Conde et al.; PMC4537412） | 盯住窗 8–14Hz 等效微颤 + 相关微漂 |
| **微扫视与自然度** | 缺 microsaccadic jitter 被一致判为 **最不自然**；1/f pink noise 接近录眼数据（Duchowski et al., 2015） | `micro_jitter` + prior 底噪；扫视窗 **关闭** 大颤 |

#### 2.2.2 恐怖谷与外观—运动匹配

| 要点 | 来源 | 设计约束 |
|------|------|----------|
| 外观与 **motion kinematics** 须匹配；仅外观真、运动假 → 不适 | Mori, 1970；Wikipedia / SciDirect Uncanny Valley | 近景 I2V 脸 + 02 轨迹必须同源 revision |
| 观者 **优先看眼、鼻** 判 humanness | Cheetham et al., 2011 (PMC3590815)；ETRA 2025 眼动研究 | 质检聚焦 `pupil_*` / `blink` / `eyebrow` |
| 只动画 voluntary 眼动、缺 involuntary → 「假人感」 | SciDirect 数字人章节 | prior **默认注入** 非滑杆开关的底噪 |

#### 2.2.3 通道 ensemble（眉眼分工）

| 要点 | 依据 | 本工程 |
|------|------|--------|
| 眉动晚于眼动 | 面部运动神经传导 + 动画 Finaling 惯例 | 眉峰 ≥ 眼动 onset **+5 帧**（Q03） |
| 12 轨同一人 | Laban Body + Shape：同一 inner intention 驱动多部位 | 能量标量耦合 squint/scale/lid |

#### 2.2.4 犬猫物种先验

| 要点 | 依据 | 本工程 |
|------|------|--------|
| **DogFACS / CatFACS** | 客观编码眼、耳、睑 AU/EAD，不臆测情绪标签（Waller et al.; animalfacs.github.io） | 耳位注入 `channel_adapter` + prior 微跟 |
| 狗 **内眉上抬 AU101** | 驯化后与狼相比更频繁，人读为「幼态/乞怜」（Paedomorphic facial expressions, PLoS ONE 2013） | `eyebrow` / ear 与 pupil 扫视耦合 |
| 猫 **耳位** 为猫—猫互动最强预测特征 | Quaranta et al., Animals 2021 | 耳通道与 pupil 不同相；prior 禁止全脸 sync |
| 眨眼 | 哺乳动物润滑 + 社交信号；全零 blink = 明显假 | 狗 `fix_dog_pulse_quality` blink 锚点补脉冲 |

### 2.3 「不要平庸」— 表演力与 Effort

#### 2.3.1 拉班 Effort 四因子

Laban Movement Analysis 用 **Weight / Time / Space / Flow** 描述动作 **质感**（inner intention 的外显），不是位移本身（Laban, 1940s；Bartenieff/LMA 文献）。

| Effort 因子 | 两极 | 对应失败观感 | 本工程 QC |
|-------------|------|--------------|-----------|
| **Weight** 力 | Strong ↔ Light | 戏太弱、峰弱、盯住瘪 | **Q01** 能量不够 |
| **Time** 时 | Sudden ↔ Sustained | 起势弱、扫视像匀速滑块 | **Q01** 起势斜率 + prior 扫视窗 |
| **Space** 空 | Direct ↔ Indirect | 动态范围小、只有单轴抖 | **Q01** range + PAD 通道分配 |
| **Flow** 流 | Bound ↔ Free | 保持段尖刺过多或该 bound 时 free | **Q02** 保持段杂乱 |

#### 2.3.2 Beat 与主次（Q03）

| 概念 | 说明 | QC |
|------|------|-----|
| **Beat** | 动作单元有起—峰—收；多通道须分主次 | 眼=主钟，眉=从属 |
| **Effort 不纯** | 两部位抢同一 beat → 「打架、像面具」 | **Q03** 眉峰不晚于眼 → 自动延后 eyebrow |

#### 2.3.3 与「气质」合同的关系

[`5秒气质精品成片合同.md`](../08_架构与验收/5秒气质精品成片合同.md) 定义：**气质 = 眼神有戏 + 节奏对 + 像自己的脸 + 成片不丢人**。  
本双标准是其 **数值层分解**：

- **不要假** → 「像自己的脸 / 像活的」在 02 轨迹上的底线  
- **不要平庸** → 「眼神有戏 / 节奏对」在 02 轨迹上的底线

## 三、为什么这样做（Why）

### 3.1 关键决策

| 决策 | 备选 | 选择理由 |
|------|------|----------|
| **双阶段 S6+S7** | 合并为一个模块 | 真实性（生理）与表演力（戏劲）机制不同；合并难 A/B |
| **prior 默认全开** | 用户滑杆控制「要不要颤/过冲」 | 用户只对 **戏意** 负责；生理是出厂设置（见真人默认律） |
| **QC 可自动修** | 只报不修 | 平庸多来自 envelope 标量偏低，×scale 比改 Prompt 便宜且可复现 |
| **QC 在 prior 之后** | QC 在前 | 先抬能量再注入 jitter 会 mask 过冲；先 prior 再 QC 顺序稳定 |
| **不用扩散修眼** | Wan 后处理 | 03 已锁像素轨迹；02 不合格 → 03 必假或必蔫 |

### 3.2 历史教训 ⚠️

| 坑 | 现象 | 规则 |
|----|------|------|
| 关 prior 直接烘焙 | 数学滑、死盯、高速无过冲 | **禁止** 绕过 S6 定稿（`ECURSOR_HUMAN_PRIOR=0` 仅 A/B） |
| 只抬单轨 pupil_x | 眼动大、脸其他部位死 | Q01 抬 **主能量通道组**（pupil/眉/squint/lid…） |
| hold=tremble 当「正常人开关」 | 该颤不该颤 | 正常人颤在 prior；`tremble` 仅异常加强 |
| 狗 blink 全零 | 5 秒不眨 → 恐怖谷 | S7 强制 blink 锚点（49/91/132） |
| 猫狗 QC 空壳 | 只有人类有三检 | 本目录 **猫狗专篇** 对齐人类 Q01–Q03 语义 |

## 四、怎么实现（How）

### 4.1 物种实现矩阵

| 物种 | S6 prior | S7 QC | 状态 |
|------|----------|-------|------|
| **人** | `human/human_prior.py` → `_shared/oculomotor_prior` | `human/pulse_quality.py` → `_shared/pulse_quality_core` | ✅ |
| **狗** | `dog/prior.py` + 叙事回头 | `dog/pulse_quality.py` Q01–Q03 + blink | ✅ |
| **猫** | `cat/prior.py` + 第三眼睑 | `cat/pulse_quality.py` Q01–Q03 + blink | ✅ 常数待审 |

**交付链入口**：`gaze_engine/delivery_pipeline.py` → 物种 `*_pipeline.py` / `run_delivery()`

### 4.2 人类 S6 — 不要假（摘要）

| 模块 | 输入 | 行为 | 常量窗 |
|------|------|------|--------|
| 扫视动力学 | `speed` → ζ, ω | 欠阻尼二阶 rewrite `pupil_x/y` | t≈12–28 |
| 盯住活劲 | `power`, `steady`, `hold_seg.shape` | 微漂+微颤；shape 叠 rhythm | t≈25–110 |
| 通道耦合 | 能量标量 | 眉晚 8–15 帧；scale/lid 跟随 | 全段 |
| 微颤引擎 | `micro_jitter` | 扫视窗关闭大颤 | 见 prior 报告 |

详见 [`人_眼眉先验与平庸三检.md`](人_眼眉先验与平庸三检.md)、[`眼眉真人默认律.md`](../04_通道与先验/眼眉真人默认律.md)。

### 4.3 人类 S7 — 不要平庸（Q01–Q03）

| 编号 | 检测语义 | Effort 映射 | 自动修正 | 阈值来源 |
|------|----------|-------------|----------|----------|
| **Q01** | 峰弱 / range 小 / 起势弱 / 盯住瘪 | Weight+Time 塌缩 | 主能量通道 ×scale（≤1.42） | `reference_targets(packet)` ← macro |
| **Q02** | flat/decay 保持段尖刺或起伏过大 | Flow 失控 | 盯住窗 MA 轻平滑 pupil_x/y | `hold_spike_max`, `hold_std_hi` |
| **Q03** | 眉峰不晚于眼 | Beat 主次反了 | eyebrow 延后 3–12 帧 | `brow_lag_min` ≥ 5 |

**日记字段**：`_pulse_quality_fix_log`、`_pulse_quality_remaining`、`pulse_quality_report`

### 4.4 狗 S6+S7 — 已实现

见 [`狗_先验与质检.md`](狗_先验与质检.md)：通用 `DOG_PRIOR_CONFIG` + 叙事回头 + `DOG_QC_CONFIG` Q01–Q03 + blink。

### 4.5 猫 S6+S7 — 已实现（常数待 P1 审）

见 [`猫_先验与质检.md`](猫_先验与质检.md)：`CAT_PRIOR_CONFIG`（第三眼睑 + 高 jitter）+ `CAT_QC_CONFIG`。

### 4.6 与滑杆的关系（再次强调）

```text
macro.power / speed / push / steady / hold_seg  →  期望能量 & 节奏型（戏意）
prior                                           →  生理默认值（不要假）
QC                                              →  相对期望的底线修正（不要平庸）
```

用户 **不** 配置：过冲%、颤动 Hz、眉延迟帧数。

## 五、检查点（Checkpoints）

### 5.1 P0 — 自动（程序）

| 检查项 | 物种 | 测试方法 | 合格标准 | 优先级 |
|--------|------|----------|----------|--------|
| S6 扫视过冲 | 人 | `prior_report.overshoot_ratio_px` | speed 高 > speed 低 | P0 |
| S6 盯住方差 | 人 | 盯住窗 std | ε < std < 人格上限 | P0 |
| S6 眉延迟 | 人 | brow_lag_frames | ≥ 5 | P0 |
| S7 Q01–Q03 | 人 | `diagnose_dense()` | `_pulse_quality_remaining` 空 | P0 |
| S7 blink 下限 | 狗 | `fix_dog_pulse_quality` | peak≥0.05 或补锚点 | P0 |
| 12×150 无 NaN | 全物种 | `validate_baked_delivery` | 1800 keyframes 合法 | P0 |

**命令**：

```bash
python3 scripts/verify_dog_150_compile_contract.py
python3 scripts/verify_diffusion_prompt_contract.py
```

### 5.2 P1 — 感官（人工精品线）

| 检查项 | 测试方法 | 合格标准 | 优先级 |
|--------|----------|----------|--------|
| **A/B 不要假** | 同 preset：关 prior vs 开 prior 盲看 03 | 开：有撞击/活劲；关：滑块感 | P1 |
| **A/B 不要平庸** | 关 QC vs 开 QC 盲看 | 开：同 macro 更有戏；关：易蔫 | P1 |
| **五连样本** | 5 个 seed 同情绪 | 像「同一个人/同一只」 | P1 |
| **气质三联** | 03+04+参考图 → Wan | 连续 3 次过 §5.2 精品（5秒气质合同） | P1 |
| **跨物种** | 人/狗/猫各 1 条 | 失败标签须可归因到「假」或「平庸」 | P1 |

### 5.3 失败归因表

| 观感 | 先查 | 再查 |
|------|------|------|
| 像 CG、匀速、死盯 | S6 prior 是否跳过 | micro_jitter / 扫视 ζ |
| 有动但没戏 | macro.power / Q01 | PAD 是否选对 preset |
| 盯住乱抖 | hold_seg.shape vs Q02 | tremble 是否误开 |
| 眉眼一起动 | Q03 / prior 耦合 | envelope 是否单轨插值 |
| 5 秒不眨眼 | 狗 S7 blink | S4 `_dog_blink_series` |
| 像别种情绪 | S1 PAD / S4 分支 | **不是** QC 首要背锅 |
