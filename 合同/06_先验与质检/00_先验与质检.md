## 一、5 秒读懂

```text
styled（S5 风格化后 12×150）
    │
    ▼ S6  先验 prior          →  不要假：像真眼、真扫视、真活劲
    ▼ S7  质检 pulse_quality  →  不要平庸：有戏劲、主次清、不乱
    │
    ▼ final → 02 烘焙 → 工程底膜 → 扩散
```

**两条质量标准**（产品语言）：

| 标准 | 观众会说 | 工程对应 |
|------|----------|----------|
| **不要假** | 「像活的 / 像真人」 | prior：过冲、微颤、延迟、眉眼耦合 |
| **不要平庸** | 「有戏 / 有劲 / 不是死鱼眼」 | QC：Q01 能量 · Q02 保持 · Q03 主次 |

**硬顺序**：必须先 S6 再 S7。先验把曲线「弄活」，质检把曲线「弄有戏」；颠倒则 QC 会在死曲线上做无效放大，或 prior 把已抬的能量再次打乱。

## 三、人类 S6 — 不要假（先验 prior）

### 3.1 文件与函数

| 步骤 | 文件 | 函数 | Config |
|------|------|------|--------|
| S6 入口 | [`gaze_engine/prior_qc/human_prior.py`](../../gaze_engine/prior_qc/human_prior.py) | `apply_human_prior()` | `HUMAN_PRIOR_CONFIG` |
| S6 核心算法 | [`gaze_engine/channel/oculomotor_prior.py`](../../gaze_engine/channel/oculomotor_prior.py) | `apply_oculomotor_prior()` | — |
| 微颤引擎 | [`gaze_engine/channel/micro_jitter.py`](../../gaze_engine/channel/micro_jitter.py) | — | — |

### 3.2 人类先验四模块

| 模块 | 输入 | 行为 | 时间窗 |
|------|------|------|--------|
| **扫视动力学** | `speed` → ζ（阻尼比）, ω（固有频率） | 欠阻尼二阶系统 rewrite `pupil_x/y`；`speed`↑ → ζ↓ → 过冲↑ | t≈12–28 |
| **盯住活劲** | `power`, `steady`, `hold_seg.shape` | 微漂 + 微颤（8–14Hz）；shape 叠 rhythm | t≈25–110 |
| **通道耦合** | 能量标量 | 眉晚 8–15 帧；scale/lid 跟随 pupil 能量 | 全段 |
| **微颤引擎** | `micro_jitter` | 1/f pink noise 底噪；扫视窗内关闭大颤 | 见 prior 报告 |

### 3.3 关键决策

| 决策 | 理由 |
|------|------|
| 算法在 `channel/oculomotor_prior.py`，人类只包装 Config | 保持模块独立，审定只改配置 |
| 二阶系统 rewrite 扫视 | 匀速 easing = CG 感；过冲是输出量，必须物理模拟 |
| prior 默认全开 | 用户只对**戏意**负责；生理是出厂设置 |
| 禁止用 `hold_seg.tremble` 表达正常人要不要颤 | tremble 仅异常加强，非正常人开关 |

| 入口 | [`gaze_engine/delivery/delivery_pipeline.py`](../../gaze_engine/delivery/delivery_pipeline.py) | `run_delivery()` | — |

### 4.2 时间窗（30fps）

| 窗 | 帧范围 | S6 行为 | S7 行为 |
|----|--------|---------|---------|
| 扫视 | 12–28 | 二阶动力学 | Q01 起势斜率 |
| 盯住 | 25–110 | 底噪 + hold shape | Q02 spike / std |
| 眉延迟 | ≥5 帧 | `_couple_lag_channels` lag=10 | Q03 延后检查 |

### 4.3 平庸三检 Q01–Q03

| 编号 | 检测语义 | Effort 映射 | 自动修正 | 阈值来源 |
|------|----------|-------------|----------|----------|
| **Q01** | 峰弱 / range 小 / 起势弱 / 盯住瘪 | Weight+Time 塌缩 | 主能量通道 ×scale（≤1.42） | `reference_targets(packet)` ← macro |
| **Q02** | flat/decay 保持段尖刺或起伏过大 | Flow 失控 | 盯住窗 MA 轻平滑 pupil_x/y | `hold_spike_max`, `hold_std_hi` |
| **Q03** | 眉峰不晚于眼 | Beat 主次反了 | eyebrow 延后 3–12 帧 | `brow_lag_min` ≥ 5 |

**日记字段**：`_pulse_quality_fix_log` · `_pulse_quality_remaining` · `pulse_quality_report`

### 4.4 02 烘焙字段

| 字段 | 内容 |
|------|------|
| `human_prior_report` | ζ/ω/过冲/盯住方差/issues |
| `pulse_quality_report` | metrics + fixes + remaining |
| `schema_version` | `0.2-baked-human-prior` |

## 七、与滑杆的关系

```text
macro.power / speed / push / steady / hold_seg  →  期望能量 & 节奏型（戏意）
prior                                           →  生理默认值（不要假）
QC                                              →  相对期望的底线修正（不要平庸）
```

用户 **不** 配置：过冲百分比、颤动 Hz、眉延迟帧数。

## 八、人类检查点

### 8.1 P0 — 自动（程序）

| 检查项 | 测试方法 | 合格标准 | 优先级 |
|--------|----------|----------|--------|
| S6 扫视过冲 | `prior_report.overshoot_ratio_px` | speed 高档 > speed 低档 | P0 |
| S6 盯住方差 | 盯住窗 std | ε < std < 人格上限 | P0 |
| S6 眉延迟 | brow_lag_frames | ≥ 5 | P0 |
| S7 Q01–Q03 | `diagnose_dense()` | `_pulse_quality_remaining` 空 | P0 |
| 12×150 无 NaN | `validate_baked_delivery` | 1800 keyframes 合法 | P0 |

### 8.2 P1 — 感官（人工精品线）

| 检查项 | 测试方法 | 合格标准 | 优先级 |
|--------|----------|----------|--------|
| **A/B 不要假** | 同 preset：关 prior vs 开 prior 盲看 03 | 开：有撞击/活劲；关：滑块感 | P1 |
| **A/B 不要平庸** | 关 QC vs 开 QC 盲看 | 开：同 macro 更有戏；关：易蔫 | P1 |
| **五连样本** | 5 个 seed 同情绪 | 像「同一个人」 | P1 |
| **气质三联** | 03+04+参考图 → Wan | 连续 3 次过 §0.8 P1 | P1 |

### 8.3 失败归因表

| 观感 | 先查 | 再查 |
|------|------|------|
| 像 CG、匀速、死盯 | S6 prior 是否跳过 | micro_jitter / 扫视 ζ |
| 有动但没戏 | macro.power / Q01 | PAD 是否选对 preset |
| 盯住乱抖 | hold_seg.shape vs Q02 | tremble 是否误开 |
| 眉眼一起动 | Q03 / prior 耦合 | envelope 是否单轨插值 |
| 像别种情绪 | S1 PAD / S4 分支 | 不是 QC 首要背锅 |
