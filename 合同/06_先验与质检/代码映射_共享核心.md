# S6/S7 共享核心模块 — 代码映射

> **本文件**：`_shared/oculomotor_prior.py` + `_shared/pulse_quality_core.py` 的工程说明  
> **总纲**：[`双质量标准_不要假不要平庸.md`](双质量标准_不要假不要平庸.md)

---

## 一、概述（What）

| 模块 | 管什么 | 物种包装 |
|------|--------|----------|
| `oculomotor_prior.py` | **S6 不要假**：扫视/盯住/jitter/延迟/第三眼睑 | `human_prior` · `dog/prior` · `cat/prior` |
| `pulse_quality_core.py` | **S7 不要平庸**：Q01–Q03 + blink 下限 | `human/pulse_quality` · `dog/pulse_quality` · `cat/pulse_quality` |

**原则**：物种差异只在 **Config 常量**，算法不分叉。

---

## 二、理论依据（Theory）

与 [`双质量标准_不要假不要平庸.md`](双质量标准_不要假不要平庸.md) §2 相同；本文件只记录 **Config → 理论** 映射。

| Config 字段 | 理论 | 人 | 狗 | 猫 |
|-------------|------|----|----|-----|
| `zeta_range` / `omega_range` | 扫视过冲（二阶系统） | 0.72→0.38 / 9→20 | 0.58→0.42 / 11→18 | 0.55→0.38 / 14→22 |
| `jitter_hz_bias` | microsaccades | 0 | 0 | +4 Hz |
| `lag_channels` | Beat 主次 / FACS 耳位 | eyebrow | eyebrow+brow_raise | eyebrow+brow_raise |
| `third_eyelid` | CatFACS 内眦膜 | off | off | on @ t≈32 |
| Q01 `energy_channels` | Laban Weight | 8 轨 | +brow_raise | +brow_raise |
| Q03 `brow_lag_min` | 眉眼/耳眼延迟 | 5 帧 | 5 帧 | 6 帧 |

---

## 三、为什么（Why）

| 决策 | 理由 |
|------|------|
| 抽 `_shared` | 人/狗/猫 Q01–Q03 语义一致，避免三份复制漂移 |
| Config dataclass | 后续门户审定只改常量，不改算法 |
| 物种 env 分离 | `ECURSOR_HUMAN_PRIOR` / `ECURSOR_DOG_PRIOR` / `ECURSOR_CAT_PRIOR` 可独立 A/B |

## 四、怎么实现（How）

### 4.1 oculomotor_prior

```text
apply_oculomotor_prior(channels, packet, cfg, sparse?)
  1. _intent(packet, cfg)           → ζ, ω, energy
  2. _apply_saccade_dynamics        → pupil_x/y 二阶 rewrite
  3. _apply_hold_shape_on_channels  → decay/swell/pulse（非 envelope-v1 时）
  4. _couple_lag_channels           → 眉/耳延迟跟随
  5. _apply_third_eyelid            → 猫 lid_lower 短脉冲
  6. _apply_fixation_jitter         → micro_jitter 烘焙
  7. outro 衰减                     → macro.outro < 50
  8. validate_dense_channels        → prior_report.issues
```

**入口 Config**：

| 常量 | 文件引用 |
|------|----------|
| `HUMAN_PRIOR_CONFIG` | `human/human_prior.py` |
| `DOG_PRIOR_CONFIG` | `dog/prior.py` |
| `CAT_PRIOR_CONFIG` | `cat/prior.py` |

### 4.2 pulse_quality_core

```text
fix_pulse_quality_core(channels, packet, cfg, species_blink?)
  循环 max_rounds:
    diagnose_dense → Q01/Q02/Q03 列表
    _fix_q01_energy      ×scale ≤ max_energy_scale
    _fix_q02_chaotic_hold  MA 平滑 pupil_x/y
    _fix_q03_ensemble      lag_channels 延后
  species_blink → _fix_blink_floor
  decouple_pairs 抽检
  → PulseQualityReport(metrics, fixes, remaining)
```

**入口 Config**：

| 常量 | 包装函数 |
|------|----------|
| `HUMAN_QC_CONFIG` | `human/pulse_quality.fix_pulse_quality()` |
| `DOG_QC_CONFIG` | `dog/pulse_quality.fix_dog_pulse_quality()` |
| `CAT_QC_CONFIG` | `cat/pulse_quality.fix_cat_pulse_quality()` |

### 4.3 时间窗（全物种共用）

| 窗 | 帧 | 用途 |
|----|-----|------|
| 扫视 | 12–28 | S6 动力学 / Q01 起势斜率 |
| 盯住 | 25–110 | S6 jitter / Q02 spike |
