## 目录结构（= 管线阶段）

```text
合同/
├── 00_管线导读/          ← **唯一宏观架构**（编号 = 编译顺序）
├── 01_输入与收口/        ← SliderPacket、L1
├── 02_情绪与能量/        ← macro+hold → E(t)
├── 03_情绪坐标/          ← 情绪坐标 (PAD) → pad_scale
├── 04_通道编译/          ← pulse = E(t) × 情绪坐标
├── 05_风格化/            ← styled
├── 06_先验与质检/        ← prior + QC
├── 07_工程底膜/          ← 底膜 MP4
├── 08_输出与扩散/        ← 扩散包、NL-B
└── 09_架构与验收/        ← P0/P1 验收专篇
```

**原则**：一种情绪 / 一种风格 = 一份独立正文 md；物种索引文件仅跳转，不含定稿正文。

**生成器**：`python3 tools/03_工具脚本/generate_species_contracts.py`  
**品种/人格数值**：改 catalog → `sync_human_style_pack.py` / `sync_species_style_pack.py` → 再跑生成器
