## 目录结构（= 管线阶段）

```text
合同/
├── 00_管线导读/          ← 阅读地图、改参决策表
├── 01_输入与收口/        ← S0：6+3 滑杆、macro/hold、L1 禁区
├── 02_情绪与能量/        ← S2：38 种情绪 macro/E(t)（人16·猫12·狗10）
├── 03_情绪坐标/          ← S1：情绪坐标理论（扁平 5 篇）+ 人/猫/狗 38 份单项
├── 04_通道与先验/        ← S4：12 通道、真人律、节拍表
├── 05_风格化/            ← S5：人格/品种 base+scale
├── 06_工程底膜/          ← 视觉封装：RGB 三色底膜
├── 07_输出与扩散/        ← 04 Prompt、UI、上下游接口
├── 08_架构与验收/        ← S0–S7 全链、P0/P1 验收
└── 09_先验与质检/        ← S6 prior + S7 QC：不要假 · 不要平庸
```

**原则**：一种情绪 / 一种风格 = 一份独立正文 md；物种索引文件仅跳转，不含定稿正文。

**生成器**：`python3 tools/03_工具脚本/generate_species_contracts.py`  
**品种/人格数值**：改 catalog → `sync_human_style_pack.py` / `sync_species_style_pack.py` → 再跑生成器
