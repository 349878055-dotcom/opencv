# 演技理论 — 张力三层解耦模型

> **状态：2026-05-29 定稿专篇**  
> **读者**：编译器模式、合同审定、滑杆调参、E(t) 图形诊断  
> **定位**：**参数 → 图形 → 表演力** 的底层理论标尺；判断一切滑杆数值的唯一参照系  
> **宏观架构**：见 [`00_从门户到扩散_管线总览.md`](00_从门户到扩散_管线总览.md)  
> **滑杆映射**：见 [`macro与hold_seg专篇.md`](../01_输入与收口/macro与hold_seg专篇.md)

**核心哲学**：

> **内部力量与外部力量的错位，是表演张力（或浮夸）的来源。**

肌肉在空间里「动了多少」与肌肉组之间「死磕了多少」是两件独立的事——这一原理来自角色动画/表演学，**不是**本项目的渲染维度。观众潜意识读取二者的比例，瞬间判定表演是真情流露还是虚假浮夸。本模型把这一原理拆成三层，供 E(t) 曲线与滑杆配置一一对应。

### 工程语境（别和渲染层混淆）

| 层级 | 本系统实际是什么 |
|------|------------------|
| **理论层（本文）** | $F_{ext}$ / $F_{int}$ 是**表演语义**，映射到 E(t) 曲线的几何特征（峰高、平顶、锯齿） |
| **编译层（`02`）** | 一条 E(t) 主钟 150×1，**所有物种共用**；与 OpenCV / 3D 无关 |
| **像素层（`07`）** | OpenCV **2D** 仿射网格：`affine_renderer` 把 12 通道数值画成 RGB 线条控制视频（R 眼 / G 眉 / B 瞳孔），**不是 3D 骨骼** |
| **狗（`04`）** | 同一 E(t) 驱动 **12 通道**：眼（blink / squint / lid / pupil…）+ 眉脊（eyebrow / brow_raise）+ **耳位**（`channel_adapter` 注入）。耳与眼共享主钟，读感上仍是「这只狗在克制/释放」 |

```text
表演理论（F_ext / F_int）
      ↓  语义映射，非几何维度
E(t) 能量曲线（02，150 点）
      ↓  × PAD scale
12 通道 pulse（04；狗含耳）
      ↓  OpenCV 2D 线条
03_工程底模.mp4  →  Wan 扩散
```

**结论**：写「3D」是指**借动画行业的表演语言**解释张力；工程落地是 **OpenCV 眼眉（+ 狗/猫耳）控制线**。公式与诊断表对狗完全适用——狗的多通道（含耳）都服从同一条 E(t)。

## 一、第一层：核心物理定义（力量的本质）

在本系统里，「力量」被**强制拆分为两个独立的物理量**。绝对不能混为一谈。

### 1.1 $F_{ext}$ — 外部物理位移（External Displacement）

| 维度 | 内容 |
|------|------|
| **物理意义** | 控制量在数值/像素上的**可见位移幅度**（表演语义）。眼皮线条抬高多少？眉脊/耳位变化多大？ |
| **控制滑杆** | `power` |
| **图形映射** | 决定 E(t) 曲线在 **Y 轴的绝对高度**（山有多高） |
| **视觉直观** | 动作的「大小」 |

### 1.2 $F_{int}$ — 内部对抗张力（Internal Tension）

| 维度 | 内容 |
|------|------|
| **物理意义** | 肌肉组之间的对抗发力（拮抗）。想哭（收缩）与理智憋着（拉伸）两股力在原位死磕——肌肉没有大幅度移动，但消耗了巨大能量 |
| **控制滑杆** | `grip`（憋住的死区）+ `hold_seg`（能量溢出导致的微颤） |
| **图形映射** | 决定 E(t) 曲线在 **平顶段的维持率**（不掉下来）与 **高频噪点**（毛刺） |
| **视觉直观** | 动作的「吃力感」与「失控感」 |

```text
F_ext  →  power     →  E(t) 峰高 Y 轴
F_int  →  grip + hold_seg.shape  →  E(t) 平顶维持 + 锯齿纹理
```

**铁律**：高 `power` 不等于有戏；低 `power` 不等于没戏。戏在 $F_{int}/F_{ext}$ 的比例，不在单一滑杆。

## 二、第二层：表演力推导公式

观众通过潜意识捕捉 $F_{ext}$ 与 $F_{int}$ 的比例，判断表演是「真情流露」还是「虚假浮夸」。

### 2.1 戏剧张力公式

$$
\text{戏剧张力 (Dramatic Tension)} \approx \frac{F_{int}\ \text{（内部对抗）}}{F_{ext}\ \text{（外部位移）}}
$$

| 比值区间 | 读感 |
|----------|------|
| $F_{int} \ll F_{ext}$ | 浮夸、廉价、体操感 |
| $F_{int} \gg F_{ext}$ | 隐忍、高级、内心戏 |
| $F_{int} \approx F_{ext}$ | 均衡释放，视情绪种类而定 |

### 2.2 案例 A：浮夸的来源（CG 廉价感）

| 维度 | 配置 / 状态 |
|------|-------------|
| **参数** | 高 `power`，低 `grip`，`shape = flat` |
| **图形长相** | 极高的 Y 轴，完美平滑的钟形曲线 |
| **物理状态** | $F_{ext}$ 极大，$F_{int}$ 为零 |
| **观众读感** | 五官乱飞。狗的眼眉/耳位瞬间拉到最大，然后平滑落下。没有任何阻力，线条像橡皮筋一样随意拉伸 |
| **大脑判定** | 「它没有在控制情绪，它只是在做体操」→ **极度浮夸，廉价** |

### 2.3 案例 B：高级的表演力（隐忍的委屈）

| 维度 | 配置 / 状态 |
|------|-------------|
| **参数** | 低 `power`，高 `grip`，`shape = tremble` |
| **图形长相** | 极低的 Y 轴（几乎贴在底端），但平顶段极长且充满锯齿毛刺 |
| **物理状态** | $F_{ext}$ 极小，$F_{int}$ 极大 |
| **观众读感** | 狗的眼眶只收缩了 1 毫米（外部动作极小），但这 1 毫米花了 40 帧才达到，在最高点死死卡住，肌肉因过度用力控制而产生高频抽搐（颤抖） |
| **大脑判定** | 「它花费了极其巨大的内部能量，才勉强把动作压制在这个微小的幅度上」→ **极高的隐忍张力，可怜，心疼** |

```text
浮夸  =  大山（高 F_ext）+  光滑（零 F_int）
高级  =  矮山（低 F_ext）+  长平顶锯齿（高 F_int）
```

## 三、第三层：滑杆与 E(t) 图形的 1:1 诊断沙盘

导出一张 E(t) 能量曲线图时，通过四个区域的**几何特征**直接反推表演力。这是编译器模式下的唯一诊断表。

| 模块 | E(t) 图形特征 | 滑杆来源 | 映射的「表演力」 | 心理学语义 |
|------|---------------|----------|------------------|------------|
| **一、上坡段**<br>（0 帧 → 峰值） | **斜率（坡度）**。越陡 = 越快；越缓 = 越慢 | `speed` | 理智的介入度 | **极陡**（如 5 帧到顶）：纯粹的生物本能应激（吓一跳）<br>**极缓**（如 40 帧到顶）：大脑在疯狂运算、迟疑、酝酿情绪 |
| **二、最高点**<br>（峰值拐点） | **Y 轴绝对坐标（高度）**。0.1 以下 = 微动；0.5 以上 = 大动 | `power` | 情绪的释放度（$F_{ext}$） | **低高度**：情绪被封锁、压抑（委屈 / 暗中观察）<br>**高高度**：情绪完全爆发（狂怒 / 狂喜） |
| **三、平顶段**<br>（峰值维持区） | **曲线塌陷率与毛刺**。平滑 = 无阻力；锯齿 = 高对抗 | `grip`<br>`hold_seg.shape` | 内心的挣扎度（$F_{int}$） | **本系统最值钱的几何特征**。高 `grip` + `tremble` 锯齿，是唯一能向观众传达「这只狗有内心戏，它在极力克制自己」的信号 |
| **四、下坡段**<br>（缓和区） | **回落曲线**；与上坡段的**不对称性** | `outro` | 情绪的收尾惯性 | **慢起 + 快收** = 突然被打断的隐忍<br>**快起 + 慢收** = 惊吓后的长时间心悸<br>不对称性创造活物感 |

### 3.1 四段联合读图口诀

```text
看坡（speed）  →  情绪来得多急
看高（power）  →  情绪放出来多少（F_ext）
看顶（grip + hold）  →  情绪憋回去多少（F_int）
看收（outro）  →  情绪怎么收场
```

### 3.2 张力比与图形对照

| 图形组合 | $F_{int}/F_{ext}$ | 典型情绪读感 |
|----------|-------------------|--------------|
| 高 Y + 短平顶 + 光滑 | 极低 | 浮夸、廉价 CG |
| 低 Y + 长平顶 + 锯齿 | 极高 | 隐忍、委屈、心疼 |
| 高 Y + 长平顶 + 锯齿 | 中高 | 强忍的爆发（怒视·压人类） |
| 低 Y + 短平顶 + 光滑 | 低 | 空竭、死心、无戏 |

## 四、与管线的边界

| 本模型管 | 本模型不管 |
|----------|------------|
| macro + hold_seg → E(t) 几何 → 表演力读感 | PAD 情绪坐标 → 12 通道配比（见 `03`） |
| $F_{ext}$ / $F_{int}$ 比例与浮夸/高级判定 | style 品种偏移（见 `05`） |
| E(t) 四段图形诊断 | prior 扫视、人类 steady 后效（见 `06`，部分不进 E(t)） |

**编译序不变**：本理论作用于 **`02` E(t) 主钟** 之前的滑杆决策；E(t) 定稿后再叠 PAD、通道、风格、先验。

## 五、标尺使用约束

1. **任何滑杆调参**，先问：这次改动主要抬 $F_{ext}$ 还是 $F_{int}$？二者不可混调而不自知。
2. **任何 E(t) 验收**，必须四段联读；单看峰高或单看平顶均不完整。
3. **浮夸诊断**：高 `power` + 低 `grip` + `flat` → 几乎必然廉价；除非情绪合同明确要求「外放型」。
4. **高级诊断**：低 `power` + 高 `grip` + `tremble` → 隐忍类情绪的黄金区间；参考 [`委屈.md`](../02_情绪与能量/委屈.md)（变体 2）。
