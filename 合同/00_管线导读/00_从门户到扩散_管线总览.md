## 一、5 秒读懂：数据怎么走

```text
客户门户 / Pomot
    │
    ▼ S0  输入收口     SliderPacket + L1 禁区
    ▼ S1  PAD 气质     (P,A,D) → pad_scale[12]
    ▼ S2  情绪能量     macro+hold → E(t)
    ▼ S4  通道编译     E(t)×PAD → pulse[12×150]
    ▼ S5  风格化       pulse → styled（品种/人格）
    ▼ S6  先验 prior   不要假（过冲/微颤/耳眼延迟）
    ▼ S7  质检 QC      不要平庸（Q01-Q03）
    ▼ S8  节拍表编译   02 → rhythm_compiler → 扩散节拍表（导演语义指令）
    ▼ 视觉封装         02 烘焙 + 工程底膜 MP4（像素，与 S8 同源）
    ▼ 扩散包组装       MP4 + 节拍表 + NL + 正反向 Prompt → 扩散引擎包
    ▼ 输出扩散         AutoDL + ComfyUI Wan Fun Control → 成片 MP4
                       （部署见 07_AutoDL扩散引擎部署专篇）
```

**定稿口诀**：`macro=演多重` · `PAD=哪类戏` · `style=谁的脸`

**资产边界**：`预设资产/`（情绪包+风格包+**底膜包**）= 只读真源；门户 **仅存选项 id**，Pomot/保存时由服务端从资产库调取；`客户资产库/` 存标定后的 **`物种底膜模板.json`** 与管线产出（01～05）。底膜 **禁止** 客户美颜滑杆，见 [`底膜模板选择与标定专篇.md`](../06_工程底膜/底膜模板选择与标定专篇.md)。

## 三、改参决策表（最常问）

| 你想… | 去哪个目录 | 不要动 |
|-------|-----------|--------|
| 戏太弱/起势快慢 | `01_输入与收口` macro | 品种 style |
