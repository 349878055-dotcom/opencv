## 零、项目目的与终验（C 端第一步交付 · 当前第一优先级）

整条 `01`～`08` **只为一个终验目标**：

> **5 秒内让人「更有气质」的精品成片** — 不是「能播放」，是 **愿意转发**。

**气质** = 眼神有戏 + 节奏对 + 像自己的脸/宠物 + 成片不丢人。  
**不写在本节**：音乐 feed / 脉冲推送语法书 / 关联度推荐（后续独立合同）。

| ✅ 本节管 | ❌ 本节不管 |
|-----------|------------|
| 气质验收定义、5s/150 帧、试气质 vs 定稿精品 | 音乐编译、长片 stitch |
| Wan `wan_final` 参数线与 P1 否决 | ComfyUI 节点 UI、LoRA/换脸 |

### 0.1 气质四维 ↔ 管线

| 维度 | 含义 | 管线谁负责 |
|------|------|------------|
| **眼有戏** | 5s 内起→盯→收，非死鱼眼 | `01`～`06`；P1 必查 blink/pupil |
| **像** | 像参考图那只脸/宠物 | `start_image.jpg` + `05` style |
| **节奏对** | 与 preset 读感一致 | `02` E(t) + `03` 情绪坐标 + `08` 节拍表 |
| **成片质感** | 不廉价、不闪不崩 | `wan_final` 参数 + seed |

### 0.2 两档产品

| 档位 | 用户感知 | 工程 |
|------|----------|------|
| **试气质** | 「感觉对不对」 | `wan_preview` 49～65 帧，可多次、多 seed |
| **定稿精品** | 「能发抖音/当作品集」 | `wan_final` **150 帧 @30fps ≈ 5s**，**只跑一次** |

⚠️ ~20 分钟可接受；**20 分钟出垃圾 = 产品失败。**

### 0.3 合格链（必须同源 revision）

```text
参考图 + 情绪/滑杆（或 NL-A）+ 场景（或 NL-B）
        ↓  01～07 眼眉链（P0 见 §1.2）
02_烘焙_*.json + 03_工程底模.mp4 + 04_Prompt（同 revision）
        ↓  08 扩散包 → Wan
5s 气质精品成片 MP4
```

`02` / `03_工程底模.mp4` / `04` **必须同一 revision**；换 seed 定稿前须锁定滑杆包。

### 0.4 产品形态（气质向 · 精控眼眉）

| 层 | 范围 |
|----|------|
| **精控区** | 眼眉（狗/猫含耳）12 通道 — 产品核心价值 |
| **自然发挥区** | 毛发、光照、微姿态 — Wan 补，须与控制 **同拍对齐** |
| **边界** | 不靠全身大动作交付气质；叙事里「跑」归氛围，「回头看那一眼」归验收 |

**气质 = MP4 像素路 + Prompt/节拍表语义路 + 参考图身份路 + `02` 数值合格**；不单押 Prompt。

### 0.5 Wan 渲染档位（定稿不得下修）

**预览 `wan_preview`**：frames 49～65 · steps 15～20 · 480p · `wan2.1-i2v-14b-480p`

**定稿 `wan_final`（精品）**：frames **150** · fps **30** · steps **≥40** · 480p · 与预览 **同模型族**

### 0.6 MVP 第一战线

1. 物种：**狗**（门户主路径）  
2. 情绪：[`委屈·幼犬眼`](../02_情绪与能量/狗/委屈·幼犬眼.md) 定稿后扩其余 9 个  
3. **连续 3 次** `wan_final` 过 **§0.8 P1**（同情绪、可不同 seed）→ 再开下一情绪 / 音乐

### 0.7 P0 结构（不过则禁止送 Wan 定稿）

| 检查项 | 方法 | 合格 |
|--------|------|------|
| 02 烘焙 1800 keyframes | `verify_dog_150_compile_contract.py` | exit 0 |
| 04 五段 + 节拍 | `verify_diffusion_prompt_contract.py` | exit 0 |

眼眉链 P0 细节：[`04_通道编译/狗/动态层编译与代码映射.md`](../04_通道编译/狗/动态层编译与代码映射.md)

### 0.8 P1 气质 · 精品（人眼否决；任一 FAIL = 整链失败）

| 检查项 | 合格标准 |
|--------|----------|
| **眼有戏** | 全片至少 1 次明显 blink 或 pupil 位移；盯住段非死鱼眼 |
| **情绪弧** | 起—盯—收与 [`02_情绪与能量/狗/`](../02_情绪与能量/狗/) 该情绪 md 读感一致 |
| **像** | 同一只狗/同品种气质，无换脸感 |
| **不廉价** | 无塑料毛、大面积 glitch、通道撕裂 |
| **可转发** | 制作人自评愿当作品集 — **一票否决** |

**否决语（出现即 FAIL）**：cheap AI / 眼神空的 / 和选的委屈没关系 / 不像我家狗 / 等了 20 分钟不值

### 0.9 历史教训（定稿前自检）

| 坑 | 规则 |
|----|------|
| 预览像 demo、成片像另一物种 | 预览与成片 **同 preset、同 E(t) 方向** |
| 02 过但 Wan 死鱼眼 | P1 必查盯住段 blink/pupil |
| 04 与 03 revision 不一致 | P0 脚本必过 |
| 砍 steps 省时间 | 定稿 **不得低于** `wan_final` steps≥40 |

## 一、编译顺序（为 §零 服务）

### 1.1 四层数据（别混）

**150 帧全量 = 12 通道 × 150 = 1800 个数**；不是一条 E(t)。

| 层 | 形状 | 管什么 | 合同目录 |
|----|------|--------|----------|
| **E(t)** | 150×1 | 戏的节奏（起—盯—收） | `02` + `01` macro/hold |
| **pulse** | 12×150 | 戏往哪些通道走 | `03` + `04` |
| **styled** | 12×150 | 品种怎么吃戏 | `05` |
| **final** | 12×150 | 先验 + 质检底线 | `06` → `02_烘焙_*.json` |

> E(t) 管时间 · 情绪坐标管通道配比 · style 管脸 · 质检管底线。

### 1.2 眼眉链数据流（狗示例；猫/人同构）

```text
01 SliderPacket → 02 E[t] → 03 scale[ch] → 04 pulse[ch,t]
  → 05 styled → 06 prior+QC → 02_烘焙（1800 v）→ 07 MP4
```

代码逐步表：[`狗动态层编译与代码映射.md`](../04_通道编译/狗/动态层编译与代码映射.md)

### 1.3 工程状态（2026-05）

| 类别 | 状态 |
|------|------|
| 管线骨架 01～08 | ✅ 已通；`verify_dog_150_compile_contract.py` |

### 1.4 `08_输出与扩散` — 送 Wan 要什么（六块）

**本步不再改 12 通道**，只做 **组装 + 落盘 + 触发扩散**。上游 **`07` 已出 MP4**；`08` 把 **参考图 + 像素 + 语义** 绑成同一 revision 的 `扩散引擎包/`。

| 块 | 是什么 | 从哪来 | 落盘 / Wan 怎么吃 |
|----|--------|--------|-------------------|
| **⓪ 参考图** | 脸/宠物 **身份锚点**（画的是谁） | **客户必传**；**测试同样必传**（门户项目上传） | `start_image.jpg` → Wan **参考图节点**（不是场景正文，不改 12 通道） |
| **① 控制视频 MP4** | 150 帧 RGB 眼眉线条（R 眼 / G 眉 / B 瞳孔） | **`07` 工程底膜** OpenCV 渲染 | `03_工程底模.mp4` → Wan **`control_video`** |
| **② 场景描述** | 戏外世界：在吃饭、光线、镜头、动作叙事（**NL-B**） | **客户自然语言**；测试时 **③ 手写** | `04` 的 **`## 叙事`** → 拼进 `wan_positive.txt` |
| **③ 扩散节拍表** | 12 通道关键帧 **翻译成人话**（眼眉在演什么） | `02_烘焙_*.json` → `rhythm_compiler` | `04` 的 **`## 扩散节拍表`** → `wan_positive` 中段 |
| **④ 正反向提示词** | 正向：物种/情绪/质感 + 跟随控制序列；反向：画质/同步/身份禁区 | `pomot/assembler` | `wan_positive.txt` · `wan_negative.txt` |
| **⑤ Wan 扩散** | 消费整包 → **§零 终验**：5s 气质精品成片 | AutoDL + Comfy `wan_final` | 输入 = **⓪①②③④** 齐备；标准见 **§0.5～0.8** |

**分工口诀**：

```text
参考图   = 画的是谁（身份，测试与客户都要）
MP4     = 眼眉几何在哪、怎么动（像素）
节拍表   = 眼眉在演什么节奏（语义，眼眉链 01～06）
场景描述 = 在吃饭、什么环境（语义，客户 NL / 测试手写）
Prompt  = 总导演约束 + 禁区（正向/负向）
Wan     = 六块齐备后的视频生成引擎
```

**门户常用**：`POST /api/portal/export` = 渲染 ③ MP4 + 写 ④ 文本 + `build_diffusion_bundle()`。Pomot round1/2 **只出 02/04/wan±，不出 MP4**，需再 export 或 render-preview。
