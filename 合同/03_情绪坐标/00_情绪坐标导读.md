## 一、概述（What）

### 本目录管什么

`03_情绪坐标/` 是 **PAD（Pleasure–Arousal–Dominance）** 的 **专题目录**，分两块：

| 分区 | 内容 | 份数 |
|------|------|------|
| **根目录 `00～04_*.md`** | PAD 理论、边界、编译链（**扁平，无子目录**） | **5 份**（含本文） |
| **`人/` `猫/` `狗/`** | 每种情绪的 **PAD 定稿**（P/A/D + 12 通道投影） | **38 份** |

### 一句话结论（先读这个）

> **PAD = 这种情绪的「脸性格坐标」（情绪坐标），不是 macro 表演力微调，也不是品种/人格 style。**  
> **PAD 不进 E(t)**：不管第几秒到峰；只管 5 秒内各通道 **像委屈还是像凶狠** 的静态配比。

### 定稿口诀

```text
macro  →  这一类戏「演多重」（表演力 · 时间轴 E(t)）
情绪坐标 →  「是哪一类戏」（P/A/D · 通道性格）
style  →  「谁的脸在吃戏」（脸框 · 品种/人格 S5）
```

### 管线位置（编译序见总览）

```text
选情绪 preset
  ├─ macro + hold_seg ──→ E(t)           ← 02_情绪与能量（先于 PAD）
  ├─ pad (P,A,D)      ──→ pad_scale[12]  ← 03_情绪坐标（叠在 E(t) 上，再进 04）
  └─ style.json       ──→ styled         ← 05_风格化
         ↓
    04 通道编译 → 02 烘焙 → 底膜 → 扩散
```

唯一宏观图：[`00_从门户到扩散_管线总览.md`](../00_管线导读/00_从门户到扩散_管线总览.md)

## 二、理论依据（Theory）

### 2.1 PAD 从哪来

```text
① Russell 环形情绪模型 → 愉悦度 × 激活度
② Mehrabian & Russell PAD 量表 → 加 Dominance（支配度）
③ 本项目 → 每种情绪 preset 占 (P,A,D) 空间中的一个点
           该点描述「脸整体偏甜/压/急/软/支配/退缩」
           不描述「第几秒到峰」
```

| 轴 | 符号 | 本项目读感示例 |
|----|------|----------------|
| **P** 愉悦度 | [-1,1] | 纯甜 P↑ → 高光/眯眼偏吸引；怒视 P↓ → 偏沉压 |
| **A** 激活度 | [-1,1] | 威慑 A↑ → 眼动急、上睑绷；困倦 A↓ → 软塌 |
| **D** 控制度 | [-1,1] | 压人 D↑ → 眉压/耳竖；委屈 D↓ → 垂、缩、不压场 |

**Wp/Wa/Wd 权重表** 有心理学 **三维** 依据；**落到 squint 的系数是 🧠 工程审定**（读感 + 合同 CHECK）。

### 2.2 为什么单独成目录

PAD 原先散在多处专篇里，与 macro、全栈架构混在一起，**入门成本高**。  
集中到 `03_情绪坐标/` 后：

- 理论读 **根目录 5 篇**（按顺序，无子目录）
- 数值改 **`人/猫/狗/`** 对应情绪 md
- 与 [`02_情绪与能量/`](../02_情绪与能量/) **一一对应**，职责不重叠

## 三、为什么这样做（Why）

| 决策 | 理由 |
|------|------|
| PAD 不进 E(t) | 换情绪大类不应意外改掉「第几秒到峰」 |
| PAD 与 style 分层 | 10 狗种共用同一委屈 PAD；贵宾/田园各吃各的 pulse |
| 一种情绪一份 PAD md | 改委屈 PAD 只改一处，不碰 macro 合同 |
| C 端不拖 PAD 三轴 | 大类靠 **选 preset + 审定**；微调靠 macro |

⚠️ **常见误解**：「PAD 是表演力微调」→ 错；拖 power 是 macro；PAD 是 **换 preset 才换的大类**。
