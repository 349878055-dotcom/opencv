## 一、问题陈述

### 1.1 为什么需要空间校准

Affine Renderer 在 **1024×1024 标准画布**上渲染眼区线条图。但这个标准画布与客户真人照片存在三重差异：

| 差异 | 来源 | 影响 |
|------|------|------|
| **位置偏移** | 照片中人物脸部不一定居中 | 渲染的眼区在照片中位置不对 |
| **尺度差异** | 照片分辨率、拍摄距离不同 | 渲染的眼区大小与照片不符 |
| **旋转/倾斜** | 人物头部可能有 ±15° 旋转 | 渲染的眼区角度与照片不一致 |

**解决方案**：计算一个 2×3 仿射矩阵，将标准画布上的渲染结果 warp 到与客户照片对齐。

### 1.2 核心思想

```
标准画布 (1024×1024)          照片画布 (原始分辨率)
    ┌────────────────┐            ┌──────────────────┐
    │                │            │                  │
    │   ● 左眼        │            │        ● 左眼     │
    │        ● 鼻梁   │   仿射     │      ● 鼻梁       │
    │   ● 右眼        │   ────►   │        ● 右眼     │
    │                │            │                  │
    └────────────────┘            └──────────────────┘

    三对对应点 → cv2.getAffineTransform → 2×3 矩阵 M
    warp(render_frame, M) → 690×361 对齐输出
```

## 二、三组锚点

空间校准基于 **3 组 × 3 点** = 9 个坐标值。

### 2.1 标准模型锚点（model_anchors）

代码：[`standard_model_anchors()`](gaze_engine/render/spatial_calibration.py:152)

在 1024×1024 标准画布上，从 `RendererConstants` 提取眼中心坐标：

```
左眼中心 = (LEFT_CX, LEFT_CY)
右眼中心 = (RIGHT_CX, RIGHT_CY)
中颚点   = ((LEFT_CX + RIGHT_CX) / 2, (LEFT_CY + RIGHT_CY) / 2)
鼻尖     = (中点_x, 中点_y + 眼距 × nose_eye_ratio)
```

其中 `nose_eye_ratio` 默认值 0.62，表示鼻尖在眼中心连线下方约 0.62×眼距处。

**外眼角模式**（`anchor_mode="outer_canthus"`）：

```
左外眼角 = (LEFT_CX - EYE_W, LEFT_CY)   # EYE_W 默认 150
右外眼角 = (RIGHT_CX + EYE_W, RIGHT_CY)
```

此模式适用于面部较宽或需要更强旋转约束的场景。

### 2.2 照片锚点（photo_anchors）

从 MediaPipe 检测（或手动标定）提取：

```python
left_eye  = (landmark[33].x * img_w, landmark[33].y * img_h)   # 左外眼角
right_eye = (landmark[362].x * img_w, landmark[362].y * img_h)  # 右外眼角
nose      = (landmark[1].x * img_w, landmark[1].y * img_h)      # 鼻尖
```

**约束**：眼距 ≥ 5px，否则 `raise ValueError`。

### 2.3 输出锚点（output_anchors）

照片锚点通过简单缩放映射到输出空间：

```python
# _map_photo_to_output()
output_x = photo_x * OUTPUT_W / img_w    # OUTPUT_W = 690
output_y = photo_y * OUTPUT_H / img_h    # OUTPUT_H = 361
```

## 三、仿射变换数学

### 3.1 cv2.getAffineTransform

给定三组对应点 {src₀, src₁, src₂} → {dst₀, dst₁, dst₂}，求解 2×3 仿射矩阵 M：

```
M = | m00  m01  m02 |
    | m10  m11  m12 |
```

满足：

```
dst_x = m00 × src_x + m01 × src_y + m02
dst_y = m10 × src_x + m11 × src_y + m12
```

写成线性方程组：

```
| src_x  src_y  1   0     0     0 |   | m00 |   | dst_x |
|   0     0    0  src_x  src_y  1 | × | m01 | = | dst_y |
| ... 每个点提供两行，3 点共 6 行    |   | m02 |   | ...  |
                                        | m10 |
                                        | m11 |
                                        | m12 |
```

三组对应点 → 6 个方程 → 唯一解。OpenCV 的 `cv2.getAffineTransform` 内部使用最小二乘法求解此 6×6 线性系统。

### 3.2 两个仿射矩阵

[`compute_spatial_calibration()`](gaze_engine/render/spatial_calibration.py:193) 计算 **两个** 仿射矩阵：

```python
src  = standard_model_anchors(...)   # 1024 画布坐标
dst  = _map_photo_to_output(...)     # 690×361 输出坐标
photo_src = 照片原始坐标

M_model  = cv2.getAffineTransform(src, dst)       # → affine_matrix
M_photo  = cv2.getAffineTransform(photo_src, dst) # → photo_affine_matrix
```

| 矩阵 | 源 | 目标 | 用途 |
|------|----|------|------|
| `affine_matrix` | 1024 标准画布 | 690×361 输出 | warp 渲染帧 |
| `photo_affine_matrix` | 照片原始图像 | 690×361 输出 | warp 照片（overlay 预览） |

### 3.3 SpaticalCalibration 数据类

```python
@dataclass
class SpatialCalibration:
    scale: float                # 眼距比例：photo_eye_dist / model_eye_dist
    affine_matrix: list[list[float]]   # 2×3 矩阵（模型→输出）
    photo_affine_matrix: list[list[float]]  # 2×3 矩阵（照片→输出）
    model_anchors: dict[str, list[float]]   # 1024 画布三点
    photo_anchors: dict[str, list[float]]   # 照片原始三点
    output_anchors: dict[str, list[float]]  # 输出空间三点
    nose_eye_ratio: float       # 推算的眼-鼻比（默认 0.62）
    output_size: list[int]      # [690, 361]
    model_canvas: int           # 1024
```

## 四、Warp 管线

### 4.1 渲染帧 Warp（model→output）

```python
def warp(self, canvas: np.ndarray) -> np.ndarray:
    M = self.matrix_np()  # 2×3 float32
    return cv2.warpAffine(
        canvas,
        M,
        (OUTPUT_W, OUTPUT_H),  # (690, 361)
        flags=cv2.INTER_LINEAR,
        borderMode=cv2.BORDER_CONSTANT,
        borderValue=(0, 0, 0),
    )
```

**输入**：1024×1024 uint8 RGB（AffineRenderer 的输出）
**输出**：690×361 uint8 RGB（对齐到客户照片的最终帧）
**插值**：`cv2.INTER_LINEAR`（双线性插值）
**边界**：`BORDER_CONSTANT` 黑色填充（超出标准画布的区域）

### 4.2 照片 Warp（photo→output）

```python
def warp_photo(self, photo_bgr: np.ndarray) -> np.ndarray:
    if self.photo_affine_matrix:
        M = self.matrix_photo_np()
    else:
        # 从锚点重建
        M = cv2.getAffineTransform(photo_pts, output_pts)
    return cv2.warpAffine(photo_bgr, M, (OUTPUT_W, OUTPUT_H), ...)
```

**用途**：将原始客户照片投影到相同输出空间，用于 overlay 模式——在预览界面将渲染帧半透明叠加在 warp 后的照片上检查对齐质量。

## 五、Nose-Eye Ratio 计算

[`nose_eye_ratio_from_anchors()`](gaze_engine/render/spatial_calibration.py:136) 从照片的三点标定推算眼-鼻垂直比（相当于面部「中庭长度」比例）：

```python
def nose_eye_ratio_from_anchors(anchors):
    le, re, nose = extract_points(anchors)
    eye_dist = hypot(re.x - le.x, re.y - le.y)
    mid_y = (le.y + re.y) / 2
    dy = nose.y - mid_y
    if dy > 0 and eye_dist >= 5:
        return clamp(dy / eye_dist, 0.35, 0.95)
    return NOSE_EYE_RATIO  # 默认 0.62
```

**意义**：不同人脸的面部比例不同——有些人中庭长（鼻尖离眼远），有些人中庭短。使用照片实际推算的 `nose_eye_ratio` 替代固定的 0.62，可使鼻尖锚点位置更准确，改善仿射变换的旋转/缩放精度。

**范围**：[0.35, 0.95]，超出此范围说明标定异常，回退到默认值。

## 六、关键常量

| 常量 | 值 | 含义 | 位置 |
|------|-----|------|------|
| `MODEL_CANVAS` | 1024 | 标准渲染画布尺寸 | [spatial_calibration.py:35](gaze_engine/render/spatial_calibration.py:35) |
| `OUTPUT_W` | 690 | 输出宽度 | [spatial_calibration.py:36](gaze_engine/render/spatial_calibration.py:36) |
| `OUTPUT_H` | 361 | 输出高度 | [spatial_calibration.py:36](gaze_engine/render/spatial_calibration.py:36) |
| `NOSE_EYE_RATIO` | 0.62 | 默认眼-鼻垂直比 | [spatial_calibration.py:37](gaze_engine/render/spatial_calibration.py:37) |
| `EYE_W` | 150 | 标准单眼宽度（外眼角模式） | [affine_renderer.py](gaze_engine/render/affine_renderer.py) |

**为什么 690×361？**

```
690 / 512 ≈ 1.348     → 接近 4:3 比例
361 / 512 ≈ 0.705     → 接近黄金分割 ~0.618
```

实际选择的考虑：宽高比 ≈ 690/361 ≈ 1.91:1，接近 2:1 的宽幅布局，为双眼 + 鼻梁留出足够水平空间，同时垂直方向只保留眼-眉区域，去除无关面部下部分。

## 七、与 Geometry Adapter 的关系

**Geometry Adapter** 和 **Spatial Calibration** 是两个不同层次的「适配」：

| | Geometry Adapter | Spatial Calibration |
|--|-----------------|---------------------|
| 输入 | MediaPipe detection | 三点锚点 + RendererConstants |
| 输出 | adjustments + render_baseline | affine_matrix |
| 适配对象 | 眼睛形状参数 | 画布空间位置 |
| 抽象层次 | **What** to render | **Where** to place |
| 数据流 | 检测 → 模板参数 → RendererConstants | 锚点 + constants → 仿射矩阵 |

两者串联使用：

```
MediaPipe → [GeometryAdapter] → adjustments → SpeciesTemplate → RendererConstants
                                                                    │
                              anchors → [SpatialCalibration]  ←────┘
                                            │
                                    affine_matrix → cv2.warpAffine
```

## 八、验证标准

| 检查项 | 标准 | 检测方法 |

## 十、常见问题

### Q1：为什么不用透视变换（cv2.getPerspectiveTransform）？

三点确定一个仿射变换（6 自由度），四点才能确定透视变换（8 自由度）。对于眼区这种近似平面的区域，仿射变换已经足够：

- 面部在照片中近似正面或轻微旋转
- 仿射变换可以表达：平移（2）、旋转（1）、缩放（1）、剪切（2）= 6 自由度
- 透视变换需要四点，增加标定复杂度

### Q2：为什么输出是 690×361 而不是其他尺寸？

690×361 的宽高比（~1.91:1）兼容扩散引擎的 latent space 尺寸（通常为 8 的倍数 ≈ 688→690，360→361 有 1px 奇数余量用于中心定位）。

### Q3：手动标定 JSON 已废弃？

[`load_project_spatial_calibration()`](gaze_engine/render/spatial_calibration.py:270) 标记为 `[DEPRECATED]`——不再落盘 JSON 文件，每次从 MediaPipe 检测 + renderer_constants 实时计算仿射矩阵。保留该函数仅为兼容旧项目读取。
