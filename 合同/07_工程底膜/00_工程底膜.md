### 1.1 本文件管什么

### 1.4 工程底膜的定义

**工程底膜（Engineering Base Mesh）** = 一条由 12 通道脉冲驱动的、经空间校准对齐到客户真人面部的、690×361 像素的仿射渲染 MP4 视频。

它与「底膜 Prompt」共同构成扩散引擎的双路 conditioning 输入。

### 1.5 本管线在全流程中的位置

```

                                       │
```

#### 2.2.2 Direction A（2026-06）绝对映射

[`geometry_adapter._human_adjustments_strict()`](gaze_engine/render/geometry_adapter.py:400) 实现了 **Direction A 绝对映射**——将照片中眼部尺寸直接映射到 1024×1024 标准画布空间：

```python
# 缩放因子：标准眼距 / 检测眼距
scale_1024 = STANDARD_EYE_DIST / det_eye_dist

# 映射后的眼宽（像素，在 1024 画布空间）
mapped_eye_w = det_eye_size * scale_1024

# 模型标准眼宽 = 150px（标准画布中一只眼占 150px）
model_eye_w = STANDARD_EYE_SIZE / 2  # = 150

# eye_size 缩放因子 = 映射眼宽 / 模型眼宽
eye_size_factor = mapped_eye_w / model_eye_w

# 眼高类似：mapped_eye_h / model_eye_h
# 虹膜半径类似：mapped_iris_r / model_iris_r
# 瞳孔缩放类似：mapped_pupil_d / model_pupil_d
```

**核心公式**：所有模板参数 = `photo_measurement × scale_1024 / model_standard`

参数范围：

| 参数 | 范围 | 默认（模型标准） |
|------|------|------------------|
| `eye_size` | [0.6, 1.8] | 1.0 |
| `eye_aspect` | [0.6, 1.4] | 1.0 |
| `iris_size` | [0.4, 2.0] | 1.0 |
| `pupil_size` | [0.4, 2.0] | 1.0 |

#### 2.4.2 抛物线公式

眼睑曲线由标准抛物线描述：

```
y = peak × (1 − (2t − 1)²),  t ∈ [0, 1]

性质：
  t=0     → y=0    （左眼角）
  t=1     → y=0    （右眼角）
  t=0.5   → y=peak （最高点）
```

**上眼睑**：从左到右，steps=40，每步一个顶点
**下眼睑**：从右到左，steps=40，每步一个顶点

#### 2.4.3 12 通道驱动逻辑

[`deform()`](gaze_engine/render/affine_renderer.py:188) 方法接受 12 通道脉冲 dict，按以下规则修改顶点：

| 通道 | 影响 | 公式 |
|------|------|------|
| `pupil_x` | 瞳孔水平位移 | 直接偏移 iris 顶点 |
| `pupil_y` | 瞳孔垂直位移 | 直接偏移 iris 顶点 |
| `blink` | 上眼睑下降 + 下眼睑上升 | `upper_peak -= blink × BLINK_DROP`，`lower_peak += blink × BLINK_DROP` |
| `eyebrow` | 眉毛垂直偏移 | 眉顶点按 `eyebrow × BROW_RAISE_AMP` 偏移 |
| `pupil_scale` | 瞳孔缩放 | iris 顶点按 `pupil_scale` 缩放 |
| `iris_scale` | 虹膜缩放 | iris 顶点按 `iris_scale` 缩放 |
| `cornea_bulge` | 角膜隆起（眼球突出） | iris 顶点沿 z 偏移 |
| `squint` | 下眼睑上抬 | `lower_peak += squint × SQUINT_LIFT` |
| `brow_raise` | 眉上抬 | 眉顶点额外上抬 |
| `lid_upper` | 上眼睑独立微调 | `upper_peak += lid_upper × LID_UPPER_AMP` |
| `lid_lower` | 下眼睑独立微调 | `lower_peak += lid_lower × LID_LOWER_AMP` |
| `eye_gloss` | 高光亮度 | 修改高光区域 alpha |

#### 2.4.4 关键常量

[`affine_renderer.py`](gaze_engine/render/affine_renderer.py) 类级常量：

| 常量 | 值 | 含义 |
|------|-----|------|
| `UPPER_PEAK` | 45 | 上眼睑抛物线峰值（像素，标准模型） |
| `LOWER_BOT` | 38 | 下眼睑抛物线峰值（像素，标准模型） |
| `BLINK_DROP` | 40 | 眨眼时上眼睑下降幅度 |
| `SQUINT_LIFT` | 25 | 眯眼时下眼睑上抬幅度 |
| `BROW_RAISE_AMP` | 15 | 眉毛上抬幅度 |
| `EYE_W` | 150 | 单眼宽度（标准模型） |

| `OUTPUT_H` | 361 | 渲染输出高度 |

#### 2.4.5 渲染管线

```
render_frame(channels)
    │
    ├─► EyeMesh.deform(channels) → 顶点位移
    │
    ├─► _parametric_eyelid(mesh, channels) → 眼睑像素
    │       │
    │       ├─► 上眼睑：for t in 0..40: y = peak*(1-(2t-1)²)
    │       └─► 下眼睑：for t in 0..40: y = peak*(1-(2t-1)²)
    │
    ├─► 虹膜 + 瞳孔圆形绘制（cv2.circle）
    │
    ├─► 眉毛线段绘制（LINE_8 硬边）
    │
    └─► 返回 (361, 690, 3) uint8 RGB
```

#### 2.4.6 0-noise（LINE_8）策略

所有绘制操作使用 `cv2.LINE_8`（非抗锯齿）而非 `cv2.LINE_AA`。

**原理**：帧间微颤（14Hz micro_jitter）在抗锯齿模式下会导致边缘像素值在相邻帧间 ±1 变化，对扩散引擎产生不必要的噪声。硬边（LINE_8）确保所有像素值 ∈ {0, 255}，帧间完全相同。

### 2.5 端到端数据流

[`delivery_pipeline.mediapipe_to_opencv_lines()`](gaze_engine/delivery/delivery_pipeline.py:174) 聚合了上述全部步骤：

```python
def mediapipe_to_opencv_lines(
    photo_bgr: np.ndarray,
    emotion: str,
    channels_150: dict[str, list[float]],
    species: str = "human",
    fps: int = 30,
) -> tuple[np.ndarray, np.ndarray, dict, dict]:

    # Step 1: MediaPipe 检测
    detection = detect_human_face_mediapipe(photo_bgr)

    # Step 2: 几何适配（fail-fast）
    adapt_result = adapt_geometry(detection, species, photo_bgr)

    # Step 3: 模板 + 基线 → renderer_constants
    template = species_template(adapt_result.adjustments)
    renderer_constants = RendererConstants.from_template(template)
    apply_render_baseline(renderer_constants, adapt_result.render_baseline)

    # Step 4: 空间校准
    calib = compute_spatial_calibration(
        adapt_result.anchors, renderer_constants)

    # Step 5: 逐帧渲染
    renderer = AffineRenderer(renderer_constants)
    frames = []
    for t in range(150):
        ch = {name: channels_150[name][t] for name in CHANNEL_NAMES}
        raw_frame = renderer.render_frame(ch)
        warped = calib.warp(raw_frame)  # 1024 → 690×361
        frames.append(warped)

    # Step 6: ffmpeg → MP4
    mp4_path = renderer.render_batch(frames, out_dir)
```

## 三、关键决策

### 3.1 关键决策一览

| ID | 决策 | 选择 | 理由 |
|----|------|------|------|
| D1 | 检测方案 | MediaPipe Face Mesh 468 点 | 开源、轻量、实时、面部地标准确 |
| D2 | 几何映射策略 | Direction A（2026-06）绝对映射 | 直接使用照片测量值，不依赖品种模板 |
| D3 | 错误处理 | Fail-fast（raise ValueError） | 不放行低质量检测，避免无声缺陷 |
| D4 | 空间校准 | cv2.getAffineTransform（3 点） | 足够表达眼区仿射变换，比透视更稳定 |
| D5 | 渲染线条 | cv2.LINE_8（非抗锯齿） | 帧间 0-noise，扩散引擎稳定性 |
| D6 | 眼睑曲线 | 标准抛物线公式 | 精确几何基础，参数化驱动 |
| D7 | 绘制顺序 | 虹膜 → 瞳孔 → 眼睑 → 眉毛 → 高光 | 正确遮挡关系 |
| D8 | 输出分辨率 | 690×361 | 扩散引擎 latent 对齐（约 512 倍数） |
| D9 | 编码 | H.264 CRF 18 | 视觉无损，扩散引擎可接受 |
| D10 | 物种 | 仅人类 | 猫/狗不再维护，检测架构已移除 |

### 3.2 关键决策详解

#### D2：Direction A（2026-06）绝对映射

旧方案（Direction B）依赖预设品种模板，需要手动选择「类似的眼睛形状」。Direction A 直接从 MediaPipe 检测值计算所有模板参数：

```
eye_size   = f(detected_eye_width  × scale_1024)
eye_aspect = f(detected_eye_height × scale_1024 / detected_eye_width)
iris_size  = f(detected_iris_r     × scale_1024)
pupil_size = f(detected_pupil_d    × scale_1024)
```

这一变化从 `gaze_engine/render/geometry_adapter.py` 的 `_human_adjustments_strict()` 开始实施。

#### D3：Fail-fast

任何缺失字段 → `raise ValueError`，不提供默认值回退。这是为了防止无声缺陷——扩散引擎训练时如果接收到「默认值底膜」，会学会「默认值 = 正确」，导致后续真实底膜效果异常。

#### D5：0-noise（LINE_8）

抗锯齿（LINE_AA）在微颤（14Hz ±0.5px）时产生帧间像素值波动 ±1~3。在 150 帧 MP4 中，每秒 12 轨通道值 150 次变化 × 每帧 ~2000 边缘像素 → ~300000 次帧间噪声事件。LINE_8 将所有边缘限制为 {0, 255}，帧间变化降为 0。

### 3.3 历史教训

| 教训 | 描述 | 修复 |
|------|------|------|
| H1 | 硬编码默认值导致无声缺陷 | 删除所有默认值，fail-fast |
| H2 | 抗锯齿引入帧间噪声 | 全部改为 LINE_8 |
| H3 | 多物种模板增加复杂度且无客户需求 | 只保留 human |
| H4 | `_shared/` 路径混乱 | 归入 `gaze_engine/render/` |
| H5 | 三点标定（人肉点击）引入误差 | 改为 MediaPipe 自动检测 |
| H6 | 照片眼高 < 25px 时检测不可靠 | 增加 25px 阈值，< 则 raise |

## 六、增量修改原则

1. **不改抛物线公式** — 眼睑曲线的基础公式（`y = peak × (1 − (2t−1)²)`）不可修改，更改需全组审批
2. **不改输出分辨率** — 690×361 与扩散引擎 latent 对齐，更改需同时修改扩散引擎
3. **不改 LINE_8** — 改为抗锯齿需重新验证 0-noise
4. **不改 fail-fast** — 添加默认值回退需合同变更 + 扩散引擎重新训练
5. **不添加新物种** — 架构仅保留 human，添加新物种需重新设计 geometry_adapter
6. **所有常量修改必须在代码 + 本文件同步更新**
