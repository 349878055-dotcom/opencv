## 一、门户勾选：情绪 + 品种 → styled

```text
通用狗情绪（10 选 1）  +  狗品种（1 个，可扩展 N 个）
        ↓
组合定稿曲线 = styled  12 通道 × 150 帧
```

> **情绪写「戏怎么演」；品种写「这张脸怎么吃戏」。**  
> 一种情绪 JSON **全狗种共用**；改情绪 **只改一处**，各品种用 **base+scale×pulse** 自动跟上。

| 环节 | 输入 | 输出 | 定稿合同 |
|------|------|------|----------|
| ① 情绪 | `情绪包/dog/{情绪}.json` | E(t) + **pulse** | `02_情绪与能量/狗/{情绪}.md` |
| ② 品种 | `风格包/dog/{品种}/style.json` | base_offset / scale_factor | **下文品种表 → `{品种}.md`** |
| ③ 合成 | pulse + 品种 | **styled** | **本文 §二** |
| ④～⑤ | styled | prior → 02 → MP4 | `dog_pipeline` · `affine_renderer` |

**别去改**：某一情绪 macro → `02/狗/`；某一品种 blink 基线 → `{品种}.md`；客户标定 → 客户资产库。

## 二、合成公式与 pulse / styled

| 曲线 | 维度 | 含品种？ |
|------|------|----------|
| **E(t)** | 150 | ❌ 仅情绪 |
| **pulse** | 12×150 | ❌ 情绪 + 狗 PAD |
| **styled** | 12×150 | ✅ 情绪×品种 |

```text
E(t)         = build_energy_envelope(macro, hold_seg)
pulse[ch,t]  = DogCompile(E(t), PAD, …)
styled[ch,t] = clamp01( base_offset[ch] + scale_factor[ch] × pulse[ch,t] )
```

「贵宾委屈眼的能量曲线」= **styled**，不是单独 E(t)。

| | pulse（S4） | styled（S5） |
|--|-------------|--------------|
| 输入 | E(t)+PAD+编译 | pulse + style.json |
| 品种 | ❌ | ✅ base + scale×pulse |
| 只抬 base[blink] | 节奏不变 | 脸更阖 |
| 只抬 power | 全轨 pulse 变猛 | 各品种同比例跟 |

品种 **不参与** `build_energy_envelope()`，**不改** t_peak / hold 帧轴。

**几何**（并行）：`SpeciesTemplate × breed.template_scales × 客户标定` → 底膜 MP4，不写入 E(t)。

## 三、改法（保证改情绪全品种跟上）

```text
styled_breed(ch,t) = base_breed[ch] + scale_breed[ch] × pulse_new(ch,t)
```

| 操作 | 改 | 不改 |
|------|-----|------|
| 委屈更软 | `02/狗/委屈·幼犬眼.md` + 情绪 JSON | 各品种 `style.json` |
| 贵宾更半阖 | `poodle_giant.md` + style + breed_matrix | 委屈 JSON |

**禁止**：`{情绪}_{品种}.json`；品种里改 E(t)；在 style 里写「仅某情绪」的 macro。
