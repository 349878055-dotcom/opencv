## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **一套滑杆走天下** | 施压、可怜、魅惑共用同一 6+3 结构；差别在默认数，不在控件名 |
| **LLM 友好** | 全是 **0～100 整数**；改动用 **±步进**（默认 5），禁止浮点与自由文本进 compile |
| **Python 友好** | 每根滑杆有固定 `id`、线性或分段公式、作用帧区间；可单测 |
| **与验收对齐** | 每根滑杆写明影响哪段戏、哪几条通道；禁区见本文 §10 |

## 2. 数据包 `SliderPacket`（JSON）

```json
{
  "schema": "slider-packet-v1",
  "emotion": "s01_pressure",
  "style": "cold",
  "macro": {
    "push": 82,
    "power": 88,
    "speed": 90,
    "steady": 92,
    "grip": 88,
    "outro": 28
  },
  "hold_seg": {
    "shape": "flat",
    "pulse_rate": 0,
    "pulse_depth": 0,
    "swell": 0
  },
  "pad": {
    "P": -0.2,
    "A": 0.7,
    "D": 0.6,
    "position": "偏不悦/压抑 · 高激活 · 偏支配/压人"
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `schema` | string | ✅ | 固定 `slider-packet-v1` |
| `emotion` | string | ✅ | 情绪 id，如 `s01_pressure` |
| `style` | string |  | 风格 id，如 `cold`；默认 `default` |
| `macro` | object | ✅ | 6 根宏观滑杆，各 0～100 |
| `hold_seg` | object |  | 盯住段花纹；**v1 compile 可忽略**，须写入便于 LLM 表达魅惑 |
| `pad` | object |  | **03 情绪坐标 (PAD)** `(P,A,D)` ∈ [-1,1]；真源 **`预设资产/情绪包/{species}/*.json`**（与 macro 同包）；门户/API 调取，不在网页展示 |

**三层分工（定稿口诀）**：

```text
macro + hold_seg  →  E(t)        （02 情绪与能量 · 演多重 · 时间轴）
pad (P, A, D)     →  pad_scale   （03 情绪坐标 · 哪类戏 · 通道性格）
style.json        →  styled      （05 风格化 · 谁的脸 · 品种/人格）
```

## 3. 宏观六滑杆（`macro`）

**时间轴分工**（与 `01_十二通道与全量帧格式.md` §4 一致）：

| 阶段 | 帧（S01 模板参考） | 主要吃哪些滑杆 |
|------|-------------------|----------------|
| 蓄力 / 静 | 0～14 | 模板为主 |
| 起 | 约 14～25 | `speed` `power` `push` |
| 盯住 | 约 25～90 | `steady` `grip` + **`hold_seg`** |
| 收场 | 约 90～149 | `outro` |

### 3.1 定义表

| id | 客户能懂的话 | LLM 关键词示例 | 0 | 100 | Python 映射（v1） |
|----|-------------|----------------|---|-----|-------------------|
| `push` | 往哪使劲 | 往里收、外放、施压 | 内收 `in` | 外放 `out` | `direction`；阈值 50 |
| `power` | 力度 | 狠、轻、压死人 | 幅度×0.72 | ×1.18 | `weight` 线性 + 全轨幅度 |
| `speed` | 快慢 | 急、缓、瞬间 | 戏眼延后 | 戏眼提前 | `time`；`peak` 帧 ±4 |
| `steady` | 盯得稳 | 飘、钉死、对视 | 空间散 | 直盯 | `space`；盯住段 jitter 权重 |
| `grip` | 定得住 | 泄、憋住、松劲 | 盯住泄 | 盯住平 | `flow`；盯住段值衰减 |
| `outro` | 收场 | 快落、慢收、留尾 | 快 `fast` | 慢 `slow` | `ending`；阈值 50 |

> **命名**：`grip`（定得住）≠ `hold_seg`（盯住段花纹），避免和「按住」混淆。

### 3.2 LLM 改刻度规则

| 用户说法 | 步进 Δ | 约束 |
|----------|--------|------|
| 一点 / 稍微 | ±5 | 单轮单键建议只改 1～2 项 |
| 一些 / 明显 | ±10 | |
| 很多 / 狠一点 | ±20 | 仍 clamp 0～100 |
| 「林青霞那种瞪人」 | 写整包或 `emotion`+`style`，勿编造帧号 | 映射到 `s01_pressure` + 高 power/speed/steady/grip |

输出只允许：

- 绝对值：`{"macro": {"power": 90}}`
- 增量：`{"macro_delta": {"power": "+10"}}`（由程序合并并 clamp）

## 4. 盯住段三滑杆（`hold_seg`）— 表达「中间怎么变」

| id | 客户能懂的话 | 取值 | 说明 |
|----|-------------|------|------|
| `shape` | 盯住段形状 | `flat` `decay` `swell` `pulse` `tremble` | 平顶 / 泄 / 慢起慢落 / 一阵一阵 / 发颤 |
| `pulse_rate` | 勾得多密 | 0～100 | 仅 `pulse` 有效；0=无脉冲 |
| `pulse_depth` | 一波多深 | 0～100 | 脉冲幅度 |
| `swell` | 段内起伏 | 0～100 | `swell` 形：慢强再弱 |

**魅惑默认**：`shape=pulse`，`pulse_rate` 40～60，`pulse_depth` 35～55。  
**施压默认**：`shape=flat`，其余 0。

> **实现状态**：v1 `pulse_compile` 仍以宏观缩放为主；`hold_seg` **必须先入 schema**，compile v2 按本表写盯住段关键帧。

## 5. 十六预设（操作台左侧 · 必须先点）

**不是新滑杆** = 一组默认 `SliderPacket`（`emotion` 字段 = 下表预设名）。  
客户/LLM：**先点预设，再拖起/动/收**；禁区范围见 §10。

| 分组 | 预设 | 戏感要点 |
|------|------|----------|
| **压·慑** | 施压·凝视 | 外放、急、猛、平顶钉死 |
| | 冷压·决心 | 更狠更钉，起略缓 |
| | 威慑·一瞬 | 极急、快收 |
| | 怒视·压人 | 高 push、平顶、中快收 |
| | 鄙夷·冷瞥 | 外放但轻力、快收 |
| **悲·怯** | 可怜·委屈 | 内收、轻、颤 |
| | 要哭未哭 | 更轻更慢、颤 |
| | 崩溃·泄劲 | decay 下泄、快断 |
| | 哀求·仰望 | 内收、慢收留韵 |
| | 惊惧·一怔 | 急、颤、快收 |
| | 空竭·死心 | 轻、decay、慢散 |
| **媚·勾** | 魅惑·勾人 | pulse、高粘、慢收 |
| | 纯甜·含情 | 轻甜脉冲、很粘 |
| | 媚杀·一眼 | 深脉冲、较猛 |
| | 若即若离 | swell 慢拱、飘 |
| | 打量·玩味 | 慢拱、中等粘 |

**自检**（改预设后）：

```bash
python3 -c "from gaze_engine.control_surface import validate_all; print(validate_all() or 'OK')"
```

工作台应显示「预设 16 个 · 校验通过」。旧 id 情绪包见 `slider_schema.EMOTION_DEFAULTS`（如 `s01_pressure`），**新戏以本表 16 名为准**。

**注意**：整段 5 秒多轮戏拆多个包，不在一包里硬拧两种情绪。

## 10. 滑杆禁区 L1（`SliderPacket` · fix 弹回）

> **预设中心值**：`gaze_engine/control_surface.py`（工作台左侧 16 预设）  
> **禁区半径与 G 条**：`gaze_engine/slider_bounds.py`（改 §10.3 后同步该文件）  
> **代码**：`packet_finalize.py` · 工作台 `slider_forbidden_bounds.js`（`scripts/export_slider_forbidden_js.py` 导出）  
> **对齐**：`tools/能量工作台.html` ① 滑杆 · 起/动/收 三区

### 10.1 客户怎么用

1. **必须先点左侧 16 预设** = 本戏数值盒。  
2. 只拖滑杆；越界 → **悄悄弹回**。  
3. 无预设：仅全剧种 **G1～G8**。

### 10.2 戏种与 `hold_seg.shape`

| 戏种 | 预设 | 允许 `shape` |
|------|------|-------------|
| **压·慑** | 施压、冷压、威慑、怒视、鄙夷 | 仅 `flat` |
| **悲·怯** | 可怜、要哭、崩溃、哀求、惊惧、空竭 | `tremble` `decay` |
| **媚·勾** | 魅惑、纯甜、媚杀、若即若离、打量 | `pulse` `swell`（按预设） |

每预设 `[min,max]` → JSON `presets.{名}`。

### 10.3 全剧种硬禁区 G1～G8

| 编号 | 条件 | fix |
|------|------|-----|
| G1 | 六杆全 42～58 | 弹回预设默认 macro |
| G2 | speed≥82 且 power≤28 | 抬 power |
| G3 | power≥75 且 steady≤28 | steady≥45 |
| G4 | steady≥80 且 grip≤25 | 抬 grip |
| G5 | flat + pulse_rate≥1 | pulse 清零 |
| G6 | 非 pulse + pulse_depth≥1 | pulse 清零 |
| G7 | speed≥85 且 outro≥75 | 压 outro |
| G8 | push≤25 且 power≥80 | 压 power |

### 10.4 变更

改 **§10.2 / §10.3** 或 `slider_bounds.py` 里 `MOOD_GROUPS` / `GLOBAL_FIXES` → 运行 `python3 scripts/export_slider_forbidden_js.py`。
