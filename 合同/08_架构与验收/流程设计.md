## 一、核心架构：双模驱动 (Dual-Stream Pipeline)

```
┌─ 逻辑定义层 (The Core Logic) ─────────────────┐
│  12 通道物理约束参数 → JSON / Python Class     │
│  物理约束器：瞳孔缩放↔眼睑开合的联动公式         │
│  人格数据库：Personality_Database.json          │
└──────────────────────────────────────────────┘
        │
        ▼
┌─ 视觉封装层 (The Articulator) ────────────────┐
│  ┌─ 工程底模 (Asset for Diffusion) ──┐         │
│  │  RGB 三色分离，0-noise，闭合路径    │         │
│  │  R=眼, G=眉, B=瞳孔               │         │
│  └──────────────────────────────────┘         │
│  ┌─ 艺术皮肤 (Visual Skin for Client) ─┐      │
│  │  Canvas 渲染，Bloom/变径/手绘质感    │      │
│  │  加法策略：不碰底层坐标，只叠加装饰   │      │
│  └──────────────────────────────────┘         │
└──────────────────────────────────────────────┘
        │
        ▼
┌─ 输出分流引擎 (The Stream Splitter) ──────────┐
│  Stream 1 → Raw_Asset.png/mp4  (给 Wan 引擎)  │
│  Stream 2 → Preview_View.mp4 (给客户预览)     │
│  底层控制点（12 通道数据）永远不变              │
└──────────────────────────────────────────────┘
```

## 三、Wan 扩散引擎标准资产定义

### 色彩协议（三色分离）

| 通道 | 颜色 | 定义 | 约束 |
|------|------|------|------|
| R | RGB(255,0,0) | 眼部主骨架 | 必须闭合路径 |
| G | RGB(0,255,0) | 辅助骨架（眉） | 允许非闭合 |
| B | RGB(0,0,255) | 瞳孔区 | 实心圆/逻辑区域 |

### Metadata JSON 格式

```json
{
  "schema": "wan-control-mesh-v1",
  "emotion": "魅惑·勾人",
  "persona": "天选者_大祭司",
  "channels_12": { ... },
  "frame_count": 150,
  "fps": 30
}
```
