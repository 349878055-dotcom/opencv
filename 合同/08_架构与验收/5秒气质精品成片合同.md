# 5 秒气质 · 精品成片验收合同

> **范围**：C 端第一步交付 —— **5 秒内让人「更有气质」**；定稿 **Wan 全量渲染** 必须达到 **精品**，否则整链失败。  
> **不写**：音乐 feed / 脉冲推送语法书 / 关联度推荐（见后续独立合同）。  
> **状态**：P0 结构验收已挂钩现有脚本；**精品 P1 人工审定** 为当前第一优先级。

**兄弟合同**：[`狗150帧全量编译合同_上篇.md`](狗150帧全量编译合同_上篇.md) · [`扩散Prompt全链路方案_导读.md`](扩散Prompt全链路方案_导读.md) · [`工程底膜合同.md`](../06_工程底膜/工程底膜合同.md) · [`流程设计.md`](流程设计.md)

## 零、导读（30 秒读懂）

### 0.1 一句话

**气质 = 眼神有戏 + 节奏对 + 像自己的宠物/脸 + 成片不丢人**；不是「能播放」，是 **愿意转发**。

### 0.2 两档交付（产品顺序）

| 档位 | 用户感知 | 耗时目标 | 工程 |
|------|----------|----------|------|
| **试气质** | 「感觉对不对」 | 秒～十几秒（后续 neon / 轻量 Wan） | 同 revision 的预览链 |
| **定稿精品** | 「可以发抖音/当作品集」 | **~20 分钟可接受，但只跑一次** | Wan 全量 150 帧 |

⚠️ **20 分钟不是原罪；20 分钟出垃圾 = 产品失败。**

### 0.3 合格链（必须同源）

```text
客户参考图 + 情绪预设 + 滑杆微调
        ↓  S0～S7（见狗150帧上篇）
02_烘焙 + 06_工程底膜.mp4 + 04_Prompt（同 revision）
        ↓  Wan I2V 全量
成片 MP4（150 帧 @ 30fps ≈ 5s）
```

**03 / 04 / 02 必须同一 `revision`**；换 seed 定稿前须锁定滑杆包。

## 一、概述（What）

### 1.1 本合同管什么

| ✅ 管 | ❌ 不管 |
|------|--------|
| **气质** 的验收定义（眼/节奏/像/质感） | 音乐编译、主导情绪 feed |
| 5s 时长、150 帧与 E(t) 四段对齐 | 长片 stitch / 口型 |
| 试气质 vs 定稿精品 两档标准 | ComfyUI 节点 UI 布局 |
| Wan 全量 **精品线** 参数与否决项 | 训练 LoRA / 换脸 Deepfake |
| 门户/CLI 定稿前检查清单 | 关联度内容推荐 |

### 1.2 管线位置

```text
上游：预设 JSON + 客户参考图 + SliderPacket（S0～S7 → 02）
本合同：03 + 04 + Wan → 5s 精品 MP4
下游：（可选）归档客户资产库 / 导出包；音乐编译为独立阶段
```

### 1.3 第一战线（MVP 审定顺序）

1. **物种**：狗（门户主路径）  
2. **情绪**：[`委屈·幼犬眼`](../02_情绪与能量/狗/委屈·幼犬眼.md) 定稿后扩其余 9 情绪  
3. **成功标准**：**连续 3 次** 定稿 Wan 输出均过 §5.2 **精品 P1**（同情绪、可不同 seed）

## 二、理论依据（Theory）

### 2.1 为什么 5 秒、为什么「气质」

```
① 短视频 hook 有效时长 ≈ 3～5s（抖音/小红书传播约束）
② 人类对「有没有气质」的判断 >80% 来自眼区与时序（社交注意力理论）
③ AI 视频最大差评源 = 死鱼眼 + 情绪弧 flat（与关联推荐无关）
④ 150 帧 @ 30fps ≈ 5s 与 E(t) 起—蓄—盯—收 同轴（见 全量帧指令集规范）
```

### 2.2 Wan 双路 conditioning 依据

| 输入 | 作用 | 气质缺了会怎样 |
|------|------|----------------|
| **03 工程底膜 MP4** | 像素级 **怎么动**（12 通道几何） | 形对但 **无戏** |
| **04 Prompt**（含节拍表） | 语义 **在演什么情绪** | 动但 **不像委屈/像别种** |
| **客户参考图（I2V）** | **像谁**（identity） | 气质对但 **不是我家狗** |

**气质 = 三路同源 + 02 数值合格**；不是单押 Prompt 或单押热 BGM。

### 2.3 「精品」不是普世好听

```
⑤ 热歌/普世好听（Chart 逻辑）常 **劫持** 当下 dominant → 不纳入本合同
⑥ 本合同只验：**与锁定情绪 preset 读感一致 + 5s 内完整情绪弧**
```

### 2.4 产品形态：气质向、无大动作（非禁止）

本产品 **天然是近景、小幅度、气质向的 5 秒表演**，不是全身动作片或 UE 级数字人。

| 层 | 范围 | 说明 |
|----|------|------|
| **精控区** | 眼眉（狗/猫含耳）12 通道 | 跟 E(t) 与节拍表走；**产品核心价值** |
| **自然发挥区** | 眉眼以外（毛发、光照、微姿态） | Wan 可补；情绪起伏须与控制序列 **同拍对齐** |
| **产品边界** | 不做全身 choreography | 非规则禁止跑跳，而是 **不靠大动作交付气质** |

```
⑦ 控制真源在眼眉 → 戏在「这一眼」，不在全身编排
⑧ 5s + 单张 I2V → 大动作易崩脸、抢戏、难验收
⑨ 客户场景 = 宠物特写 / IP 表情 / 人像 hook → 天然无大动作
```

**叙事分工**：客户 action 可含「跑回笼子再回头看」——**跑** 为 Wan 语义氛围；**回头看那一眼** 为本产品精控与验收对象。  
正向 Prompt 真源：[`assembler.py`](../../gaze_engine/pomot/assembler.py) `_RHYTHM_LINES`（「眼耳/眉眼以外可自然发挥」）。  
否决项：**乱动脱节**（负向 N1～N3），非「出现任何肢体位移」。

## 三、为什么这样做（Why）

### 3.1 关键决策

| 决策 | 备选 | 选择理由 |
|------|------|----------|
| **第一步只做 5s 气质视频** | 同时上音乐 feed | 20min 精品未达标则音乐无意义；顺序保证 |
| **定稿必须 Wan 全量 150 帧** | 只交付底膜/neon | C 端要 **像真成片**；底膜 alone 不算气质交付 |
| **试气质与定稿分档** | 每次全量 Wan | 全民不能等 20min 试感觉；定稿才跑全量 |
| **精品 = 人工 P1 + 结构 P0** | 纯自动指标 | 气质含「读感」，必须人眼否决权 |
| **音乐延后** | 视频音乐同发 | 控制面未稳前不扩输出端 |

### 3.2 历史教训

| ⚠️ 坑 | 规则 |
|------|------|
| 预览像 demo、成片像另一物种 | 预览链必须与成片 **同 preset / 同 E(t) 方向** |
| 02 过了但 Wan 死鱼眼 | P1 必查 **盯住段 blink/pupil 是否有变化** |
| 04 与 03 revision 不一致 | 定稿前 **P0 脚本必过** |
| 为省时间砍 steps → 廉价 AI 感 | 定稿 **不得** 低于 §4.3 `wan_final` 阈值 |
| 一次 seed 定生死 | 允许预览档 **多 seed**；定稿 **选定 seed 写入归档** |

## 四、怎么实现（How）

### 4.1 交付物定义

| 文件 | 规格 | 气质相关 |
|------|------|----------|
| `02_烘焙_*.json` | 12×150 keyframes | 眼有戏的数据真源 |
| `06_工程底膜.mp4` | RGB 三色，150 帧 | Wan 几何控制 |
| `04_Prompt.txt` | 五段 + Wan 正负向 | 情绪语义 |
| **成片 `*.mp4`** | 5s，≥480p，30fps | **本合同终验对象** |

### 4.2 气质四维（验收用）

| 维度 | 含义 | 主要数据来源 |
|------|------|--------------|
| **眼有戏** | 5s 内可见起→盯→收，非 flat 死鱼眼 | 02 blink/pupil + 03 预览 |
| **像** | 像上传参考的个体，品种/脸不漂 | I2V 参考图 + 品种 style |
| **节奏对** | 与 preset 读感一致（如委屈=慢起、长盯） | E(t) timing + 05 节拍表 |
| **成片质感** | 毛发/光不廉价、不闪不崩 | Wan 全量参数 + seed |

### 4.3 Wan 渲染档位（工程真源，定稿不得下修）

**预览档 `wan_preview`**（试气质，可多次）：

| 参数 | 值 |
|------|-----|
| frames | 49～65（约 1.6～2.2s） |
| steps | 15～20 |
| resolution | 480p（832×480 或合同等价） |
| model | `wan2.1-i2v-14b-480p`（Q3/Q4 量化可） |

**定稿档 `wan_final`（精品，客户确认后单次）**：

| 参数 | 值 |
|------|-----|
| frames | **150** |
| fps | **30** |
| steps | **≥40**（审定前不得低于 40） |
| resolution | **480p 定稿**；720p 为 P2 扩展 |
| model | 与预览 **同模型族**（保证气质方向一致） |
| GPU | 建议 A100/H100；4090 允许但须过 P1 |

### 4.4 定稿前强制检查（portal / CLI）

```text
1. python3 scripts/verify_dog_150_compile_contract.py   # 02 结构
2. python3 scripts/verify_diffusion_prompt_contract.py    # 04/05 链
3. 03 revision == 02 revision == 04 文件头 revision
4. 人眼过 03 底膜预览（5s）— 眼区有动
5. 选定 seed → 跑 wan_final → 人眼 P1 精品表
```

## 五、检查点（Checkpoints）

### 5.1 P0 结构（不过则禁止送 Wan 定稿）

| 检查项 | 测试方法 | 合格标准 | 优先级 |
|--------|---------|---------|--------|
| 02 烘焙 1800 keyframes | `verify_dog_150_compile_contract.py` | exit 0 | P0 |
| 04 五段 + 节拍 12 通道 | `verify_diffusion_prompt_contract.py` | exit 0 | P0 |
| revision 同源 | 比对 02/03 meta/04 头 | 字符串一致 | P0 |
| 150 帧 / 30fps | 02 `frame_count` | =150 | P0 |
| E(t) 四段非塌 | `export_envelope_series` 或 baked meta | peak>0.05 且收段→0 | P0 |
| 03 MP4 可解码 | ffprobe | 150 frames，无全黑 | P0 |

### 5.2 P1 气质 · 精品（定稿 Wan 必过；任一否决 = 失败）

| 检查项 | 测试方法 | 合格标准 | 优先级 |
|--------|---------|---------|--------|
| **眼有戏** | 人眼全片 5s | 至少 **1 次** 明显 blink 或 pupil 位移；盯住段非「死鱼眼」 | P1 |
| **情绪弧** | 人眼 + 对照 preset 读感 | 起—盯—收 **方向** 与 [`02_情绪与能量/狗/`](../02_情绪与能量/狗/) 该情绪 md 一致 | P1 |
| **像** | 与客户参考对比 | 同一只狗/同品种气质；**不换脸感** | P1 |
| **不廉价** | 人眼 | 无严重塑料毛、无大面积 glitch、无通道撕裂 | P1 |
| **稳定** | 人眼逐帧扫 | 无 ≥3 帧连续 identity 跳变 | P1 |
| **可转发** | 制作人自评 | 「愿当作作品集/朋友圈」— **一票否决权** | P1 |

**精品否决语（出现即 FAIL）**：

- 「像 cheap AI / 像 PPT 动图」  
- 「眼神空的 / 和选的委屈没关系」  
- 「不像我家狗」  
- 「等了 20 分钟不值」

### 5.3 P2 增强（非 MVP 阻断）

| 检查项 | 测试方法 | 合格标准 | 优先级 |
|--------|---------|---------|--------|
| 720p 定稿 | Wan 全量 | 在 24GB+ GPU 可跑且 P1 仍过 | P2 |
| 人类物种气质 | human pipeline | 同表 P1 适用于 [`02_情绪与能量/人/`](../02_情绪与能量/人/) | P2 |
| 连续 3 次精品 | 同 preset 不同 seed | 3/3 过 P1 | P2 |

### 5.4 MVP 通过定义（项目级）

```text
✅ 狗 · 委屈·幼犬眼 · 客户参考图路径
✅ 连续 3 次 wan_final 输出过 §5.2 P1
✅ P0 脚本 CI 绿
→ 方可开下一情绪 / 音乐阶段
```

### 5.5 一键命令（定稿前）

```bash
# 项目根目录
python3 scripts/verify_dog_150_compile_contract.py
python3 scripts/verify_diffusion_prompt_contract.py
# 人眼：03 预览 + wan_final 成片 → 填 §5.2 表
```
