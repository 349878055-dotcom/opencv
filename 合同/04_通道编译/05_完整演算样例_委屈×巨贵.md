## 一、第一步演算：macro → E(t)

### 1.1 输入（你定义的）

```text
macro:  push=15  power=15  speed=8  steady=62  grip=68  outro=55
hold_seg: shape=flat  pulse_rate=0  pulse_depth=0  swell=0
```

### 1.2 时间节点（公式 `_timing()`）

```text
speed = 8/100 = 0.08

t_peak   = round( lerp(20, 14, 0.08) ) = 20      ← 第 20 帧到峰
t_settle = t_peak + round( lerp(8, 4, 0.08) ) = 28
t_hold0  = max(t_settle, 25) = 28                 ← 保持段从第 28 帧开始
outro=55 ≥ 50 → t_hold1 = 110                     ← 保持到第 110 帧
t_outro_end = 149
```

四段划分：

```text
帧 0────20────28────────────110────149
     蓄力  启动   保持(flat)      缓和
```

### 1.3 峰值 peak（公式 `_peak_level()`）

```text
push = 15/100 = 0.15  (< 0.35，走「低 push」分支)
power = 15/100 = 0.15

peak = 0.04 + 0.26 × power
     = 0.04 + 0.26 × 0.15
     = 0.079
```

### 1.4 平顶 plateau（保持段高度）

```text
grip = 68/100 = 0.68

plateau = peak × lerp(0.88, 1.0, grip)
        = 0.079 × (0.88 + 0.12×0.68)
        = 0.079 × 0.9616
        = 0.075966
```

### 1.5 关键帧 E(t) 实算值

| 帧 t | 阶段 | E(t) | 怎么来的 |
|------|------|------|----------|
| 0 | 蓄力起点 | **0.000** | 从 0 起步 |
| 20 | 峰 | **0.079000** | = peak |
| 28 | 进入保持 | **0.075966** | = plateau |
| **80** | **保持段中** | **0.075966** | flat → 恒定 plateau |
| 110 | 保持结束 | **0.075966** | 同上 |
| 149 | 收尾 | **0.011395** | outro 缓降 |

> **结论**：委屈变体3 整体能量很低（peak 仅 0.079）；**PAD 不参与这一步**。

## 二、第二步演算：PAD → 12 个 scale

### 2.1 输入（你定义的 · v3.2 巨贵审定）

```text
P = -0.40    （压抑/苦涩）
A = -0.15    （低激活/疲惫）
D = -0.70    （极度顺从/退缩）
```

来源：`预设资产/情绪坐标/dog/委屈.json` + `emotion_pad.py` 真源表。

### 2.2 公式（每个通道各算一次）

```text
scale[ch] = base[ch] + P×Wp[ch] + A×Wa[ch] + D×Wd[ch]
scale[ch] = max(0, scale[ch])
```

### 2.3 十二通道完整演算表

以 **squint** 为例展开：

```text
base=0.31, Wp=0.10, Wa=0.35, Wd=0.20

scale[squint] = 0.31 + (-0.40×0.10) + (-0.15×0.35) + (-0.70×0.20)
              = 0.31 - 0.04 - 0.0525 - 0.14
              = 0.0775
```

| 通道 | base | Wp | Wa | Wd | **scale（实算）** |
|------|------|----|----|-----|-------------------|
| pupil_x | 0.36 | 0.00 | 0.50 | 0.40 | **0.0050** |
| pupil_y | 0.33 | 0.00 | 0.50 | 0.40 | **0.0000** ← clamp 前为负 |
| blink | 0.48 | 0.00 | 0.30 | 0.10 | **0.3650** |
| eyebrow | 0.28 | 0.05 | 0.30 | 0.20 | **0.0750** |
| pupil_scale | 0.24 | 0.10 | 0.30 | 0.20 | **0.0150** |
| iris_scale | 0.19 | 0.10 | 0.20 | 0.10 | **0.0500** |
| cornea_bulge | 0.14 | 0.00 | 0.40 | 0.30 | **0.0000** |
| **squint** | 0.31 | 0.10 | 0.35 | 0.20 | **0.0775** |
| brow_raise | 0.22 | 0.10 | 0.20 | -0.20 | **0.2900** |
| lid_upper | 0.37 | 0.00 | 0.50 | 0.40 | **0.0150** |
| lid_lower | 0.25 | 0.00 | 0.30 | 0.20 | **0.0650** |
| eye_gloss | 0.11 | 0.30 | 0.10 | 0.00 | **0.0000** ← clamp 前为负 |

> **结论**：scale 是 **12 个常数**，整段 5 秒不变；低 A + 极负 D 会把很多通道压得很小甚至归零。

## 三、第三步演算：E(t) × scale → pulse（重点帧 t=80）

保持段中段 **t=80**，**E(80) = 0.075966**（上节已算）。

### 3.1 默认公式通道（先算「补丁前」）

```text
pulse[ch, t] = clamp( E[t - lag[ch]] × scale[ch] × gain[ch] )
```

#### squint（有 lag、有 gain）

```text
lag=2, gain=1.10, scale=0.0775

pulse[squint, 80]（补丁前）
  = E[78] × 0.0775 × 1.10
  = 0.075966 × 0.0775 × 1.10
  = 0.006476
```

#### lid_upper

```text
lag=2, gain=1.08, scale=0.0150

pulse[lid_upper, 80]（补丁前）
  = 0.075966 × 0.0150 × 1.08
  = 0.001231
```

#### pupil_x（有方向 sign）

```text
push=15 < 50 → sign = -1

pulse[pupil_x, 80] = sign × E[80] × scale[pupil_x]
                   = -1 × 0.075966 × 0.0050
                   = -0.000380 → clamp 后 ≈ 0（实际代码保留符号后再 clamp，实算 0.008527 含 jitter）
```

#### eye_gloss（scale=0，默认公式为 0）

```text
pulse[eye_gloss, 80]（补丁前）= E[73] × 0.0000 × 0.42 = 0.000000
```

---

### 3.2 补丁 A：委屈湿眼 `_apply_moist_sad_baseline`

触发条件：emotion 含「委屈/可怜/渴望」且 t 在保持段 [28, 110]。

```text
u = (t - t_hold0) / (t_hold1 - t_hold0)
  = (80 - 28) / (110 - 28)
  = 52 / 82
  = 0.6341

droop = 0.07 + 0.05 × u
      = 0.07 + 0.05 × 0.6341
      = 0.1017
```

| 通道 | 补丁公式 | t=80 实算 |
|------|----------|-----------|
| squint | `+ droop` | 0.006476 + 0.1017 = **0.108183** |
| lid_upper | `+ droop × 0.85` | 0.001231 + 0.0865 = **0.087682** |
| lid_lower | `+ droop × 0.35` | … = **0.039350** |
| eye_gloss | `+ 0.04 + 0.05×u` | 0 + 0.0717 = **0.071707** |

> **这就是为什么 squint 在 t=80 不是 0.006 而是 0.108** —— 湿眼补丁在保持段 **叠加** 了约 0.10 的基线。

本案例 hold_seg=**flat**，**不触发** tremble 补丁。

---

### 3.3 补丁 B：blink 独立锚点（不用 E×scale）

眨眼在固定时刻插入 spike；t=80 **无锚点**，blink[80]=**0**。

锚点之一在 **t=72**（保持段 52% 位置）：

```text
scale[blink] = 0.365
peak = 0.17 × scale = 0.17 × 0.365 = 0.06205   （委屈类系数 0.17）

blink[72] 时间形状（dt 相对锚点）:
  dt=0 → ×0.0
  dt=1 → ×0.72  → 0.0447
  dt=2 → ×1.0   → 0.0621  ← 闭到最大
  dt=3 → ×0.58  → 0.0360
  dt=4 → ×0.0
```

全片 blink 非零帧（节选）：22–24, 51–53, **71–73**, 103–105。

---

### 3.4 补丁 C：耳位注入 `inject_ear`（你定义的 ear）

**你定义的**（`_category.json` · dog）：

```text
left_angle = right_angle = -0.7   （耷耳）
```

**工程公式**：

```text
base_eyebrow = (left_angle + 1) / 2 = (-0.7 + 1) / 2 = 0.15

eyebrow[t] = clamp( base_eyebrow + pulse_eyebrow[t] × 0.35 )
```

t=80：

```text
pulse_eyebrow[80]（注入前）= E[78] × scale[eyebrow] = 0.075966 × 0.075 = 0.005697

eyebrow[80] = 0.15 + 0.005697 × 0.35
            = 0.151994
```

styled[ch, t] = clamp01( base_offset[ch] + scale_factor[ch] × pulse[ch, t] )

## 五、纵向串起来（一张总账）

```text
┌─ 你定义 ─────────────────────────────────────────────────────────┐
│ macro(6) + hold_seg  →  E(t) 一条线，peak=0.079，保持≈0.076      │
│ PAD (-0.4,-0.15,-0.7) → scale[12] 常数，squint=0.0775 …         │
│ ear 耷耳 -0.7        → eyebrow 基线 0.15                         │
│ poodle_giant style   → base/scale_factor 各 12 路                 │
└──────────────────────────────────────────────────────────────────┘
                              ↓
┌─ 公式 + 工程常数 ────────────────────────────────────────────────┐
│ 默认: pulse = E[t-lag] × scale × gain                             │
│ 补丁: 湿眼 +droop / blink 锚点 / 耳位 base+pulse×0.35 / jitter   │
└──────────────────────────────────────────────────────────────────┘
                              ↓
                    pulse[12×150]  （如 squint[80]=0.108）
                              ↓
┌─ S5 公式 ────────────────────────────────────────────────────────┐
│ styled = base_offset + scale_factor × pulse                       │
└──────────────────────────────────────────────────────────────────┘
                              ↓
                    styled[12×150]  （如 squint[80]=0.516）
                              ↓
                         02_烘焙.json
```

## 六、你要改什么时，改哪里

| 想改… | 改「你定义的」 | 不改 |
|-------|----------------|------|
| 起峰更慢/更快 | macro.speed | PAD |
| 整体更用力 | macro.power | scale 权重表 |
| 更委屈/更湿 | PAD P/A/D（`情绪坐标/dog/委屈.json`） | macro |
| 保持段更颤 | hold_seg.shape=tremble | E(t) 公式本身 |
| 眨眼更密 | 代码 `_dog_blink_series` 锚点 | style |
| 巨贵眼更大 | `poodle_giant/style.json` base_offset | E(t)、PAD |
| squint 对 D 更敏感 | `DOG_PAD_WEIGHTS` 里 Wd | macro |

**正交规则**：换品种（巨贵→哈士奇）→ 只变 **styled**，**E(t) 和 pulse 不变**。
