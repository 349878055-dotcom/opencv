## 一、先记口诀（四个旋钮、四个文件）

```text
变体3  →  macro + hold     →  E(t) 一条线        （怎么演、多慢、多用力）
委屈   →  PAD (P,A,D)       →  scale[12] 常数     （什么气质的脸）
委屈   →  ear（狗）         →  耳位基线           （耷耳 → 眉脊）
贵宾   →  poodle_giant     →  styled 偏移        （谁的脸、眼多大、眨多慢）
```

**正交规则**：

| 你换… | 会变 | 不会变 |
|-------|------|--------|
| 变体1→变体3 | E(t)、pulse 时间形状 | PAD、贵宾 style |
| 贵宾→哈士奇 | styled 数值 | E(t)、pulse、PAD |
| 改 PAD | scale、pulse 幅度 | E(t) 时间轴 |
| 改 macro.power | E(t) 峰高 | PAD、style |

## 三、三个「名字」别混（最容易乱的地方）

同一条情绪链路里，有三个不同用途的字符串：

| 用途 | 示例 | 谁用 | 能不能当 macro 真源 |
|------|------|------|---------------------|
| **preset_id**（机器主键） | `委屈/变体3_迟疑试探` | 门户按钮 `data-id`、编译加载、02 烘焙 `preset_id` | ✅ **是** |
| **display_alias**（展示别名） | `委屈·幼犬眼` | 旧 CLI、路由表、客户口语 | ❌ 只是别名，须解析到 preset_id |
| **emotion**（JSON 显示名） | `委屈·变体3·迟疑试探` | 滑杆包 `emotion` 字段、Prompt 可读标签 | ❌ 仅展示，**不等于** macro 文件 |

```text
门户正确链路：
  点按钮 id = 委屈/变体3_迟疑试探
       ↓
  加载 变体3_迟疑试探.json  →  macro/hold = flat, power=15
       ↓
  02 烘焙里 preset_id = 委屈/变体3_迟疑试探

错误链路（C001 曾出现）：
  emotion 显示 = 委屈·幼犬眼（像变体3）
  但 macro/hold = 变体2（power=26, tremble）  ← 滑杆与标签脱节
```

**定稿**：审数据、对按钮、查 02 烘焙，一律看 **`preset_id` + macro 数值**，不要只看 `emotion` 别名。

## 四、变体2 vs 变体3（狗·委屈，防错配）

| | **变体2 · 隐忍微颤** | **变体3 · 迟疑试探** |
|--|----------------------|----------------------|
| preset_id | `委屈/变体2_隐忍微颤` | `委屈/变体3_迟疑试探` |
| 别名 | 可怜·委屈、委屈呜咽 | **委屈·幼犬眼** |
| power | **26** | **15** |
| speed | **22** | **8** |
| hold | **tremble** | **flat** |
| E(t) 峰 | ~0.14 量级 | **~0.079** |
| 合同约束 | 可微颤 | **禁止叠变体2 tremble** |

变体3 的物理语义：**慢起、平顶、弱峰、迟疑回头** — 不是「抖」。

---

## 五、贵宾（poodle_giant）只管 styled

贵宾 **不参与** E(t) 公式，也 **不改** PAD。

| 通道 | 贵宾 style 典型作用 | 与变体3 叠加效果 |
|------|---------------------|------------------|
| blink | base=0.55（偏阖、慢眨） | 变体3 E(t) 弱 → pulse 小 → styled blink **波动很窄**（~0.016 量级） |
| squint | base=0.5, scale=0.15 | 在 pulse 上抬高 + 放大 |
| lid_upper | base=0.48 | 整体眼睑线偏高 |

**换品种**：巨贵 → 哈士奇，**E(t) 与 pulse 不变**，只有 styled 变。

**若嫌变体3+贵宾「眼没戏」**：动 **style.json 的 blink scale_factor** 或 **变体3 macro.power**，不要误改 PAD 或换成变体2 tremble（语义不同）。

## 七、02 烘焙里应对齐的字段

| 字段 | 应对值（本案例） | 说明 |
|------|------------------|------|
| `preset_id` | `委屈/变体3_迟疑试探` | **主键**，与门户按钮一致 |
| `display_alias` | `委屈·幼犬眼` | 可选，给人看 |
| `breed` | `poodle_giant` | 品种 |
| `slider_packet.macro.power` | 15 | 与变体3 JSON 一致 |
| `slider_packet.hold_seg.shape` | flat | 与变体3 JSON 一致 |
| `revision` | `dog:委屈/变体3_迟疑试探+breed=poodle_giant` | 一眼看出组合 |

**验收**：`macro.power=26` 且 `preset_id` 含变体3 → **错配**，需重生成。
