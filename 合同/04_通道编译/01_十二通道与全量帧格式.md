## 2. 真值层级（谁可以改什么）

```text

    ↓ finalize_packet
```

| 层级 | 客户/LLM 能否直接改 |

| id | 中文 | 人 | 猫/狗备注 |

## 4. hold_seg 在全量上的语义

与 [`滑杆规范.md`](../01_输入与收口/滑杆规范.md) 一致；`shape` 调制 **保持段** 能量花纹（非「开关正常人颤动」）：

| shape | 全量语义 |
|-------|----------|
| `flat` | 平顶盯住 |
| `decay` | 保持段下泄 |
| `swell` | 慢拱 |
| `pulse` | 低频起伏 |
| `tremble` | 高频微颤（异常加强；正常人底噪见 `06`） |

## 6. 烘焙 02 文件格式

**示例路径**：`…/指令/02_烘焙_*.json`

```json
{
  "schema_version": "0.2-baked-human-prior",
  "_baked_dense": true,
  "revision": "delivery:情绪名",
  "slider_packet": { "schema": "slider-packet-v1", "macro": {}, "hold_seg": {} },
  "human_prior_report": {},
  "pulse_quality_report": {},
  "channel_tracks": {}
}
```

### `channel_tracks`

- 每通道 **150** 个 `{ "t", "v", "phase", "easing": "linear" }`  
- `t` 与下标一致 `0..149`

### 校验

```bash
python3 scripts/verify_dog_150_compile_contract.py   # 狗结构 P0
python3 -c "
from pathlib import Path
import json
from gaze_engine._shared.channel_contract import validate_baked_delivery
d = json.loads(Path('…/02_烘焙_*.json').read_text())
print(validate_baked_delivery(d) or 'OK')
"
```

### 出厂

```bash
./scripts/s01_从能量生成02.sh <情绪名>
python3 scripts/verify_diffusion_prompt_contract.py
```

实现：`delivery_pipeline.run_delivery_from_packet()` / `run_species_delivery()`。
