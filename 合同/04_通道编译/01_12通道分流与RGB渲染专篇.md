## 二、三层固定体系

每个通道的最终几何量由 **三个层次** 叠加决定：

```
最终几何量 = 物种常量 × 品种模板乘数 × (1 + 通道值 × 振幅系数)
```

| 层次 | 来源 | 固定性 | 示例 |
|------|------|--------|------|
| **L1: 物种常量** | [`_RENDERER_CONSTANTS`](../../gaze_engine/render/species_template.py) | 写死在代码中，跨项目不变 | `IRIS_R_BASE=36`, `PUPIL_R_BASE=8` |
| **L2: 品种模板** | [`SpeciesTemplate`](../../gaze_engine/render/species_template.py) | 每个物种+品种一套，客户可调 | `iris_size=1.0`, `pupil_size=1.0` |
| **L3: 帧级通道值** | `channels_from_envelope()` 输出 | 每帧不同 | `iris_scale=0.3`, `pupil_scale=-0.1` |

> 注意：`cornea_bulge` 是在 L1 × L2 × L3 结果上**再乘** `(1.0 + cornea_bulge × 0.15)`，相当于 L3 的额外附加层。

## 三、12 通道 → RGB 路由

### 路由 A：OpenCV 工程底膜（10 通道）

BGR 三色分离编码：

| # | 通道 | BGR 层 | 几何作用 | 最终几何量公式 |
|---|------|--------|---------|-------------|
| 1 | `pupil_x` | B | 瞳孔/虹膜水平偏移 | `cx + px × PUPIL_X_RANGE × template.pupil_size` |
| 2 | `pupil_y` | B | 瞳孔/虹膜垂直偏移 | `cy + py × PUPIL_Y_RANGE × template.pupil_size` |
| 3 | `blink` | R | 上眼睑抛物线下降 | `UPPER_PEAK - blink × BLINK_DROP` |
| 4 | `squint` | R | 下眼睑抛物线上升 | `LOWER_BOT - squint × SQUINT_LIFT` |
| 5 | `lid_upper` | R | 上眼睑微调下降 | `- lid_upper × LID_UPPER_DROP`（叠加到 blink 之上） |
| 6 | `lid_lower` | R | 下眼睑微调上升 | `+ lid_lower × LID_LOWER_LIFT`（叠加到 squint 之上） |
| 7 | `eyebrow` | G | 眉脊垂直偏移 | `brow_y - eyebrow × template.eye_size` |
| 8 | `brow_raise` | G | 眉脊上抬 | `brow_y - brow_raise × BROW_RAISE_AMP`（叠加到 eyebrow 之上） |
| 9 | `pupil_scale` | B | 瞳孔环半径 | `PUPIL_R_BASE × template.pupil_size × (1.0 + p_scale × 0.5)` |
| 10 | `iris_scale` | B | 虹膜实心圆半径 | `IRIS_R_BASE × template.iris_size × (1.0 + i_scale × 0.3)` |
| — | `cornea_bulge` | B | **虹膜额外缩放** | `× (1.0 + cornea_bulge × 0.15)`（乘在 iris_scale 结果之上） |

> **不进入线条图的通道：** `eye_gloss`（见路由 B，用节奏说明书语义描述）

### 路由 B：节奏说明书（全部 12 通道）

所有 12 通道被送入 [`rhythm_compiler.build_metronome_text()`](../../gaze_engine/delivery/rhythm_compiler.py)，生成自然语言描述：

```
例：
- frame 30-45: pupil_x 右偏 +0.42，幅度中等
- frame 86: blink 尖峰 0.14（快速眨眼）
- frame 50-90: iris_scale 持续 0.3（虹膜轻微扩张）
- frame 20-60: eye_gloss 脉冲 0.8（高光显现）
```

详细格式见 [`../08_输出与扩散/节奏说明书.md`](../08_输出与扩散/节奏说明书.md)。

### 路由 C：04 Prompt（不含 12 通道）

04 Prompt 文本包含物种/品种描述、场景/背景、情绪叙事文本。12 通道**不直接进入** 04 Prompt。

## 四、B 通道内部：iris vs pupil 的精确分离

这是最容易混淆的地方。B 通道在像素空间画 **三层** 内容：

```
B 通道（蓝色层）：
┌─────────────────────────────────────────┐
│  第 1 层：虹膜实心圆  cv2.circle(filled)  │
│  - 半径 = iris_scale × cornea_bulge      │
│  - 圆心 = pupil_x / pupil_y 偏移后的位置  │
│  - 颜色 = (255, 0, 0)  蓝色实心填充      │
├─────────────────────────────────────────┤
│  第 2 层：瞳孔挖空    cv2.circle(black)   │
│  - 半径 = pupil_scale                    │
│  - 圆心 = 同虹膜圆心                      │
│  - 颜色 = (0, 0, 0)  黑色填充            │
│  - 作用：在虹膜蓝色区域中挖出黑洞         │
├─────────────────────────────────────────┤
│  第 2b 层：瞳孔轮廓  cv2.circle(outline)  │
│  - 半径 = pupil_scale                    │
│  - 颜色 = (255, 0, 0)  蓝色轮廓环        │
│  - 作用：标记瞳孔边缘（在黑洞外侧画环）   │
├─────────────────────────────────────────┤
│  第 3 层：湿润高光    draw_eye_gloss()    │
│  - 位置 = 由物种常量固定（不在 12 通道中） │
│  - 强度 = eye_gloss 通道值                │
└─────────────────────────────────────────┘
```

**关键区分：**

| 概念 | 控制通道 | 渲染方式 | 大小关系 |
|------|---------|---------|---------|
| **虹膜** (iris) | `iris_scale` + `cornea_bulge` | **实心填充**圆 `cv2.circle(..., -1)` | 大（IRIS_R_BASE=36） |
| **瞳孔** (pupil) | `pupil_scale` | **先黑色挖空** + **再蓝色轮廓环** | 小（PUPIL_R_BASE=8） |

> **不要** 把 iris_scale 和 pupil_scale 混为一谈。它们独立控制、独立渲染、独立消费。
>
> **关键约束**：瞳孔必须先在虹膜蓝色区域中挖出黑色空洞（`(0,0,0)`），再画蓝色轮廓环。如果只画蓝色轮廓而不挖空，扩散引擎将无法区分虹膜和瞳孔区域（两者都是蓝色）。

**渲染顺序（必读）：**

```
Step 1: cv2.circle(canvas, center, iris_r, (255,0,0), -1)   ← 画蓝色实心虹膜
Step 2: cv2.circle(canvas, center, pupil_r, (0,0,0), -1)    ← 在虹膜中挖出黑色瞳孔洞
Step 3: cv2.circle(canvas, center, pupil_r, (255,0,0), t)   ← 在黑洞外侧画蓝色瞳孔轮廓
Step 4: draw_eye_gloss(...)                                   ← 画高光点
```

**为什么第 2 步必须用黑色 (0,0,0) 而不是蓝色 (255,0,0)：**

如果瞳孔区域用蓝色填充，结果：
```
B 通道像素值：
  虹膜内部 = 255（蓝）
  瞳孔内部 = 255（蓝，同色）← 扩散引擎分不清
  瞳孔轮廓 = 255（蓝）
```

正确做法（瞳孔黑色挖空）：
```
B 通道像素值：
  虹膜内部 = 255（蓝）
  瞳孔内部 = 0（黑，清晰可见的洞）← 扩散引擎看到瞳孔区域
  瞳孔轮廓 = 255（蓝）
```

## 七、检查点

| 检查项 | 通过标准 |
|--------|---------|
| 10 通道进线条图 | pupil_x/y, blink, squint, lid_upper/lower, eyebrow, brow_raise, pupil_scale, iris_scale 全部出现 |
| cornea_bulge 作为乘数 | `(1.0 + cornea_bulge * 0.15)` 作为额外乘数 |
| eye_gloss 不进线条图 | 只出现在 draw_eye_gloss() 调用中，不独立画几何 |
| 虹膜为实心圆 | iris = `-1`（填充） |
| **瞳孔为黑色挖空** | **必须先 `(0,0,0)` 填充，再 `(255,0,0)` 画轮廓** |
| 所有通道进节奏说明书 | 12 个通道全部出现在 JSON 输出中 |

### 常见错误

| 错误 | 表现 | 原因 |
|------|------|------|
| 虹膜和瞳孔一样大 | 渲染图瞳孔不可见 | 误将 `iris_scale` 和 `pupil_scale` 混用，或常数量级错误 |
| **瞳孔未挖空** | 底膜 B 通道整片蓝色，看不到瞳孔黑区 | 瞳孔区域用 `(255,0,0)` 而非 `(0,0,0)` 填充，与虹膜同色 |
| eye_gloss 画了小白圆 | 底膜多出一个白点 | 误将 eye_gloss 当几何层画了，应只走节奏说明书 |
| cornea_bulge 无效果 | 虹膜大小不受角膜影响 | 忘记在 iris_r 公式中乘 `(1.0 + cornea_bulge * 0.15)` |
