## 一、概述（What）

**通道编译**把标量能量曲线 **E(t)** 与 **12 维 pad_scale** 合成为 **pulse[12×150]**，再经风格化、先验、质检写入 **`02_烘焙_*.json`**。

```text
01 SliderPacket
  → 02 E(t)              # 合同/02_情绪与能量
  → 03 pad_scale[12]     # 合同/03_情绪坐标
  → 04 pulse[12×150]     # 本目录 ⭐
  → 05 styled            # 合同/05_风格化
  → 06 prior + QC        # 合同/06_先验与质检
  → 02_烘焙_*.json
  → 07 MP4 / 08 扩散包
```

**150 帧全量 = 12 通道 × 150 = 1800 个数**（不是一条 E(t)）。
