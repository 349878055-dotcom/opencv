## 一、逐步编译（01～06 在狗上的展开）

| 步 | 做什么 | 出参形状 | 代码入口 |
|----|--------|----------|----------|
| 01 | `SliderPacket` + L1 | packet | `slider_schema` · `packet_finalize` |
| 02 | macro+hold → **E(t)** | 150×1 | `build_energy_envelope()` |
| 03 | pad → **scale[ch]** | 12×1 | `resolve_pad()` · `compute_pad_scale()` |
| 04 | E×scale + 分支 → **pulse** | 12×150 | `channels_from_envelope()` ⭐ |
| 05 | pulse + 品种 → **styled** | 12×150 | `apply_breed_style()` |
| 06 | prior + QC → **02 JSON** | 1800 v | `apply_dog_prior()` · `fix_dog_pulse_quality()` |

```text
情绪 JSON + 品种 style.json
  → resolve_pad → build_energy_envelope → channels_from_envelope
  → inject_ear → apply_breed_style → apply_dog_prior → fix_dog_pulse_quality
  → _make_dog_baked → 02_烘焙_*.json
```

**门户总入口**：`run_species_delivery("dog")` → `run_dog_pipeline()`（`gaze_engine/dog/dog_pipeline.py`）

### S4 表演力要点（微调主战场）

| 通道/规则 | 要点 |
|-----------|------|
| 通用形 | `pulse = clamp(E[t] × scale[ch] × gain)` |
| `blink` | **独立 blink 序列**（多锚点），非纯 E×scale |
| lag 通道 | 用 `E[t-lag]`，防 12 轨同步拉伸 |
| hold=tremble | ripple → squint、pupil_y |
| 委屈/渴望类 | 保持段 squint/lid/gloss 抬高 |
| 全段 | `micro_jitter` · 可选 `ear` 注入 eyebrow |

12 通道（`DOG_CHANNELS`）：`pupil_x` `pupil_y` `blink` `eyebrow` `pupil_scale` `iris_scale` `cornea_bulge` `squint` `brow_raise` `lid_upper` `lid_lower` `eye_gloss`

帧轴四段：蓄力 → 启动 → 保持 → 缓和；`t_peak` / `t_hold0` / `t_hold1` 由 `_timing(macro)` 推出。详见 [`01_十二通道与全量帧格式.md`](../01_十二通道与全量帧格式.md)。
