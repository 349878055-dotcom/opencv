## 二、理论依据（Theory）

### 2.1 为什么人、狗、猫共用一套 E(t)？

无论是人被老板骂、狗被主人训、还是猫被抢了罐头，作为 **脊椎哺乳动物**，在「委屈」情境下神经系统反应 **宏观同构**：

```text
情境：权力压制 + 无法反抗
      ↓
副交感/交感与皮层控制的配比冲突
      ↓
E(t) 形态（时间感）可跨物种复用
      ↓
PAD + pad_weights → 同一 E(t) 推到不同面孔硬件
```

**引擎解耦**（与 [`03_情绪坐标/01_三层分工与边界.md`](../03_情绪坐标/01_三层分工与边界.md) 一致）：

```text
macro + hold_seg ──→ E(t)              ← 本文件：三种力学变体
emotion.pad        ──→ (P,A,D)         ← 03：气质/通道性格
pad_weights[物种]  ──→ 12 通道 scale   ← 物种：眉/耳/唇映射差异
```

- **E(t)** 决定：多用力、何时峰、平顶多长、有没有锯齿（**时间物理学**）
- **物种差异** 决定：同样能量推到 **狗** → 耳耷 + 眼睑颤；推到 **人** → 嘴角抿 + 眉压；推到 **猫** → 背塌 + 低频喉鸣（耳/睑通道）

### 2.2 与演技理论的关系

委屈类表演力的黄金区间（见 [`演技理论_张力三层解耦模型.md`](../00_管线导读/演技理论_张力三层解耦模型.md) §2.3）：

| 维度 | 委屈典型 |
|------|----------|
| $F_{ext}$ | **低**（`power` 偏低，峰高 Y ≈ 0.1） |
| $F_{int}$ | **高**（`grip` 偏高 + `hold.shape = tremble`） |
| 读感 | 动作极小，但到达峰顶极慢、平顶极长且带毛刺 → **心疼、隐忍** |

## 三、三种 E(t) 力学变体（核心）

同一情绪类别「委屈」下，按 **时间序列形状** 拆为三种 **可跨物种复用** 的物理模板。编译时选定变体 → 再映射到 macro/hold 滑杆。

### 变体 1：缓慢泄气（Deflation）

| 维度 | 内容 |
|------|------|
| **生物学** | 副交感神经彻底接管，能量极度耗散 |
| **跨物种表现** | 人叹气低头；狗趴下头埋爪；猫背塌、耳平放 |
| **E(t) 签名** | **极缓上坡**（`t_peak` ≥ **40** 帧）；**极低峰**（`peak` ≪ 0.2）；平顶长、塌陷慢 |
| **主滑杆方向** | `speed`↓ · `power`↓ · `grip` 中 · `hold` 偏 flat/decay |
| **观众读感** | 认栽、耗尽、不再挣扎 |

### 变体 2：隐忍微颤（Restraint）← **人/猫 JSON 仍为旧档**

| 维度 | 内容 |
|------|------|
| **生物学** | 交感（想哭/想逃）与皮层控制（不敢动）激烈拮抗 → 肌肉微痉挛 |
| **跨物种表现** | 人咬唇眼眶含泪微颤；狗夹尾盯人嘴角抽；猫喉间极低频呜呜 |
| **E(t) 签名** | 低峰 + **长平顶** + **`hold.shape = tremble`** 高频噪波 |
| **主滑杆方向** | `power`↓ · `grip`↑ · `steady`↑ · `hold = tremble` |
| **观众读感** | 极力克制、可怜、心疼（演技理论案例 B） |

**当前定稿快照**（三物种 macro 一致，仅 PAD/ear 不同）：

| 指标 | 人 / 狗 / 猫 现值 |
|------|-------------------|
| `push` / `power` / `speed` | 15 / 26 / 22 |
| `grip` / `steady` / `outro` | 68 / 62 / 22 |
| `hold.shape` | **tremble** |
| `t_peak` | **19**（偏快，属隐忍但起势不够「迟疑」） |
| `peak_level` | **≈ 0.1076** |

### 变体 3：迟疑试探（Hesitation）← **狗已锁定 · Patch v3.1**

| 维度 | 内容 |
|------|------|
| **生物学** | 信息处理阻滞：不知错在哪，或判断对方是否还会继续攻击 |
| **跨物种表现** | 人眼神闪躲、慢吞吞回头；狗转身又停、回头看；猫走两步回头看 |
| **E(t) 签名** | 极缓上坡 · **flat 平顶（零 tremble）** · 高 `outro` 慢收 — **纯粹物理滞后，不叠变体 2** |
| **主滑杆方向** | `speed`↓ · `power`↓ · `grip`↑ · `hold=flat` · `outro`↑ |
| **观众读感** | 不情愿的回头、僵住试探、缓慢卸力躲开 |

**场景锚定**：「狗狗委屈地回头看了一眼」→ **仅变体 3**；已写入 `预设资产/情绪包/dog/委屈·幼犬眼.json`。

## 四、变体选型与滑杆映射（How · 理论层）

### 4.1 选型决策表

| 客户语义 / 场景 | 推荐变体 | 备注 |
|-----------------|----------|------|
| 被骂后趴下、放弃挣扎 | **1 缓慢泄气** | `t_peak` 优先拉到 ≥40 |
| 盯着你不哭但一直在抖 | **2 隐忍微颤** | 现三份合同近似此型 |
| 转身走开又回头看、lag 感 | **3 迟疑试探** | 狗 Patch v3.1；`flat` 无 tremble |
| 回头 + 含泪 | ~~3 + 2~~ | **已弃用** — 变体 3 要求剥离微颤 |

### 4.2 变体 → E(t) 几何对照

| 变体 | 上坡（speed） | 峰高（power） | 平顶（grip + hold） | 下坡（outro） |
|------|---------------|---------------|---------------------|---------------|
| 1 泄气 | 极缓，≥40 帧到顶 | 极低 Y | 长、平滑塌陷 | 慢收 |
| 2 隐忍 | 中缓（现 ~19 帧） | 低 Y (~0.11) | 长 + **锯齿 tremble** | 快收（现 22） |
| 3 迟疑 | 极缓上坡 | 低 Y (~0.08) | **flat** 僵直平台 | 高 outro 慢收 |
