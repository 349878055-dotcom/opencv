## 二、macro + hold 变成什么？

### 2.1 输出

```text
输入：macro 6 根 + hold_seg
输出：E(t) = [E(0), E(1), … E(149)]   ← 150 个数，约 0～1
函数：build_energy_envelope()
```

**不是** 12 通道。就 **一条「5 秒总音量曲线」**。

### 2.2 怎么算？（不是「先关键帧再插值」）

```text
❌ 不是：先定帧20=0.079、帧80=0.076，中间插值补齐

✅ 而是：
   第一步 → 算「时间边界」+「峰顶/平顶高度」（几个常数）
   第二步 → for t = 0..149，每帧套对应段的公式，直接填满 150 帧
```

四段时间边界（由 **speed、outro** 等决定，委屈案例）：

```text
帧:  0 ─── 20 ── 28 ───────────── 110 ─── 149
        蓄力↑  峰  落稳   保持(flat)     缓和↓
        │              │                │
     t_peak=20    t_hold0=28      t_hold1=110
```

### 2.3 委屈·幼犬眼 长什么样

```text
强度
0.08 │      ╭─峰(0.079)─╮
     │     ╱              ╲___平顶(0.076)___╲
0    │____╱                                  ╲___
     0   20帧  28帧           110帧            149帧
```

- **矮** → power 低  
- **慢起** → speed 低（第 20 帧才到顶）  
- **中间平** → hold.shape=flat  
- **慢收** → outro≥50（保持到 110 帧再落）

## 三、六根 macro：中文 + 进不进 E(t)

> 值域 0～100。案例取自 `预设资产/情绪包/委屈/变体3_迟疑试探.json`。

### 3.1 先学三根（主旋钮）

| 滑杆 | 案例值 | 中文 | 对 E(t) 干什么 | 案例结果 |
|------|--------|------|----------------|----------|
| **power 力度** | 15 | 整体有多用力 | 决定 **峰顶多高**（主音量） | 峰顶 **0.079**（很弱） |
| **speed 快慢** | 8 | 起势急还是缓 | 决定 **第几帧到峰**（管时间，不管高度） | **第 20 帧**到顶 |
| **outro 收场** | 55 | 盯住多久、怎么收 | outro≥50 → 保持到 **110 帧**再慢收 | 长盯住 + 慢收尾 |

### 3.2 另外三根（二级，第一遍可后学）

| 滑杆 | 案例值 | 中文 | 对 E(t) 干什么 | 备注 |
|------|--------|------|----------------|------|
| **push 往哪使劲** | 15 | 内收 vs 外放 | push<35 用 **内收公式**，峰 顶偏低；≥35 用外放公式 | **也管** pupil 左/右，**不管 PAD** |
| **grip 定得住** | 68 | 盯住泄劲还是憋住 | 峰顶到 **平顶** 差多少 | 案例：0.079→0.076，差很小 |
| **steady 盯得稳** | 62 | 眼飘不飘 | ⚠️ **当前不进 E(t)** | 以后可能接 prior 微颤 |

### 3.3 power 与 push 别混

```text
power  →  峰顶大概多高（主旋钮，动一下变化大）
push   →  ① 选内收/外放公式，微调峰高  ② 后面 pupil_x/y 视线方向
         →  与 PAD 完全无关
```

数字对比（代码实算）：

```text
power=15 固定，改 push：  15→85，峰顶 0.079→0.113（差小）
push=15  固定，改 power： 15→85，峰顶 0.079→0.261（差大）
```

### 3.4 hold_seg（和 macro 一起进 E(t)）

| 字段 | 案例值 | 中文 | 作用 |
|------|--------|------|------|
| **shape** | flat | 盯住段形状 | flat=平线；tremble=抖；pulse=一阵一阵… |
| pulse_rate | 0 | 脉冲多密 | shape≠pulse/tremble 时 **忽略** |
| pulse_depth | 0 | 脉冲多深 | 同上 |
| swell | 0 | 段内起伏 | 仅 shape=swell 时用 |

案例 flat → 保持段 **E(t)=0.076 恒定**，不抖。

## 五、E(t) 之后：macro 还影响什么？

macro **不直接**变成 12 通道；下游分 **三条岔路**：

```text
                    E(t) 150 帧
                         │
     ┌───────────────────┼───────────────────┐
     │                   │                   │
     ▼                   ▼                   ▼
 大多数通道           push 专路           PAD 平行路
 E×scale[ch]        pupil_x / pupil_y     (P,A,D)
 squint, lid…       sign × E × scale      → scale[12]
     │                   │                   │
     └───────────────────┴───────────────────┘
                         ▼
                    pulse 12×150
                    （+ blink/湿眼等补丁）
                         ▼
                    styled（品种，如巨贵）
```

| 输入 | 进 E(t)？ | 进 scale？ | 进 pulse？ | 进 styled？ |
|------|-----------|------------|------------|-------------|
| macro.power | ✅ 峰高 | ❌ | ✅ 乘在公式里 | ❌ |
| macro.speed | ✅ 时间轴 | ❌ | ✅ | ❌ |
| macro.outro | ✅ 保持/收尾 | ❌ | ✅ | ❌ |
| macro.push | ✅ 微调峰高 | ❌ | ✅ pupil 方向 | ❌ |
| macro.grip | ✅ 平顶 | ❌ | ✅ | ❌ |
| macro.steady | ❌（暂未） | ❌ | 人类 prior 可能用 | ❌ |
| hold_seg | ✅ 保持段花纹 | ❌ | tremble 等补丁 | ❌ |
| **PAD** | **❌** | **✅** | **✅** | ❌ |
| **style.json** | **❌** | **❌** | **❌** | **✅** |

**定稿口诀**：

```text
macro + hold  →  E(t)         管「怎么演、何时演、多用力」
PAD           →  scale[12]    管「什么气质的脸」
style         →  styled       管「谁的脸（品种/人格）」
```

## 六、委屈案例：macro 一项项落到数字

**输入**：

```json
"macro": { "push":15, "power":15, "speed":8, "steady":62, "grip":68, "outro":55 },
"hold_seg": { "shape":"flat", "pulse_rate":0, "pulse_depth":0, "swell":0 }
```

**第一步：时间边界**

```text
speed=8  → t_peak=20, t_settle=28
outro=55 → t_hold1=110（慢收）
```

**第二步：高度**

```text
power=15, push=15(<35) → peak = 0.04 + 0.26×0.15 = 0.079
grip=68                → plateau = 0.079 × 0.9616 = 0.076
```

**第三步：逐帧填 E(t)**（节选）

| 帧 t | 阶段 | E(t) |
|------|------|------|
| 0 | 蓄力 | 0.000 |
| 20 | 峰顶 | 0.079 |
| 28 | 进入保持 | 0.076 |
| 80 | 保持中 | 0.076 |
| 110 | 保持末 | 0.076 |
| 149 | 收尾 | 0.011 |

**steady=62**：上表 **完全不变**（未接 E(t)）。

## 七、下游两步（点到为止，细节见 04 目录）

### 7.1 PAD → scale（与 macro 正交）

```text
委屈 PAD = (-0.40, -0.15, -0.70)   ← 情绪坐标/dog/委屈.json

scale[squint] = 0.31 + P×Wp + A×Wa + D×Wd ≈ 0.0775
```

**改 macro 不改 scale；改 PAD 不改 E(t)。**

### 7.2 E(t) × scale → pulse → styled

```text
pulse[squint, 80] ≈ E(80) × scale[squint] × gain + 湿眼补丁
styled[squint, 80] = 巨贵 base + 巨贵 scale × pulse
```

完整手算：[`05_完整演算样例_委屈×巨贵.md`](../04_通道编译/05_完整演算样例_委屈×巨贵.md)
