## 一、概述（What）

定义 **冷压·决心** 这一种人类情绪的：**滑杆定稿、E(t) 指标、观众读感、验收标准**；PAD 见 [`03_情绪坐标/人/冷压·决心.md`](../../03_情绪坐标/人/冷压·决心.md)。

**冷压·决心** = 外放、高强度、平顶盯住、快收（peak≈0.403）；分组「压 · 慑」。

## 二、理论依据（Theory）

### E(t) 四段（本情绪共用公式，数值因滑杆而异）

```text
蓄力(0～t_peak) → 启动(t_peak～t_settle) → 保持(t_hold0～t_hold1) → 缓和(t_hold1～149)
```

- 实现：[`gaze_engine/_shared/envelope_compile.py`](../../../gaze_engine/_shared/envelope_compile.py) → `build_energy_envelope()`
- **本情绪**：peak=0.40331，t_peak=15，保持段 [25, 92]

### 滑杆 → E(t)

| 阶段 | 主要滑杆 |
|------|----------|
| 起 | push · power · speed |
| 盯住 | steady · grip · hold_seg |
| 收场 | outro |

人类 prior / 眉滞后见 `gaze_engine/human/human_prior.py`。

### PAD → 12 通道（与 E(t) 正交）

- PAD **不进** E(t) 公式；定稿见 [`03_情绪坐标/人/冷压·决心.md`](../../03_情绪坐标/人/冷压·决心.md)。
- 实现：[`emotion_pad.py`](../../../gaze_engine/_shared/emotion_pad.py) · [`human/pad_weights.py`](../../../gaze_engine/human/pad_weights.py)
- **本情绪 PAD 摘要**：P=-0.3，A=0.6，D=0.8 → 愉悦中性 · 高激活 · 偏支配/压人

## 三、为什么这样做（Why）

| 键 | 客户语义 | 备选方向 | 定稿 | 理由 |
|----|----------|----------|------|------|
| `push` | 往哪使劲 | 偏低 → 偏内收 / 偏高 → 偏外放 | **88** → 偏高 → 偏外放 | 🧠 与 JSON 同步 |
| `power` | 力度 | 偏低 → 偏轻 / 偏高 → 偏狠 | **95** → 偏高 → 偏狠 | 🧠 与 JSON 同步 |
| `speed` | 快慢 | 偏低 → 偏缓 / 偏高 → 偏急 | **76** → 偏高 → 偏急 | 🧠 与 JSON 同步 |
| `steady` | 盯得稳 | 偏低 → 偏飘 / 偏高 → 偏钉死 | **96** → 偏高 → 偏钉死 | 🧠 与 JSON 同步 |
| `grip` | 定得住 | 偏低 → 偏泄 / 偏高 → 偏憋住 | **94** → 偏高 → 偏憋住 | 🧠 与 JSON 同步 |
| `outro` | 收场 | 偏低 → 偏快落 / 偏高 → 偏慢收 | **38** → 偏低 → 偏快落 | 🧠 与 JSON 同步 |
| `hold.shape` | 盯住段纹理 | flat/pulse/tremble/… | **flat** | 平顶盯住 |
| `pad.P/A/D` | 通道性格 | 各轴 -1～1 | **(-0.3, 0.6, 0.8)** | 🧠 与 JSON `pad` 同步；不改 E(t) |

⚠️ **历史教训**：同组情绪若 push/power/hold.shape 三者全同，门户与 02 烘焙无法区分 → 必须在本文件 §4.6 写清「别像谁」。

### 4.2 滑杆定稿

| 键 | 定稿值 | 范围 | L1 建议带 | 说明 |
|----|--------|------|-----------|------|
| `push` | **88** | 0～100 | 80～96 | 往哪使劲 |
| `power` | **95** | 0～100 | 87～100 | 力度 |
| `speed` | **76** | 0～100 | 68～84 | 快慢 |
| `steady` | **96** | 0～100 | 88～100 | 盯得稳 |
| `grip` | **94** | 0～100 | 86～100 | 定得住 |
| `outro` | **38** | 0～100 | 30～46 | 收场 |

| hold 键 | 定稿值 |
|---------|--------|
| shape | **flat** |
| pulse_rate | **0** |
| pulse_depth | **0** |
| swell | **0** |

> 人类预设无 `ear` 块。

### 4.3 PAD 定位

> **独立合同**：[`03_情绪坐标/人/冷压·决心.md`](../../03_情绪坐标/人/冷压·决心.md)  
> **摘要**：P=-0.3，A=0.6，D=0.8 — 愉悦中性 · 高激活 · 偏支配/压人
>
> PAD 定稿、12 通道投影、气质读感与验收见 **03_情绪坐标**；本文件只管 macro / hold / E(t)。

### 4.4 能量包络 E(t)

| 指标 | 值 | 说明 |
|------|-----|------|
| peak_level | **0.40331** | 全轨峰值 |
| t_peak | **15** | 蓄力结束 |
| t_settle | **20** | 启动结束 |
| t_hold0 / t_hold1 | **25** / **92** | 保持段 |
| E[0] / E[149] | **0.0** / **0.0** | 起/收 |
| 保持段 E | **0.4004 ~ 0.4004** | hold 纹理 |

### 4.5 观众读感（🧠 待审）

- 资产 note：**更狠更钉，起略缓**。
- 视线/情绪 **面向外放**，有压向镜头或对方的倾向。
- 整体 **能量偏高**，盯住段硬，不宜像发呆或困倦。
- 保持段 **平顶高 grip**，钉住不放。
- 起势 **偏急**，戏眼来得快。

### 4.6 避免混淆（🧠 待审）

| 别像 | 区分要点 |
|------|----------|
| 施压·凝视 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 威慑·一瞬 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 怒视·压人 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
