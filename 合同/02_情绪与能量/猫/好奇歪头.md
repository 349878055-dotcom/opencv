## 二、理论依据（Theory）

### E(t) 四段（本情绪共用公式，数值因滑杆而异）

```text
蓄力(0～t_peak) → 启动(t_peak～t_settle) → 保持(t_hold0～t_hold1) → 缓和(t_hold1～149)
```

- 实现：[`gaze_engine/_shared/envelope_compile.py`](../../../gaze_engine/_shared/envelope_compile.py) → `build_energy_envelope()`
- **本情绪**：peak=0.19023，t_peak=17，保持段 [25, 92]

### 滑杆 → E(t)

| 阶段 | 主要滑杆 |
|------|----------|
| 起 | push · power · speed |
| 盯住 | steady · grip · hold_seg |
| 收场 | outro |

宠物 `ear` 块映射眉/耳通道，不进 E(t) 公式。

### PAD → 12 通道（与 E(t) 正交）

- PAD **不进** E(t) 公式；定稿见 [`03_情绪坐标/猫/好奇歪头.md`](../../03_情绪坐标/猫/好奇歪头.md)。
- 实现：[`emotion_pad.py`](../../../gaze_engine/_shared/emotion_pad.py) · [`cat/pad_weights.py`](../../../gaze_engine/cat/pad_weights.py)
- **本情绪 PAD 摘要**：P=0.28，A=0.42，D=-0.08 → 愉悦中性 · 高激活 · 控制中性

## 三、为什么这样做（Why）

| 键 | 客户语义 | 备选方向 | 定稿 | 理由 |
|----|----------|----------|------|------|
| `push` | 往哪使劲 | 偏低 → 偏内收 / 偏高 → 偏外放 | **58** → 偏高 → 偏外放 | 🧠 与 JSON 同步 |
| `power` | 力度 | 偏低 → 偏轻 / 偏高 → 偏狠 | **42** → 偏低 → 偏轻 | 🧠 与 JSON 同步 |
| `speed` | 快慢 | 偏低 → 偏缓 / 偏高 → 偏急 | **48** → 居中 → 中性戏 | 🧠 与 JSON 同步 |
| `steady` | 盯得稳 | 偏低 → 偏飘 / 偏高 → 偏钉死 | **52** → 居中 → 中性戏 | 🧠 与 JSON 同步 |
| `grip` | 定得住 | 偏低 → 偏泄 / 偏高 → 偏憋住 | **62** → 偏高 → 偏憋住 | 🧠 与 JSON 同步 |
| `outro` | 收场 | 偏低 → 偏快落 / 偏高 → 偏慢收 | **42** → 偏低 → 偏快落 | 🧠 与 JSON 同步 |
| `hold.shape` | 盯住段纹理 | flat/pulse/tremble/… | **swell** | 慢拱起伏 |
| `pad.P/A/D` | 通道性格 | 各轴 -1～1 | **(0.28, 0.42, -0.08)** | 🧠 与 JSON `pad` 同步；不改 E(t) |

⚠️ **历史教训**：同组情绪若 push/power/hold.shape 三者全同，门户与 02 烘焙无法区分 → 必须在本文件 §4.7 写清「别像谁」。

| 键 | 定稿值 | 范围 | L1 建议带 | 说明 |

### 4.4 PAD 定位

> **独立合同**：[`03_情绪坐标/猫/好奇歪头.md`](../../03_情绪坐标/猫/好奇歪头.md)

>
> PAD 定稿、12 通道投影、气质读感与验收见 **03_情绪坐标**；本文件只管 macro / hold / E(t)。

### 4.5 能量包络 E(t)

| 指标 | 值 | 说明 |
|------|-----|------|
| peak_level | **0.19023** | 全轨峰值 |
