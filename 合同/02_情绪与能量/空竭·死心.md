## 一、概述（What）

### 本文件用途

定义 **空竭·死心** 这一种人类情绪的：**滑杆定稿、E(t) 指标、观众读感、验收标准**；PAD 见 [`03_情绪坐标/人/空竭·死心.md`](../../03_情绪坐标/人/空竭·死心.md)。

**空竭·死心** = 内收、低强度、段内下泄、慢收留韵（peak≈0.076）；分组「悲 · 怯」。

## 二、理论依据（Theory）

### E(t) 四段（本情绪共用公式，数值因滑杆而异）

```text
蓄力(0～t_peak) → 启动(t_peak～t_settle) → 保持(t_hold0～t_hold1) → 缓和(t_hold1～149)
```

- 实现：[`gaze_engine/_shared/envelope_compile.py`](../../../gaze_engine/_shared/envelope_compile.py) → `build_energy_envelope()`
- **本情绪**：peak=0.07640，t_peak=19，保持段 [26, 110]

### 滑杆 → E(t)

| 阶段 | 主要滑杆 |
|------|----------|
| 起 | push · power · speed |
| 盯住 | steady · grip · hold_seg |
| 收场 | outro |

人类 prior / 眉滞后见 `gaze_engine/human/human_prior.py`。

### PAD → 12 通道（与 E(t) 正交）

- PAD **不进** E(t) 公式；定稿见 [`03_情绪坐标/人/空竭·死心.md`](../../03_情绪坐标/人/空竭·死心.md)。
- 实现：[`emotion_pad.py`](../../../gaze_engine/_shared/emotion_pad.py) · [`human/pad_weights.py`](../../../gaze_engine/human/pad_weights.py)
- **本情绪 PAD 摘要**：P=-0.7，A=0.1，D=-0.2 → 偏不悦/压抑 · 激活中性 · 控制中性

## 三、为什么这样做（Why）

| 键 | 客户语义 | 备选方向 | 定稿 | 理由 |
|----|----------|----------|------|------|
| `push` | 往哪使劲 | 偏低 → 偏内收 / 偏高 → 偏外放 | **18** → 偏低 → 偏内收 | 🧠 与 JSON 同步 |
| `power` | 力度 | 偏低 → 偏轻 / 偏高 → 偏狠 | **14** → 偏低 → 偏轻 | 🧠 与 JSON 同步 |
| `speed` | 快慢 | 偏低 → 偏缓 / 偏高 → 偏急 | **24** → 偏低 → 偏缓 | 🧠 与 JSON 同步 |
| `steady` | 盯得稳 | 偏低 → 偏飘 / 偏高 → 偏钉死 | **48** → 居中 → 中性戏 | 🧠 与 JSON 同步 |
| `grip` | 定得住 | 偏低 → 偏泄 / 偏高 → 偏憋住 | **18** → 偏低 → 偏泄 | 🧠 与 JSON 同步 |
| `outro` | 收场 | 偏低 → 偏快落 / 偏高 → 偏慢收 | **58** → 偏高 → 偏慢收 | 🧠 与 JSON 同步 |
| `hold.shape` | 盯住段纹理 | flat/pulse/tremble/… | **decay** | 段内下泄 |
| `pad.P/A/D` | 通道性格 | 各轴 -1～1 | **(-0.7, 0.1, -0.2)** | 🧠 与 JSON `pad` 同步；不改 E(t) |

⚠️ **历史教训**：同组情绪若 push/power/hold.shape 三者全同，门户与 02 烘焙无法区分 → 必须在本文件 §4.6 写清「别像谁」。

## 四、怎么实现（How）

### 4.1 输入

| 项 | 规格 |
|----|------|
| 文件 | `预设资产/情绪包/human/空竭·死心.json` |
| schema | `slider-packet-v1` |
| 加载 | [`gaze_engine/human/control_surface.py`](../../../gaze_engine/human/control_surface.py) · 工作台 `/api/portal/presets` |

### 4.2 滑杆定稿

| 键 | 定稿值 | 范围 | L1 建议带 | 说明 |
|----|--------|------|-----------|------|
| `push` | **18** | 0～100 | 10～26 | 往哪使劲 |
| `power` | **14** | 0～100 | 6～22 | 力度 |
| `speed` | **24** | 0～100 | 16～32 | 快慢 |
| `steady` | **48** | 0～100 | 40～56 | 盯得稳 |
| `grip` | **18** | 0～100 | 10～26 | 定得住 |
| `outro` | **58** | 0～100 | 50～66 | 收场 |

| hold 键 | 定稿值 |
|---------|--------|
| shape | **decay** |
| pulse_rate | **0** |
| pulse_depth | **0** |
| swell | **0** |

> 人类预设无 `ear` 块。

### 4.3 PAD 定位

> **独立合同**：[`03_情绪坐标/人/空竭·死心.md`](../../03_情绪坐标/人/空竭·死心.md)  
> **摘要**：P=-0.7，A=0.1，D=-0.2 — 偏不悦/压抑 · 激活中性 · 控制中性
>
> PAD 定稿、12 通道投影、气质读感与验收见 **03_情绪坐标**；本文件只管 macro / hold / E(t)。

### 4.4 能量包络 E(t)

| 指标 | 值 | 说明 |
|------|-----|------|
| peak_level | **0.0764** | 全轨峰值 |
| t_peak | **19** | 蓄力结束 |
| t_settle | **26** | 启动结束 |
| t_hold0 / t_hold1 | **26** / **110** | 保持段 |
| E[0] / E[149] | **0.0** / **0.00465** | 起/收 |
| 保持段 E | **0.0310 ~ 0.0689** | hold 纹理 |

### 4.5 观众读感（🧠 待审）

- 资产 note：**轻、内收、下泄、慢散**。
- 视线 **内收**，弱攻击感，偏怯、恳求或退缩。
- 整体 **能量偏低**，软、幼、疲惫或空竭感。
- 保持段 **段内下泄**，适合崩溃/泄劲。
- 起势 **偏缓**，蓄力段更长。

### 4.6 避免混淆（🧠 待审）

| 别像 | 区分要点 |
|------|----------|
| 可怜·委屈 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 要哭未哭 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
| 崩溃·泄劲 | 🧠 同组邻近戏：peak、hold.shape、push 勿三者全撞 |
