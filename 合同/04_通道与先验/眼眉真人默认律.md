# 眼眉真人默认律（Oculomotor Prior · ecursor 合同）

> **本文件只管出厂后段**（全量展开 → 人格化 → 平庸修正 → 烘焙），**不是**全链路总说明；滑杆见 `滑杆规范.md`。  
> **行业对应**：动画终检（Finaling）+ 动捕曲线清理 + 眼动扫视动力学；不是游戏刚体物理，也不是端到端生成视频黑盒。  
> **阅读顺序**：本文 §0～§2 → `滑杆规范.md` → `全量帧指令集规范.md` → `gaze_engine/delivery_pipeline.py`。

---

## 0. 一句话

**正常人看东西、盯住、收戏，本来就会过冲、会微动、会眉眼不同步——这不是可选特效，是默认生理。**

本律规定：在 **12 通道 × 150 帧** 全量曲线上，用 **同一套真人默认律** 做一次整体修正；**用户/LLM 不单独定义「过冲多少」「要不要颤」**，只通过滑杆表达 **戏意**（多快、多狠、内收/外放、收束、盯住花纹）。

## 2. 正常人原则 vs 异常原则

### 2.1 正常人原则（默认全开）

| 现象 | 性质 | 本律要求 |
|------|------|----------|
| 快速扫视 | 二阶系统惯性 | **speed 越高，过冲越明显**；禁止「高速瞬停无过冲」 |
| 盯住 | 肌肉微动 | **保持段必有** 相关微漂 + 微颤（非死线）；扫视段 **关闭** 大颤 |
| 眉眼 | 神经延迟 | **眉峰晚于眼动** ≥ 5 帧（30fps）；睑、secondary 再略晚 |
| 12 轨 | 同一人 | 同一 **能量标量**（由 macro 推出）耦合 squint、scale、lid 等 |
| 收尾 | 一体泄劲 | `outro` 快/慢作用于 **多通道** 同步衰减，非单轨 |

**用户不为「有没有过冲/颤」负责**；只为 **多急、多狠、往哪推、怎么收、盯住花纹** 负责。

### 2.2 异常原则（偏离正常人）

仅当 **情绪包 / 风格** 标明异常时，在本律参数上 **偏移**，仍走同一引擎：

| 模式 | 相对正常人 | 示例情绪 |
|------|------------|----------|
| 僵 / 空竭 | 颤动压低、扫视变钝 | 死心、僵住 |
| 惧 / 激 | 颤动略升、收束加快 | 惊惧一怔 |
| 媚 / 勾 | 盯住段 **节奏型** 增强（pulse/swell） | 魅惑；不是「开关颤」 |
| 施压 / 怒 | 阻尼略大、盯住更钉，**仍有底噪** | 凝视、压人 |

**禁止**：用 `hold_seg.tremble` 等字段表达「正常人要不要颤」——`tremble` 在 v2 仅表示 **异常加强颤** 或待废弃，见 `滑杆规范.md` 修订说明。

## 3. 输入 / 输出（合同接口）

### 3.1 输入

| 名称 | 类型 | 必填 |
|------|------|------|
| `dense` | `dict[channel_id] → list[float]` 长度 **150** | ✅ |
| `slider_packet` | `SliderPacket`（`slider-packet-v1`） | ✅ |
| `persona` | 人格包 id（幅度上下限） | 推荐 |
| `envelope_meta` | 包络/相位元数据 | 可选；锁定 blink 时刻、phase 标签 |

**通道 id**：与 `全量帧指令集规范.md` §3 一致，**12 轨齐全**。

### 3.2 输出

| 名称 | 类型 | 说明 |
|------|------|------|
| `prior_report` | object | 修订摘要：扫视窗、过冲峰帧、颤动强度、异常模式等（供日志与验收） |
| `sparse_snapshot` | 02 兼容 JSON | 可选；从 Dense' **压缩** 所得，非手填过冲点 |

### 3.3 不变量（硬约束）

实现 **必须** 保证：

1. **时间**：30 fps，150 帧，`t ∈ [0,149]`。  
2. **结构保留**：不移动 `sparse_draft` 中已标注的 **blink 主峰**、**戏眼 phase 边界** 超过 ±2 帧（除非校验失败自动微调）。  
3. **扫视窗**（默认参考 S01）：约 **t 12～28** 应用动力学重写；**t ≥ 25** 为盯住主窗。  
4. **幅度**：各通道在人格包 `情绪.json` / 模板允许范围内 **clamp**。

## 4. 本律内部模块（逻辑合同 · 实现可分阶段）

对外 **一个入口** `apply_human_prior(dense, slider_packet, …) → dense'`；对内建议四步顺序固定：

### 4.1 意图解析（Intent）

由 `SliderPacket.macro` 推出连续参数（示例语义，实现用公式，不暴露给用户）：

| 滑杆 | 推出（示例） | 不推出 |
|------|--------------|--------|
| `speed` | 扫视时长、阻尼比 ζ、**过冲量自动** | 用户填「过冲 %」 |
| `power` | 幅度缩放、张力 | 每轨手写峰值 |
| `push` | 内收/外放符号与整体缩放 | — |
| `steady` | 盯住阻尼（稳≠死） | 「关闭微颤」 |
| `grip` / `outro` | 粘滞、收尾时间常数 | — |
| `hold_seg.shape` | 盯住段 **节奏型**（flat/decay/swell/pulse） | 正常人「开颤」 |

### 4.2 扫视动力学（Saccade · 替代手写过冲点）

在扫视窗内，对 `pupil_x`、`pupil_y` **重写轨迹**（非仅 easing 插值）：

- 模型：**欠阻尼二阶系统** 趋向目标位（目标来自 sparse 草稿或 dense 草稿的盯住值）。  
- **ζ（阻尼）** 由 `speed` 单调推出：越快 → ζ 越小 → **过冲越大**。  
- **禁止** 匀速直线撞停。  
- 过冲峰 **不必** 出现在稀疏 JSON 里；若导出 02 快照，可 **反算** 摘点。

### 4.3 盯住活劲（Fixation · 默认底噪）

在盯住主窗（约 **t 25～110**，以 phase 标签为准）：

- **底噪**：`pupil_x/y` 加 **相关** 微漂 + 带限微颤（典型 8～14 Hz 等效，幅度由 `power`/`steady` 调制）。  
- **扫视窗**：底噪 **置零**（避免盖住过冲）。  
- **缓和段**：振幅随 `outro` 衰减至 0。  
- `hold_seg.shape`：在底噪之上叠 **节奏型**（decay 下泄、swell 慢拱、pulse 低频起伏），**不是** 替代底噪。

### 4.4 通道耦合（Ensemble · 十二轨一人）

| 主钟 | 跟随（延迟 + 比例） |
|------|---------------------|
| `pupil_x/y` 扫视 | `eyebrow` 晚 8～15 帧；`pupil_scale`、`squint` 略晚、略弱 |
| 能量标量 | `iris_scale`、`cornea_bulge`、`lid_*` 同向缩放 |
| `blink` | **独立** 事件，不随扫视同步猛闭 |

**禁止**：12 轨各自独立插值后不再见面。

## 6. 合格 / 不合格（验收 · 对本律输出 Dense'）

### 6.1 自动（程序）

| 检查 | 合格 |
|------|------|
| 扫视窗内 `pupil_x` 存在峰后回弹（`\|v_peak\| > \|v_settle\|`） | ✅ |
| `speed` 高档过冲 > `speed` 低档（同目标位） | ✅ |
| 盯住窗方差 > ε 且 < 人格上限 | ✅ |
| 扫视窗颤动能量 < 盯住窗（不误颤） | ✅ |
| 眉峰帧 − 眼动 onset ≥ 5 | ✅ |
| 12 轨长度 150、无 NaN | ✅ |

| 检查 | 不合格观感 |
|------|----------------|
| A/B：关本律 vs 开本律 | 关：数学滑、死盯；开：有撞击、有活劲 |
| 五连样本盲测 | 像「一个人」而非 12 条漂亮曲线 |
| 与 05 节拍听感 | 全脸扩散节奏不「飘」 |

### 6.3 不合格 ❌ → 怎么补 🔧

| 情况 | 补法 |
|------|------|
| 高速无过冲 | 查 `speed`→ζ 映射；勿手加点 |
| 扫视段抖 | 收窄扫视窗或降低扫视窗噪声 |
| 眉眼同帧 | 查耦合延迟参数 |
| 绕过本律直接播 02 草稿 | **流程错误**；重跑 Human Prior |

### 6.4 平庸（L3b · 全量 Dense′）

> **理论总纲**（跨物种双标准、权威溯源）：[`09_先验与质检/双质量标准_不要假不要平庸.md`](../09_先验与质检/双质量标准_不要假不要平庸.md)

**理论**：拉班 Effort 塌缩（能量不够）· 保持段 Flow/Space 失控（杂乱）· Beat 主次不清（眉眼打架 = 不纯）。

| 编号 | 检测 | 自动修正 | 日记字段 |
|------|------|----------|----------|
| **Q01** | 峰弱 / 范围小 / 起势弱 / 盯住瘪 | 主能量通道整体 ×scale（≤1.42） | `_pulse_quality_fix_log` |
| **Q02** | `flat`/`decay` 保持段过零过多或起伏过大 | 盯住窗轻平滑 `pupil_x/y` | 同上 |
| **Q03** | 眉峰不晚于眼 | `eyebrow` 延后 3～12 帧 | 同上 |

- **时机**：`human_prior` **之后**、烘焙 **之前**（`gaze_engine/pulse_quality.py` → `fix_pulse_quality()`）。
- **关闭**：`ECURSOR_PULSE_QUALITY=0`。
- **残留**：`_pulse_quality_remaining`；完整指标 `pulse_quality_report`。
